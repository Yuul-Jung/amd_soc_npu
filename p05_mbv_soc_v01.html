제5장 · MicroBlaze V SoC

4장 NPU를 AXI IP로 감싸 MicroBlaze V SoC에 붙이고, C 드라이버로 움직인 뒤 시간·자원·전력을 잽니다.

00 이 장에서 만드는 것

4장까지는 PC가 UART로 NPU를 직접 움직였습니다. 실제 제품에서는 CPU가 그 일을 합니다. 이 장에서는 4장의 784 가속기를 CPU가 쓸 수 있는 주변장치로 만들고, 소프트 CPU인 MicroBlaze V와 한 칩에 넣어 SoC(System on Chip)를 구성합니다.

CPU와 주변장치는 AXI라는 버스로 이어지고, CPU는 주변장치를 주소로 구분합니다. NPU에 주소를 주고, C 언어 드라이버로 레지스터를 읽고 써서 추론을 실행합니다. 그런 다음 같은 추론을 CPU 혼자 할 때와 NPU에 맡길 때의 시간, 회로 크기, 에너지를 비교합니다.

장 끝에서 보드로 보여 줄 것: 비트스트림 하나에 MicroBlaze V와 NPU가 함께 들어갑니다. C 드라이버가 그림 4장을 NPU로 분류해 UART·LED·7세그먼트에 띄웁니다. 같은 추론이 CPU만으로는 1,816,547클록, NPU로는 1,080,161클록 걸립니다.

2일 과정, 서브젝트 7개입니다. 비트스트림은 5-2에서 한 번만 만들고, 그다음 서브젝트부터는 프로그램(ELF)만 바꿔 보드에서 확인합니다.

  1. 5-1AXI4-Lite NPU IP
    AXI 버스로 레지스터 15개를 읽고 써서 784 추론을 실행합니다. 추론 7번의 결과가 Python 기준과 비트 단위로 같고, 없는 주소를 건드리면 오류 응답(SLVERR)이 돌아오는 것을 시뮬레이션으로 봅니다.    1일 오전
  2. 5-2MicroBlaze V SoC 연결
    비트스트림을 내려받으면 DONE LED가 켜집니다. XSDB에서 mrd 0x4006FFF0을 읽으면 7세그먼트 IP의 ID 53454737이 나오고, 버튼을 누른 채 mrd 0x40010000을 읽으면 U·D·L·R이 8·4·2·1로 보입니다.    1일 오전
  3. 5-3C 드라이버와 표시
    npu_app.elf를 실행하면 그림 4장을 NPU로 분류하고, CPU로 계산한 값과 점수까지 같은지 비교합니다(scores_match=1). 끝나면 7세그먼트에 03 4, LED4가 켜집니다.    1일 오후
  4. 5-4CPU·NPU 추론 시간
    bench_board.elf를 실행하면 같은 그림을 CPU 정수 계산으로 1,816,547클록, NPU로 1,080,161클록(Bias 적재 3,076 포함)에 처리합니다. 1.68배 차이이고, 리셋 뒤 다시 실행해도 같은 값입니다.    1일 오후
  5. 5-5자원·타이밍 스윕
    클록 주기를 10 → 8 → 7 → 6 ns로 줄여 가며 배선해 봅니다. AXI NPU IP는 10 ns에서 되고 8 ns에서 안 되므로 최고 주파수는 약 105 MHz, 4PE INT8 코어는 약 146 MHz입니다.    2일 오전
  6. 5-6전력·추론당 에너지
    Vivado 전력 추정으로 추론 한 번에 드는 에너지를 비교합니다. CPU 4.596 mJ, NPU 2.765 mJ로 1.66배 차이입니다.    2일 오전

03 서브젝트 5-1 · AXI4-Lite NPU IP

목표: AXI 버스로 레지스터 15개를 읽고 써서 784 추론을 실행합니다. 추론 7번의 결과가 Python 기준과 비트 단위로 같고, 없는 주소를 건드리면 오류 응답(SLVERR)이 돌아오는 것을 시뮬레이션으로 봅니다.

해설

NPU를 CPU가 쓸 수 있게 하려면 버스 규격에 맞는 접속부가 필요합니다. p3_npu_axi_lite는 4장의 가속기를 AXI4-Lite 버스 뒤에 두고, 제어·상태·가중치·입력·결과를 레지스터 15개로 보여 줍니다. CPU는 이 레지스터 주소에 값을 쓰고 읽는 것만으로 NPU를 움직입니다.

없는 주소에 접근하면 조용히 넘어가지 않고 오류 응답을 돌려줍니다. 소프트웨어의 실수를 하드웨어가 알려 주는 장치입니다.

보드에서 확인

IP 하나만으로는 보드에 올릴 수 없으므로 이 서브젝트는 시뮬레이션으로 확인합니다. 보드 확인은 5-2에서 이 IP를 주소 0x44A0_0000에 붙인 뒤에 합니다.

작성할 코드

part03/ch20/rtl/p3_npu_axi_lite.v · verilog
`timescale 1ns/1ps
// (추가) 20장: 17장 Tile Controller(784입력·10분류 NPU)를 AXI4-Lite 제어·상태 레지스터로 감싼 Slave.
// 데이터 경로(14장 코어·17장 컨트롤러)는 그대로 두고 버스 어댑터만 추가한다. x 타일은 04장 bram_sync_buffer.
//
// 레지스터(32비트, 오프셋): 0x00 CTRL  0x04 STATUS  0x08 LENGTH  0x0C CLASS  0x10 X_INDEX  0x14 X_DATA
//   0x18 W_CLASS  0x1C W_INDEX  0x20 W_DATA  0x24 BIAS_LO  0x28 BIAS_HI  0x2C SCORE_SEL
//   0x30 SCORE_LO  0x34 SCORE_HI  0x38 IRQ_EN. 0x3C는 미할당(SLVERR).
// 응답 정책: 버스 수준 거부(미할당 주소, 읽기 전용 쓰기, 동작 레지스터 부분 WSTRB, 범위 초과 값,
//   프레임 잠금 중 X_DATA)는 SLVERR이며 아무 효과도 없다. NPU 동작 오류는 STATUS.ERROR·ERR_CODE로 알린다.
// AW와 W는 따로 도착할 수 있다: 각각 1개씩 보관했다가 둘 다 있으면 실행하고 B 응답을 BREADY까지 유지한다.
module p3_npu_axi_lite #(
    parameter integer DATA_W = 8,      // x·W signed 폭 (17장 기본 INT8)
    parameter integer CORE_ACC_W = 24, // 14장 코어 lane 누산 폭
    parameter integer PART_W = 25      // 14장 코어 점수 폭
)(
    input wire s_axi_aclk,
    input wire s_axi_aresetn,
    input wire [5:0] s_axi_awaddr,
    input wire [2:0] s_axi_awprot,     // AXI4-Lite 인터페이스 규격용(사용하지 않음)
    input wire s_axi_awvalid,
    output wire s_axi_awready,
    input wire [31:0] s_axi_wdata,
    input wire [3:0] s_axi_wstrb,
    input wire s_axi_wvalid,
    output wire s_axi_wready,
    output reg [1:0] s_axi_bresp,
    output reg s_axi_bvalid,
    input wire s_axi_bready,
    input wire [5:0] s_axi_araddr,
    input wire [2:0] s_axi_arprot,     // AXI4-Lite 인터페이스 규격용(사용하지 않음)
    input wire s_axi_arvalid,
    output wire s_axi_arready,
    output reg [31:0] s_axi_rdata,
    output reg [1:0] s_axi_rresp,
    output reg s_axi_rvalid,
    input wire s_axi_rready,
    output wire irq_o                  // IRQ_EN[0] && STATUS.DONE (레벨)
);
    localparam integer ACC_W = 41, BIAS_W = 40, SCORE_W = 42, N_IN = 784;
    localparam [1:0] OKAY = 2'b00, SLVERR = 2'b10;
    localparam [3:0] R_CTRL = 4'h0, R_STATUS = 4'h1, R_LENGTH = 4'h2, R_CLASS = 4'h3,
                     R_XIDX = 4'h4, R_XDATA = 4'h5, R_WCLASS = 4'h6, R_WIDX = 4'h7,
                     R_WDATA = 4'h8, R_BLO = 4'h9, R_BHI = 4'hA, R_SSEL = 4'hB,
                     R_SLO = 4'hC, R_SHI = 4'hD, R_IRQEN = 4'hE;
    // ERR_CODE: 1~6 = 17장 컨트롤러 코드, 아래는 이 어댑터가 검출하는 코드
    localparam [3:0] ERR_NO_FRAME = 4'd4, ERR_LENGTH = 4'd8, ERR_W_MISSING = 4'd9;
    wire clk = s_axi_aclk;
    wire resetn = s_axi_aresetn;

    // ---------------- NPU 데이터 경로 ----------------
    reg start_q, abort_q, go_q;
    reg [3:0] go_id_q;
    reg x_held_q;
    reg x_wr_q, w_wr_q, b_wr_q;
    reg [5:0] x_wr_addr_q;
    reg signed [DATA_W-1:0] x_wr_data_q, w_data_q;
    reg [3:0] wr_class_q;
    reg [5:0] wr_addr_q;
    reg signed [BIAS_W-1:0] b_data_q;
    wire x_rd_en, frame_ack, load_ready, busy, done, error, ovf;
    wire [5:0] x_rd_addr;
    wire signed [DATA_W-1:0] x_rd_data;
    wire [2:0] npu_err_code;
    wire [3:0] tile_idx, npu_class;
    wire [10*SCORE_W-1:0] scores;

    bram_sync_buffer #(.DATA_WIDTH(DATA_W), .ADDR_WIDTH(6)) xbuf(
        .clk(clk), .resetn(resetn), .wr_en(x_wr_q), .rd_en(x_rd_en),
        .wr_addr(x_wr_addr_q), .rd_addr(x_rd_addr), .wr_data(x_wr_data_q),
        .rd_data(x_rd_data), .rd_valid());
    p3_tile784_10 #(.ACC_W(ACC_W), .BIAS_W(BIAS_W), .SCORE_W(SCORE_W), .DATA_W(DATA_W),
                    .CORE_ACC_W(CORE_ACC_W), .PART_W(PART_W)) npu(
        .clk(clk), .resetn(resetn), .start_i(start_q), .abort_i(abort_q),
        .tile_go_i(go_q), .tile_id_i(go_id_q),
        .x_valid_i(x_held_q), .x_rd_en_o(x_rd_en), .x_rd_addr_o(x_rd_addr),
        .x_rd_data_i(x_rd_data), .frame_ack_o(frame_ack),
        .w_wr_en_i(w_wr_q), .b_wr_en_i(b_wr_q), .wr_class_i(wr_class_q), .wr_addr_i(wr_addr_q),
        .w_data_i(w_data_q), .b_data_i(b_data_q), .load_ready_o(load_ready),
        .busy_o(busy), .done_o(done), .error_o(error), .err_code_o(npu_err_code), .ovf_o(ovf),
        .tile_idx_o(tile_idx), .tile_done_o(), .part_scores_o(),
        .class_o(npu_class), .scores_o(scores));

    // ---------------- 레지스터 ----------------
    reg [31:0] length_q, bias_lo_q;
    reg [5:0] x_index_q, w_index_q;
    reg [3:0] w_class_q, score_sel_q, err_code_q;
    reg irq_en_q, done_st_q, err_st_q;
    reg [63:0] x_map_q;            // 현재 타일 x 주소별 쓰기 여부
    reg [9:0] w_cnt_q;             // 현재 타일에서 수락된 W 쓰기 수
    reg [31:0] score_hi_q;         // SCORE_LO 읽기 시점의 상위 비트(스냅샷)
    assign irq_o = irq_en_q && done_st_q;
    wire in_load = busy && load_ready;
    wire [9:0] w_need = (tile_idx == 4'd12) ? 10'd160 : 10'd640;

    // 쓰기 채널: AW·W 각각 1개 보관
    reg aw_q, w_q;
    reg [3:0] aw_idx_q;
    reg [31:0] wd_q;
    reg [3:0] ws_q;
    assign s_axi_awready = resetn && !aw_q && !s_axi_bvalid;
    assign s_axi_wready = resetn && !w_q && !s_axi_bvalid;
    wire wr_exec = aw_q && w_q && !s_axi_bvalid;

    function [31:0] merge(input [31:0] old, input [31:0] nv, input [3:0] strb);
        integer i;
        begin
            for (i = 0; i < 4; i = i + 1)
                merge[8*i +: 8] = strb[i] ? nv[8*i +: 8] : old[8*i +: 8];
        end
    endfunction
    // 32비트 값이 signed n비트 범위인가(상위 비트가 모두 부호와 같음)
    function fits_signed(input [31:0] v, input integer n);
        integer i;
        begin
            fits_signed = 1'b1;
            for (i = 0; i < 32; i = i + 1)
                if (i >= n - 1 && v[i] != v[n-1]) fits_signed = 1'b0;
        end
    endfunction

    wire full_strb = (ws_q == 4'hF);
    // 설정 레지스터는 WSTRB 바이트만 바꾼 값으로 범위를 검사하고 저장한다
    wire [31:0] xidx_m = merge({26'd0, x_index_q}, wd_q, ws_q);
    wire [31:0] wcls_m = merge({28'd0, w_class_q}, wd_q, ws_q);
    wire [31:0] widx_m = merge({26'd0, w_index_q}, wd_q, ws_q);
    wire [31:0] ssel_m = merge({28'd0, score_sel_q}, wd_q, ws_q);
    wire [31:0] irq_m = merge({31'd0, irq_en_q}, wd_q, ws_q);
    wire [2:0] cmd = wd_q[2:0];                  // CTRL bit0 START, bit1 TILE_GO, bit2 ABORT
    wire cmd_one = (cmd == 3'b001) || (cmd == 3'b010) || (cmd == 3'b100);
    // 실행할 쓰기의 SLVERR 여부
    reg wr_bad;
    always @* begin
        case (aw_idx_q)
            R_CTRL: wr_bad = !full_strb || !cmd_one;
            R_STATUS, R_LENGTH, R_BLO: wr_bad = 1'b0;
            R_IRQEN: wr_bad = irq_m > 32'd1;
            R_XIDX: wr_bad = xidx_m > 32'd63;
            R_XDATA: wr_bad = !full_strb || x_held_q || !fits_signed(wd_q, DATA_W);
            R_WCLASS: wr_bad = wcls_m > 32'd9;
            R_WIDX: wr_bad = widx_m > 32'd63;
            R_WDATA: wr_bad = !full_strb || !fits_signed(wd_q, DATA_W);
            R_BHI: wr_bad = !full_strb || !fits_signed(wd_q, BIAS_W - 32);
            R_SSEL: wr_bad = ssel_m > 32'd9;
            default: wr_bad = 1'b1;   // CLASS·SCORE_LO·SCORE_HI 읽기 전용, 0x3C 미할당
        endcase
    end

    // 읽기 채널
    assign s_axi_arready = resetn && !s_axi_rvalid;
    wire rd_acc = s_axi_arvalid && s_axi_arready;
    wire [3:0] ar_idx = s_axi_araddr[5:2];
    wire [SCORE_W-1:0] sel_score = scores[score_sel_q*SCORE_W +: SCORE_W];
    wire [31:0] status = {16'd0, err_code_q, tile_idx, 2'd0, x_held_q, load_ready,
                          ovf, err_st_q, done_st_q, busy};

    always @(posedge clk) begin
        if (!resetn) begin
            aw_q <= 1'b0; w_q <= 1'b0; aw_idx_q <= 4'd0; wd_q <= 32'd0; ws_q <= 4'd0;
            s_axi_bvalid <= 1'b0; s_axi_bresp <= OKAY;
            s_axi_rvalid <= 1'b0; s_axi_rresp <= OKAY; s_axi_rdata <= 32'd0;
            start_q <= 1'b0; abort_q <= 1'b0; go_q <= 1'b0; go_id_q <= 4'd0;
            x_held_q <= 1'b0; x_wr_q <= 1'b0; w_wr_q <= 1'b0; b_wr_q <= 1'b0;
            x_wr_addr_q <= 6'd0; x_wr_data_q <= {DATA_W{1'b0}}; w_data_q <= {DATA_W{1'b0}};
            wr_class_q <= 4'd0; wr_addr_q <= 6'd0; b_data_q <= {BIAS_W{1'b0}};
            length_q <= N_IN; bias_lo_q <= 32'd0; x_index_q <= 6'd0; w_index_q <= 6'd0;
            w_class_q <= 4'd0; score_sel_q <= 4'd0; err_code_q <= 4'd0;
            irq_en_q <= 1'b0; done_st_q <= 1'b0; err_st_q <= 1'b0;
            x_map_q <= 64'd0; w_cnt_q <= 10'd0; score_hi_q <= 32'd0;
        end else begin
            start_q <= 1'b0; abort_q <= 1'b0; go_q <= 1'b0;
            x_wr_q <= 1'b0; w_wr_q <= 1'b0; b_wr_q <= 1'b0;
            if (s_axi_awvalid && s_axi_awready) begin
                aw_q <= 1'b1;
                aw_idx_q <= s_axi_awaddr[5:2];
            end
            if (s_axi_wvalid && s_axi_wready) begin
                w_q <= 1'b1;
                wd_q <= s_axi_wdata;
                ws_q <= s_axi_wstrb;
            end
            if (s_axi_bvalid && s_axi_bready)
                s_axi_bvalid <= 1'b0;

            // NPU 상태 반영(쓰기 실행보다 먼저: 같은 클록의 W1C·START가 우선)
            if (done)
                done_st_q <= 1'b1;
            if (error) begin
                err_st_q <= 1'b1;
                err_code_q <= {1'b0, npu_err_code};
            end
            if (frame_ack) begin
                x_held_q <= 1'b0;
                x_map_q <= 64'd0;
                w_cnt_q <= 10'd0;
            end
            if (w_wr_q && load_ready && w_cnt_q != 10'h3FF)
                w_cnt_q <= w_cnt_q + 10'd1;

            if (wr_exec) begin
                aw_q <= 1'b0;
                w_q <= 1'b0;
                s_axi_bvalid <= 1'b1;
                s_axi_bresp <= wr_bad ? SLVERR : OKAY;
                if (!wr_bad) case (aw_idx_q)
                    R_CTRL: begin
                        if (cmd[0]) begin
                            if (length_q != N_IN) begin
                                err_st_q <= 1'b1;
                                err_code_q <= ERR_LENGTH;
                            end else begin
                                start_q <= 1'b1;
                                if (!busy) done_st_q <= 1'b0;
                            end
                        end
                        if (cmd[2])
                            abort_q <= 1'b1;
                        if (cmd[1]) begin
                            go_id_q <= wd_q[11:8];
                            if (!in_load || x_held_q) begin
                                go_q <= 1'b1;          // 상태 판정은 컨트롤러가 한다
                            end else if (x_map_q != {64{1'b1}}) begin
                                err_st_q <= 1'b1;
                                err_code_q <= ERR_NO_FRAME;
                            end else if (w_cnt_q < w_need) begin
                                err_st_q <= 1'b1;
                                err_code_q <= ERR_W_MISSING;
                            end else begin
                                x_held_q <= 1'b1;      // 결과 수락(frame_ack)까지 X_DATA 잠금
                                go_q <= 1'b1;
                            end
                        end
                    end
                    R_STATUS: begin                   // W1C: bit1 DONE, bit2 ERROR
                        if (ws_q[0] && wd_q[1]) done_st_q <= 1'b0;
                        if (ws_q[0] && wd_q[2]) err_st_q <= 1'b0;
                    end
                    R_LENGTH: length_q <= merge(length_q, wd_q, ws_q);
                    R_XIDX: x_index_q <= xidx_m[5:0];
                    R_XDATA: begin
                        x_wr_q <= 1'b1;
                        x_wr_addr_q <= x_index_q;
                        x_wr_data_q <= wd_q[DATA_W-1:0];
                        x_map_q[x_index_q] <= 1'b1;
                        x_index_q <= x_index_q + 6'd1;
                    end
                    R_WCLASS: w_class_q <= wcls_m[3:0];
                    R_WIDX: w_index_q <= widx_m[5:0];
                    R_WDATA: begin
                        w_wr_q <= 1'b1;
                        wr_class_q <= w_class_q;
                        wr_addr_q <= w_index_q;
                        w_data_q <= wd_q[DATA_W-1:0];
                        w_index_q <= w_index_q + 6'd1;
                    end
                    R_BLO: bias_lo_q <= merge(bias_lo_q, wd_q, ws_q);
                    R_BHI: begin                      // BIAS_LO와 합쳐 W_CLASS의 Bias로 확정
                        b_wr_q <= 1'b1;
                        wr_class_q <= w_class_q;
                        b_data_q <= {wd_q[BIAS_W-33:0], bias_lo_q};
                    end
                    R_SSEL: score_sel_q <= ssel_m[3:0];
                    R_IRQEN: irq_en_q <= irq_m[0];
                    default: ;
                endcase
            end

            if (s_axi_rvalid && s_axi_rready)
                s_axi_rvalid <= 1'b0;
            if (rd_acc) begin
                s_axi_rvalid <= 1'b1;
                s_axi_rresp <= (ar_idx == 4'hF) ? SLVERR : OKAY;
                case (ar_idx)
                    R_STATUS: s_axi_rdata <= status;
                    R_LENGTH: s_axi_rdata <= length_q;
                    R_CLASS: s_axi_rdata <= {28'd0, npu_class};
                    R_XIDX: s_axi_rdata <= {26'd0, x_index_q};
                    R_WCLASS: s_axi_rdata <= {28'd0, w_class_q};
                    R_WIDX: s_axi_rdata <= {26'd0, w_index_q};
                    R_BLO: s_axi_rdata <= bias_lo_q;
                    R_SSEL: s_axi_rdata <= {28'd0, score_sel_q};
                    R_SLO: begin                      // 하위 32비트와 상위 비트를 같은 순간에 잡는다
                        s_axi_rdata <= sel_score[31:0];
                        score_hi_q <= {{(64-SCORE_W){sel_score[SCORE_W-1]}}, sel_score[SCORE_W-1:32]};
                    end
                    R_SHI: s_axi_rdata <= score_hi_q;
                    R_IRQEN: s_axi_rdata <= {31'd0, irq_en_q};
                    default: s_axi_rdata <= 32'd0;    // CTRL·X_DATA·W_DATA·BIAS_HI는 쓰기 전용, 0x3C 미할당
                endcase
            end
        end
    end
    // synthesis translate_off
    initial begin
        if (DATA_W < 2 || DATA_W > 16)
            $fatal(1, "Require 2 <= DATA_W <= 16");
    end
    // synthesis translate_on
endmodule

// (추가) 20장 p3_npu_axi_lite 자동 판정 테스트벤치. AXI4-Lite Master BFM으로 레지스터만 사용해 784 추론을 수행한다.
// 프로토콜: AW·W 동시/AW 먼저/W 먼저, BREADY·RREADY 지연 중 응답 유지(상시 검사), WSTRB 병합,
//   읽기 전용·미할당 주소·범위 초과·부분 WSTRB·프레임 잠금 중 X_DATA → SLVERR(효과 없음 확인).
// 동작: LENGTH 오류, IDLE의 TILE_GO, x 미완성·W 미적재 TILE_GO, BUSY 중 START·Bias 쓰기, DONE·ERROR W1C,
//   IRQ, SCORE_LO/HI 스냅샷(LO 읽은 뒤 다음 추론이 끝나도 HI는 같은 결과), 미완료 AXI 쓰기·추론 중 Reset.
// 각 추론의 10개 점수(LO/HI)·CLASS·OVF를 actual에 기록하고 Python이 비트 단위 비교한다.
`timescale 1ns/1ps
module tb_p3_npu_axi_lite;
    localparam [5:0] A_CTRL = 6'h00, A_STATUS = 6'h04, A_LENGTH = 6'h08, A_CLASS = 6'h0C,
                     A_XIDX = 6'h10, A_XDATA = 6'h14, A_WCLASS = 6'h18, A_WIDX = 6'h1C,
                     A_WDATA = 6'h20, A_BLO = 6'h24, A_BHI = 6'h28, A_SSEL = 6'h2C,
                     A_SLO = 6'h30, A_SHI = 6'h34, A_IRQEN = 6'h38, A_BAD = 6'h3C;
    localparam [1:0] OKAY = 2'b00, SLVERR = 2'b10;
    localparam [31:0] START = 32'h1, GO = 32'h2, ABORT = 32'h4;

    reg clk = 0, resetn = 0;
    always #5 clk = ~clk;
    reg [5:0] awaddr = 0, araddr = 0;
    reg awvalid = 0, wvalid = 0, bready = 0, arvalid = 0, rready = 0;
    reg [31:0] wdata = 0;
    reg [3:0] wstrb = 0;
    wire awready, wready, bvalid, arready, rvalid, irq;
    wire [1:0] bresp, rresp;
    wire [31:0] rdata;

    p3_npu_axi_lite dut(
        .s_axi_aclk(clk), .s_axi_aresetn(resetn),
        .s_axi_awaddr(awaddr), .s_axi_awprot(3'd0), .s_axi_awvalid(awvalid), .s_axi_awready(awready),
        .s_axi_wdata(wdata), .s_axi_wstrb(wstrb), .s_axi_wvalid(wvalid), .s_axi_wready(wready),
        .s_axi_bresp(bresp), .s_axi_bvalid(bvalid), .s_axi_bready(bready),
        .s_axi_araddr(araddr), .s_axi_arprot(3'd0), .s_axi_arvalid(arvalid), .s_axi_arready(arready),
        .s_axi_rdata(rdata), .s_axi_rresp(rresp), .s_axi_rvalid(rvalid), .s_axi_rready(rready),
        .irq_o(irq));

    // 상시 검사: 응답 valid는 ready 전까지 내려가지 않고 내용이 바뀌지 않는다
    reg pb = 0, pr = 0;
    reg [1:0] pbresp = 0, prresp = 0;
    reg [31:0] prdata = 0;
    integer n_writes = 0, n_reads = 0, n_slverr = 0;
    always @(posedge clk) begin
        if (resetn) begin
            if (pb && !bvalid) $fatal(1, "BVALID dropped before BREADY");
            if (pb && bvalid && bresp != pbresp) $fatal(1, "BRESP changed while waiting");
            if (pr && !rvalid) $fatal(1, "RVALID dropped before RREADY");
            if (pr && rvalid && (rdata != prdata || rresp != prresp)) $fatal(1, "R payload changed");
            if (dut.npu.core.error_o) $fatal(1, "core error leaked");
            if (bvalid && bready) begin n_writes = n_writes + 1; if (bresp == SLVERR) n_slverr = n_slverr + 1; end
            if (rvalid && rready) begin n_reads = n_reads + 1; if (rresp == SLVERR) n_slverr = n_slverr + 1; end
        end
        pb = resetn && bvalid && !bready; pbresp = bresp;
        pr = resetn && rvalid && !rready; prresp = rresp; prdata = rdata;
    end

    // ---------------- AXI Master BFM (20장 공용) ----------------
    `include "axi_lite_bfm.svh"

    reg [1:0] resp;
    reg [31:0] rd;
    task automatic wr(input [5:0] a, input [31:0] d);
        begin
            axi_write(a, d, 4'hF, 0, 0, 0, resp);
            if (resp != OKAY) $fatal(1, "write 0x%02h=0x%08h got SLVERR", a, d);
        end
    endtask
    task automatic wr_expect(input [5:0] a, input [31:0] d, input [3:0] s, input [1:0] exp);
        begin
            axi_write(a, d, s, 0, 0, 0, resp);
            if (resp != exp) $fatal(1, "write 0x%02h strb %b resp %0d != %0d", a, s, resp, exp);
        end
    endtask
    task automatic rd_reg(input [5:0] a, output [31:0] d);
        begin
            axi_read(a, 0, d, resp);
            if (resp != OKAY) $fatal(1, "read 0x%02h got SLVERR", a);
        end
    endtask
    task automatic expect_reg(input [5:0] a, input [31:0] exp);
        begin
            rd_reg(a, rd);
            if (rd != exp) $fatal(1, "reg 0x%02h = 0x%08h, expected 0x%08h", a, rd, exp);
        end
    endtask
    // STATUS: bit0 BUSY, 1 DONE, 2 ERROR, 3 OVF, 4 LOAD_READY, 5 X_HELD, [11:8] TILE, [15:12] ERR_CODE
    task automatic expect_error(input [3:0] code, input [8*40-1:0] what);
        begin
            rd_reg(A_STATUS, rd);
            if (!rd[2] || rd[15:12] != code)
                $fatal(1, "missing error %0d (STATUS 0x%08h): %0s", code, rd, what);
            wr(A_STATUS, 32'h4);              // ERROR W1C
            rd_reg(A_STATUS, rd);
            if (rd[2]) $fatal(1, "ERROR not cleared by W1C");
        end
    endtask
    task automatic do_reset;
        begin
            @(negedge clk);
            resetn = 0; awvalid = 0; wvalid = 0; arvalid = 0; bready = 0; rready = 0;
            repeat (3) @(negedge clk);
            resetn = 1;
            @(negedge clk);
            if (bvalid || rvalid || irq || dut.npu.busy_o || dut.aw_q || dut.w_q)
                $fatal(1, "reset did not clear AXI/NPU state");
        end
    endtask

    // ---------------- 추론 ----------------
    integer X [0:783];
    integer PAD [0:47];
    integer W [0:9][0:783];
    reg signed [63:0] B [0:9];
    reg signed [63:0] S [0:9];
    reg signed [63:0] tmp64, v64;
    integer tmp, vf, af, rc, ncase, cidx, i, c, t, len, guard;
    reg [8*256-1:0] vpath, apath;

    task automatic poll_until(input integer bit_idx, input integer value);
        begin
            guard = 0;
            rd_reg(A_STATUS, rd);
            while (rd[bit_idx] != value) begin
                rd_reg(A_STATUS, rd);
                guard = guard + 1;
                if (guard > 2000) $fatal(1, "STATUS bit %0d timeout (0x%08h)", bit_idx, rd);
            end
        end
    endtask
    task automatic load_bias;
        begin
            for (c = 0; c < 10; c = c + 1) begin
                wr(A_WCLASS, c);
                v64 = B[c];
                wr(A_BLO, v64[31:0]);
                wr(A_BHI, {{24{v64[39]}}, v64[39:32]});
            end
        end
    endtask
    task automatic load_w(input integer tile, input integer n);
        begin
            for (c = 0; c < 10; c = c + 1) begin
                wr(A_WCLASS, c);
                wr(A_WIDX, 0);
                for (i = 0; i < n; i = i + 1) wr(A_WDATA, W[c][64*tile + i]);
            end
        end
    endtask
    task automatic load_x(input integer tile, input integer n);
        begin
            wr(A_XIDX, 0);
            for (i = 0; i < 64; i = i + 1) wr(A_XDATA, (i < n) ? X[64*tile + i] : PAD[i - n]);
        end
    endtask
    task automatic read_scores(input integer record);
        begin
            for (c = 0; c < 10; c = c + 1) begin
                wr(A_SSEL, c);
                rd_reg(A_SLO, rd);
                v64[31:0] = rd;
                rd_reg(A_SHI, rd);
                v64[63:32] = rd;
                S[c] = v64;
                if (v64 < -(64'sd1 <<< 41) || v64 >= (64'sd1 <<< 41)) $fatal(1, "score HI not sign-extended");
            end
            rd_reg(A_CLASS, rd);
            if (record) begin
                $fwrite(af, "S");
                for (c = 0; c < 10; c = c + 1) $fwrite(af, " %0d", S[c]);
                rd_reg(A_STATUS, tmp64[31:0]);
                $fwrite(af, " C%0d O%0d\n", rd, tmp64[3]);
            end
        end
    endtask
    // mode 0: 정상, 1: 오류 주입, 2: 타일 5 계산 중 Reset
    task automatic run_inference(input integer mode);
        reg cut;
        begin
            cut = 0;
            load_bias;
            wr(A_CTRL, START);
            rd_reg(A_STATUS, rd);
            if (!rd[0] || rd[1]) $fatal(1, "START: BUSY not set or DONE not cleared (0x%08h)", rd);
            if (irq) $fatal(1, "IRQ after START");
            if (mode == 1) begin
                wr(A_CTRL, START);
                expect_error(4'd1, "START while BUSY");
                wr(A_WCLASS, 0); wr(A_BLO, 1); wr(A_BHI, 0);
                expect_error(4'd5, "Bias write during inference");
            end
            for (t = 0; t < 13 && !cut; t = t + 1) begin
                len = (t == 12) ? 16 : 64;
                if (mode == 1 && t == 0) begin

def split_score(v):
    """42비트 signed 점수 → (SCORE_LO, SCORE_HI) 32비트 부호 없는 레지스터 값."""
    u = v & ((1 << 64) - 1)
    return u & 0xFFFFFFFF, u >> 32


def cases(rng):
    qm = quantize_model(json.loads(MODEL.read_text()), 8)
    picked = []
    for line in SAMPLES.read_text().splitlines():
        if line.startswith("#"):
            continue
        v = list(map(int, line.split()))
        picked.append((v[0], v[3], v[2], v[5:]))   # index, int8 예측, float 예측, pixels
    mnist = [picked[0], next(p for p in picked if p[1] != p[2]), picked[1]]
    out = [(quantize_x(px, 8), qm["w"], qm["b"]) for _, _, _, px in mnist]
    ext = build_cases("width", BIAS_W, random.Random(1717))[:2]   # 17장 극값(Bias ±2^39)
    out = [ext[0]] + out[:1] + [ext[1]] + out[1:]                 # 0: 극값(스냅샷 A), 1: MNIST(B)
    out.append(([rng.randint(-128, 127) for _ in range(N_IN)],
                [[rng.randint(-128, 127) for _ in range(N_IN)] for _ in range(N_CLASS)],
                [rng.randint(-(1 << 39), (1 << 39) - 1) for _ in range(N_CLASS)]))
    b = [-100 - c for c in range(N_CLASS)]
    b[0] = b[1] = 5
    out.append(([0] * N_IN, [[0] * N_IN for _ in range(N_CLASS)], b))
    return out


def selftest():
    assert split_score(-1) == (0xFFFFFFFF, 0xFFFFFFFF)
    assert split_score((1 << 41) - 1) == (0xFFFFFFFF, 0x1FF)
    assert split_score(-(1 << 41)) == (0, 0xFFFFFE00)
    assert sorted(REG.values()) == list(range(0, 0x3C, 4))


def generate(out):

    rng = random.Random(2020)
    cs = cases(rng)
    with (out / "vectors.txt").open("w") as vf, (out / "expected.txt").open("w") as ef:

            for row in w:

            vf.write(" ".join(map(str, b)) + "\n")
            ef.write("S " + " ".join(map(str, scores)) + f" C{cls} O{int(ovf)}\n")

/* (추가) 22장: p3_npu_axi_lite 드라이버 구현. 20장 docs/README.md의 "CPU 실행 순서"를 그대로 따른다. */
#include "npu_driver.h"

static void wr(npu_t *npu, uint32_t off, uint32_t v) { npu_io_write(npu->base + off, v); }
static uint32_t rd(npu_t *npu, uint32_t off) { return npu_io_read(npu->base + off); }

void npu_init(npu_t *npu, uintptr_t base)
{
    npu->base = base;
    npu->last_status = 0;
    npu->poll_limit = 100000u;
    wr(npu, NPU_IRQ_EN, 0);
    wr(npu, NPU_STATUS, NPU_ST_DONE | NPU_ST_ERROR);   /* W1C */
}

uint32_t npu_last_status(const npu_t *npu) { return npu->last_status; }

void npu_irq_enable(npu_t *npu, int enable) { wr(npu, NPU_IRQ_EN, enable ? 1u : 0u); }

void npu_clear_done(npu_t *npu) { wr(npu, NPU_STATUS, NPU_ST_DONE); }

/* STATUS가 (s & mask) == want가 될 때까지 폴링. 도중 ERROR면 실패. */
static int wait_status(npu_t *npu, uint32_t mask, uint32_t want)
{
    uint32_t n;
    for (n = 0; n < npu->poll_limit; n++) {
        uint32_t s = rd(npu, NPU_STATUS);
        npu->last_status = s;
        if (s & NPU_ST_ERROR)
            return NPU_E_HW;
        if ((s & mask) == want)
            return NPU_OK;
    }
    return NPU_E_TIMEOUT;
}

int npu_set_bias(npu_t *npu, const int64_t bias[NPU_N_CLASS])
{
    int c;
    for (c = 0; c < NPU_N_CLASS; c++) {
        uint64_t b = (uint64_t)bias[c];
        wr(npu, NPU_W_CLASS, (uint32_t)c);
        wr(npu, NPU_BIAS_LO, (uint32_t)b);
        /* [39:32]를 32비트로 부호 확장 */
        wr(npu, NPU_BIAS_HI, (uint32_t)(int32_t)(int8_t)(uint8_t)(b >> 32));
    }
    npu->last_status = rd(npu, NPU_STATUS);
    return (npu->last_status & NPU_ST_ERROR) ? NPU_E_HW : NPU_OK;
}

int npu_infer(npu_t *npu, const int8_t x[NPU_N_IN], const int8_t w[NPU_N_CLASS][NPU_N_IN],
              int64_t scores[NPU_N_CLASS], int *class_id)
{
    int t, c, i, rc;
    wr(npu, NPU_STATUS, NPU_ST_DONE | NPU_ST_ERROR);
    wr(npu, NPU_CTRL, NPU_CTRL_START);
    for (t = 0; t < NPU_N_TILE; t++) {
        int base = t * NPU_TILE;
        int len = (t == NPU_N_TILE - 1) ? (NPU_N_IN - base) : NPU_TILE;
        rc = wait_status(npu, NPU_ST_BUSY | NPU_ST_LOAD_READY, NPU_ST_BUSY | NPU_ST_LOAD_READY);
        if (rc != NPU_OK)
            return rc;
        for (c = 0; c < NPU_N_CLASS; c++) {
            wr(npu, NPU_W_CLASS, (uint32_t)c);
            wr(npu, NPU_W_INDEX, 0);
            for (i = 0; i < len; i++)
                wr(npu, NPU_W_DATA, (uint32_t)(int32_t)w[c][base + i]);
        }
        wr(npu, NPU_X_INDEX, 0);
        for (i = 0; i < NPU_TILE; i++)   /* 마지막 타일의 48개는 0으로 채운다(하드웨어가 무시) */
            wr(npu, NPU_X_DATA, (uint32_t)(int32_t)(i < len ? x[base + i] : 0));
        wr(npu, NPU_CTRL, NPU_CTRL_TILE_GO | ((uint32_t)t << 8));
        /* 결과 수락 = X_HELD 해제 */
        rc = wait_status(npu, NPU_ST_X_HELD, 0);
        if (rc != NPU_OK)
            return rc;
    }
    rc = wait_status(npu, NPU_ST_DONE, NPU_ST_DONE);
    if (rc != NPU_OK)
        return rc;
    for (c = 0; c < NPU_N_CLASS; c++) {
        uint32_t lo, hi;
        wr(npu, NPU_SCORE_SEL, (uint32_t)c);
        lo = rd(npu, NPU_SCORE_LO);      /* LO 먼저: HI는 이 순간의 스냅샷 */
        hi = rd(npu, NPU_SCORE_HI);
        scores[c] = (int64_t)(((uint64_t)hi << 32) | lo);
    }
    *class_id = (int)rd(npu, NPU_CLASS);
    return (npu->last_status & NPU_ST_OVF) ? NPU_E_OVERFLOW : NPU_OK;
}

int cpu_infer(const int8_t x[NPU_N_IN], const int8_t w[NPU_N_CLASS][NPU_N_IN],
              const int64_t bias[NPU_N_CLASS], int64_t scores[NPU_N_CLASS])
{
    int c, i, best = 0;
    for (c = 0; c < NPU_N_CLASS; c++) {
        int64_t acc = 0;
        for (i = 0; i < NPU_N_IN; i++)
            acc += (int32_t)x[i] * (int32_t)w[c][i];
        scores[c] = acc + bias[c];
        if (scores[c] > scores[best])   /* 동점은 낮은 번호 */
            best = c;
    }
    return best;
}

#include <stdio.h>
#include <stdlib.h>
#include "npu_driver.h"

static FILE *cmd_fp, *rsp_fp;

void cosim_open(const char *cmd_path, const char *rsp_path)
{
    cmd_fp = fopen(cmd_path, "w");   /* TB가 읽기용으로 먼저 연다 */
    rsp_fp = fopen(rsp_path, "r");
    if (!cmd_fp || !rsp_fp) {
        fprintf(stderr, "cosim: cannot open FIFOs\n");
        exit(2);
    }
}

void cosim_close(void)
{
    fprintf(cmd_fp, "Q\n");
    fflush(cmd_fp);
    fclose(cmd_fp);
    fclose(rsp_fp);
}

void npu_io_write(uintptr_t addr, uint32_t value)
{
    int resp;
    fprintf(cmd_fp, "W %lx %08x\n", (unsigned long)addr, (unsigned)value);
    fflush(cmd_fp);
    if (fscanf(rsp_fp, " B %d", &resp) != 1 || resp != 0) {
        fprintf(stderr, "cosim: bad write response at 0x%lx\n", (unsigned long)addr);
        exit(3);
    }
}

uint32_t npu_io_read(uintptr_t addr)
{
    unsigned v;
    int resp;
    fprintf(cmd_fp, "R %lx\n", (unsigned long)addr);
    fflush(cmd_fp);
    if (fscanf(rsp_fp, " D %x %d", &v, &resp) != 2 || resp != 0) {
        fprintf(stderr, "cosim: bad read response at 0x%lx\n", (unsigned long)addr);
        exit(3);
    }
    return (uint32_t)v;
}

/* (추가) 23장: 같은 MicroBlaze V SoC에서 CPU 정수 추론과 NPU 추론의 클록 수를 AXI Timer로 잰다.
 * 측정 구간
 *   CPU      : cpu_infer() 784×10 MAC + Bias + argmax (22장 드라이버와 같은 C, 소프트웨어 곱셈)
 *   NPU_BIAS : npu_set_bias() (모델 적재 1회분, 추론마다 반복하지 않아도 됨)
 *   NPU      : npu_infer() 타일 13개의 W·X 레지스터 쓰기 + TILE_GO + 폴링 + 점수 읽기(종단간)
 * 결과는 GPIO 데이터 레지스터에 순서대로 쓴다(시뮬레이션 TB가 AXI 쓰기를 기록). 보드용은 UART로도 출력.
 * 순서: 0xBE0C0001, CPU, NPU_BIAS, NPU, cpu_class, npu_class, scores_match, rc, 0xBE0C00FF
 */
#include "xparameters.h"
#include "xil_io.h"
#include "npu_driver.h"
#include "model_data.h"
#include "bench_cfg.h"
#if !BENCH_SIM
#include "xil_printf.h"
#endif

#define TMR   XPAR_AXI_TIMER_0_BASEADDR
#define GPIO  XPAR_AXI_GPIO_0_BASEADDR
#define TCSR0 0x00u
#define TLR0  0x04u
#define TCR0  0x08u

static void tmr_start(void)
{
    Xil_Out32(TMR + TLR0, 0);
    Xil_Out32(TMR + TCSR0, 1u << 5);                 /* LOAD0: TLR0 → TCR0 */
    Xil_Out32(TMR + TCSR0, (1u << 7) | (1u << 4));   /* ENT0 + ARHT0: 위로 세는 자유 카운터 */
}

static uint32_t tmr_now(void) { return Xil_In32(TMR + TCR0); }

static void report(uint32_t v) { Xil_Out32(GPIO, v); }

int main(void)
{
    npu_t npu;
    int64_t cs[NPU_N_CLASS], ns[NPU_N_CLASS];
    int ccls, ncls = -1, rc, c, same = 1;
    uint32_t t0, t_cpu, t_bias, t_npu, t_empty;

    tmr_start();
    report(0xBE0C0001u);
    t0 = tmr_now();
    t_empty = tmr_now() - t0;                        /* 측정 자체 비용 */
    t0 = tmr_now();
    ccls = cpu_infer(sample_x[0], model_w, model_b, cs);
    t_cpu = tmr_now() - t0 - t_empty;
    npu_init(&npu, XPAR_P3_NPU_0_BASEADDR);
    t0 = tmr_now();
    rc = npu_set_bias(&npu, model_b);
    t_bias = tmr_now() - t0 - t_empty;
    t0 = tmr_now();
    rc |= npu_infer(&npu, sample_x[0], model_w, ns, &ncls);
    t_npu = tmr_now() - t0 - t_empty;
    for (c = 0; c < NPU_N_CLASS; c++)
        if (ns[c] != cs[c] || cs[c] != sample_scores[0][c])
            same = 0;
    report(t_cpu);
    report(t_bias);
    report(t_npu);
    report((uint32_t)ccls);
    report((uint32_t)ncls);
    report((uint32_t)same);
    report((uint32_t)rc);
    report(0xBE0C00FFu);
#if !BENCH_SIM
    xil_printf("BENCH cpu_cycles=%u npu_bias_cycles=%u npu_cycles=%u cpu_class=%d npu_class=%d match=%d rc=%d\r\n",
               (unsigned)t_cpu, (unsigned)t_bias, (unsigned)t_npu, ccls, ncls, same, rc);
#endif
    return 0;
}

"""24장: 클록 주기 스윕 결과(배선 후 timing·utilization)를 표로 만든다. 19장 synth_summary의 파서를 재사용한다."""

import re
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parents[3]))
from part03.ch19.reference.synth_summary import timing, util  # noqa: E402

NAMES = {"pe4_int8": "PE4 INT8 코어", "pe4_int16": "PE4 INT16 코어",
         "tile784_int8": "17장 Tile INT8", "axi_npu_int8": "20장 AXI NPU IP"}


def main():
    p = argparse.ArgumentParser()
    p.add_argument("--build", type=Path, required=True)
    p.add_argument("--out", type=Path, required=True)
    a = p.parse_args()
    res = {}
    for d in sorted(a.build.glob("p*_*")):
        period = float(re.match(r"p([0-9.]+)_", d.name).group(1))
        for rt in (d / "rpt").glob("*_route_timing.rpt"):
            key = rt.name[:-len("_route_timing.rpt")]
            (wns, tns, fail), src, dst, dly, lvl = timing(rt.read_text())
            u = (d / "rpt" / f"{key}_route_utilization.rpt").read_text()
            res.setdefault(key, {})[period] = (float(wns), tns, fail, src, dst, util(u, "Slice LUTs"),
                                              util(u, "Slice Registers"))
    lines = ["# 24장 클록 주기 스윕 — OOC 합성·배치·배선 (Vivado 실제 실행)", "",
             "> 합성 단계부터 목표 주기로 제약. Fmax(추정) = 1000 / (주기 − WNS) MHz, 통과한 가장 짧은 주기 기준.",
             "> OOC는 칩 I/O를 포함하지 않는다. 실물 동작 주파수가 아니다.", "",
             "| 구성 | 주기(ns) | WNS(ns) | TNS(ns) | 실패 끝점 | LUT | FF | 임계 경로 |",
             "|---|---:|---:|---:|---:|---:|---:|---|"]
    summary = []
    for key in NAMES:
        best = None
        for period in sorted(res.get(key, {}), reverse=True):
            wns, tns, fail, src, dst, lut, ff = res[key][period]
            lines.append(f"| {NAMES[key]} | {period:.3f} | {wns:+.3f} | {tns} | {fail} | {lut} | {ff} | "
                         f"`{src}` → `{dst}` |")
            if wns >= 0:
                fmax = 1000.0 / (period - wns)
                if best is None or period < best[0]:
                    best = (period, wns, fmax)
        summary.append((key, best))
    lines += ["", "| 구성 | 통과한 가장 짧은 주기 | WNS | Fmax 추정(MHz) |", "|---|---:|---:|---:|"]
    for key, best in summary:
        lines.append(f"| {NAMES[key]} | " + (f"{best[0]:.3f} ns | {best[1]:+.3f} | {best[2]:.1f} |"
                                              if best else "— | — | 통과 없음 |"))
    a.out.write_text("\n".join(lines) + "\n", encoding="utf-8")
    print("SWEEP_SUMMARY " + " ".join(f"{k}={b[2]:.1f}MHz" if b else f"{k}=none" for k, b in summary))


if __name__ == "__main__":
    main()

"""25장: Vivado report_power 결과(vectorless·CPU 구간 SAIF·NPU 구간 SAIF)로 전력·추론당 에너지 표를 만든다.

import re
from pathlib import Path

CLK_NS = 10.0
CYCLES = {"cpu": 1_816_547, "npu": 1_080_161}          # 23장 validation/soc_bench_sim.log
CELLS = ("p3_npu_0", "microblaze_riscv_0", "axi_smc", "microblaze_riscv_0_local_memory")


def num(text, label):
    m = re.search(r"\|\s*" + re.escape(label) + r"\s*\|\s*([0-9.]+)", text)
    return float(m.group(1)) if m else None


def cell_power(text, cell):
    m = re.search(r"^\|\s+" + re.escape(cell) + r"\s+\|\s*([0-9.<]+)", text, re.M)
    return m.group(1) if m else "?"


def confidence(text):
    m = re.search(r"\|\s*Confidence Level\s*\|\s*(\w+)", text)
    return m.group(1) if m else "?"


def main():
    p = argparse.ArgumentParser()
    p.add_argument("--rpt", type=Path, required=True)
    p.add_argument("--out", type=Path, required=True)
    a = p.parse_args()

    for mode, title in (("vectorless", "기본 토글률(vectorless)"), ("cpu", "CPU 추론 구간 SAIF"),

        if not f.exists():

        rows.append(f"| {title} | {tot:.3f} | {dyn:.3f} | {sta:.3f} | {cell_power(t, 'p3_npu_0')} | "

             "|---|---:|---:|---:|---:|"]
    for mode, sec, tot, dyn in energy:

                 if re.search(r"matched|annotated|SAIF", l, re.I) and "INFO" in l][:6]

step() {  # name level_needed command...
  local name=$1 need=$2; shift 2
  local order="sim pc fpga full"
  if [[ " ${order%%$level*}$level " != *" $need "* && $need != sim ]]; then
    rows+=("| $name | NOT_RUN (LEVEL=$level) |"); echo "NOT_RUN $name"; return
