UART 계산기 → 4뉴런 NPU → 손글씨 분류 → 784 가속기 → MicroBlaze V SoC → 응용

00교육과정 개요

Basys3 보드 하나로 작은 NPU를 처음부터 만들어 보는 과정입니다. 곱셈기 하나에서 출발해 4뉴런 추론, 손글씨 숫자 분류, MicroBlaze V SoC와 응용까지 차례로 쌓아 갑니다.

장 하나가 프로젝트 하나입니다. 장마다 보드 Top 하나를 조금씩 키워 가고, 서브젝트를 끝낼 때마다 보드에서 확인한 뒤 장 끝에서 전체를 시연합니다.

장프로젝트기간장 시연 (보드)
1장UART 계산기1일PC에서 두 수를 보내면 보드가 곱해서 누산하고, 결과를 UART·LED·7세그먼트로 돌려줍니다. 스위치로 곱셈 코어를 바꿔도 값은 같고 응답 지연만 달라집니다.
2장4뉴런 NPU 보드2일PC가 입력과 가중치를 보내면 보드가 뉴런 4개짜리 추론을 하고, UART로 점수를, LED와 7세그먼트로 클래스를 보여 줍니다. 두 가지 엔진을 스위치로 바꿔 가며 같은 클래스가 나오는지도 확인합니다.
3장8×8 MNIST (CPU 없음)2일PC가 MNIST 시험 숫자를 8×8로 줄여 보내면, 보드가 CPU 없이 4PE 코어만으로 0~9를 고릅니다. UART로 은닉값과 점수가, LED와 7세그먼트로 클래스가 나옵니다.
4장784 가속기 설계 공간1일PC가 28×28 원본 손글씨를 타일 13개로 나눠 보내면, 보드가 3장 코어로 784개 입력을 누산해 분류합니다. 같은 그림이 INT8에서는 4, INT16에서는 정답 9로 갈리고, 1PE·4PE·8PE의 클록 수를 보드에서 직접 읽습니다.
5장MicroBlaze V SoC2일비트스트림 하나에 MicroBlaze V와 NPU가 함께 들어갑니다. C 드라이버가 그림 4장을 NPU로 분류해 UART·LED·7세그먼트에 띄웁니다. 같은 추론이 CPU만으로는 1,816,547클록, NPU로는 1,080,161클록 걸립니다.
6장응용 확장2일5장 비트스트림에 프로그램만 바꿔 올립니다. PC가 보낸 28×28 손글씨를 NPU가 분류해 7세그먼트·LED에 띄우고(6-1), 고른 응용 2개를 같은 방식으로 시연합니다.

01진행 방법

모든 장이 같은 순서로 진행됩니다. 서브젝트마다 아래 네 단계를 반복합니다.

  1. 코드 작성 — 서브젝트 절의 '작성할 코드'를 경로 그대로 입력합니다.
  2. 시뮬레이션 — 그 서브젝트까지 넣은 장 Top을 시뮬레이션합니다. 보드에 보낼 명령을 그대로 넣고 응답을 비교합니다.
  3. 비트스트림 — 같은 단계의 비트스트림을 만들어 보드에 내려받습니다.
  4. 보드 확인 — PC에서 명령을 보내고, UART 응답과 LED·7세그먼트를 안내서의 표와 비교합니다.
터미널 · 저장소 루트 (1장 두 번째 서브젝트의 예)
bash p01/scripts/run_sim.sh 2                                                  # 시뮬레이션
vivado -mode batch -nojournal -source p01/vivado/build_p01.tcl -tclargs 2      # 비트스트림
python3 p01/host/p01_send.py <포트> M 3 4                                      # 보드로 명령 보내기

5장과 6장은 MicroBlaze V가 들어가므로, 비트스트림을 한 번 만든 뒤에는 프로그램(ELF)만 바꿔 가며 확인합니다.

02준비물

  • Digilent Basys3 보드와 USB 케이블 하나 (전원·JTAG·UART 겸용)
  • Vivado 2024.2 — 합성, 시뮬레이션, 비트스트림. 5·6장은 Vitis 2024.2도 씁니다.
  • python3와 pyserial — PC에서 보드로 명령을 보냅니다 (pip install pyserial).
  • 시리얼 설정은 115200 bps, 8N1입니다.
