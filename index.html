00교육과정 개요

이 교재는 Yuul-Jung/amd_soc_rtl 제3부를 기반으로 고도화한 독립 NPU 교육과정입니다. 00~12장에서 MAC·DSP·BRAM·4PE·UART 기반 소형 4분류 NPU를 단계별로 제작합니다. 13~19장에서는 8×8 입력의 10분류 정수 MLP를 구현하고, 20~27장에서는 AXI4-Lite·MicroBlaze V SoC로 통합하며, 28~31장에서는 숫자 인식·센서 융합·모터 제어·보안 UART 종합 과제로 마무리합니다.

고도화 내용: ch00~12 HTML v04 개선 · ch13~31 HTML v02 + RTL 신규 구현 · 장별 CI 게이트.

02실행 절차

ch00~12 RTL은 Icarus Verilog로 로컬 시뮬레이션 가능합니다. ch13~19 정수 기준모델은 Python 3으로 독립 실행합니다. Vivado 합성·Basys3 실물 검증은 각 장의 절차를 따릅니다.

Ubuntu Terminal · 실행 순서
# ch00 UART Echo
bash ch00/scripts/run_sim.sh
# ch01~ch10 독립 RTL 회귀
bash mini_npu/scripts/run_batch_00_12.sh
# ch11+ch12 통합 NPU (UART→Engine→LED)
bash mini_npu/scripts/run_demo.sh
# ch13~ch19 정수 기준 모델
python3 host_tools/p3_integer_reference.py
# 적대적 경계 시험
bash mini_npu/scripts/run_adversarial.sh
# 정적 검사 (HTML·링크·SHA)
python3 tools/check_static.py

03설계 경계 · 검증 원칙

아래 설계 경계는 amd_soc_rtl 적대적 검증에서 확정한 사항입니다.

  • 4분류 ≠ 10분류. npu_engine4.v는 4뉴런·최대 64원소 입력 전용. 14장 10분류는 3그룹 실행·누산·클래스 매핑을 별도 설계해야 한다.
  • 64입력 ≠ 784픽셀. 8×8 입력은 다운샘플 64차원. 784 원본은 13개 타일(64×12+16)로 분할 누산.
  • INT8/INT16 계약. Python round_shift_away·sat_int8와 RTL 출력을 대조. float 모델 출력과 자동 일치한다고 가정하지 않는다.
  • AXI4-Lite. START/STATUS/LENGTH/CLASS 소규모 레지스터 중심. 대량 데이터는 BRAM·버스 대역폭을 별도 확인.
  • Basys3 자원 한계. XC7A35T DSP/LUT/BRAM은 Vivado 보고서로 확인. 무조건 온칩에 올리지 않는다.
  • 게이트 구분. HTML_PASS / HOST_MODEL_PASS / RTL_SIM_PASS / SYNTH_TIMING_PASS / BOARD_PASS는 서로 대체할 수 없다.
