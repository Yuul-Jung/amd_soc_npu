- **사본 기준 커밋:** [`d1b8278d41fca8f5e3960736f3ac9d377e462fda`](https://github.com/Yuul-Jung/rule_md/commit/d1b8278d41fca8f5e3960736f3ac9d377e462fda)

- **사본 종류:** 에이전트와 교재 제작에 적용하는 Markdown 정책·규칙 파일
- **운영 원칙:** 정본 `rule_md`가 우선이며, 이곳은 로컬/병렬 작업 접근을 위한 고정 스냅샷이다.
- **업데이트 절차:** 원본 커밋 확인 → 변경 내용 비교 → 관련 정책 파일만 동기화 → 버전·검증 기록 갱신
- **변경 금지:** 사본의 규칙을 독자적으로 수정하여 정본과 갈라지게 만들지 않는다.
- **범위:** HTML 템플릿의 이미지·CSS·JS 및 예제 콘텐츠는 정책 사본에 포함하지 않는다. HTML 제작 시에는 원본 자산과 이미 검증된 프로젝트 디자인을 별도로 확인한다.

## 우선순위

1. 안전, 개인정보 비공개, 실제 기술 검증 증거
2. `web/education-html/STANDARD.md` (확정된 학습안내서 기본 규칙)
3. `code/code-development-rules.md` 및 `code/methodology-policy.md` (점진적 추가 규칙)
4. 공통 코드·도식·FPGA SoC·VS Code 규칙

서로 다른 규칙이 기술적 사실과 충돌하면 실제 코드·공식 문서·검증 증거를 우선한다.
