제2장 · 4뉴런 NPU 보드

BRAM, 양자화, 내적, 4PE, Dense, Core를 차례로 쌓아 보드에서 4뉴런 추론을 완성합니다.

00 이 장에서 만드는 것

1장의 MAC 하나를 뉴런 4개짜리 작은 신경망 층으로 키웁니다. 뉴런 하나는 입력 벡터 X와 가중치 벡터 W를 원소끼리 곱해 모두 더한 값(내적)에 Bias를 더하고, 음수를 0으로 자르는 ReLU를 거쳐 출력을 냅니다.

그러려면 X와 W를 담아 둘 메모리(BRAM), 큰 값을 정해진 비트 폭으로 줄이는 양자화, 내적, 뉴런 4개를 한꺼번에 계산하는 병렬 구조가 차례로 필요합니다. 서브젝트마다 부품 하나를 더하고 UART 명령 하나로 그 부품만 확인하며 쌓아 올립니다. 마지막에는 PC가 모델을 통째로 싣고 추론을 시키는 완성된 NPU가 됩니다.

장 끝에서 보드로 보여 줄 것: PC가 입력과 가중치를 보내면 보드가 뉴런 4개짜리 추론을 하고, UART로 점수를, LED와 7세그먼트로 클래스를 보여 줍니다. 두 가지 엔진을 스위치로 바꿔 가며 같은 클래스가 나오는지도 확인합니다.

2일 과정입니다. 아래 서브젝트 8개를 차례로 끝내며 그때마다 보드에서 확인하고, 마지막에 장 전체를 시연합니다.

  1. 2-1BRAM 동기 버퍼
    X·W로 쓴 값을 x·w로 되읽으면 같은 값이 나옵니다(X:0003, X:FFFE, W:0005). 범위를 벗어난 주소 64는 ERR입니다.    1일 오전
  2. 2-2고정소수점 양자화
    32비트 값을 8비트로 줄입니다. 768은 03, 384는 256으로 나누면 1.5이므로 반올림되어 02, 65536은 최댓값 7F로 막히고 넘침 표시 O:1이 붙습니다.    1일 오전
  3. 2-3벡터 내적
    X=(1,2,3,4)와 W0=(5,6,7,8)의 내적은 D:0000000046(70)입니다. W0[3]을 −8로 바꾸면 6이 되고, 길이 0을 주면 ERR입니다.    1일 오후
  4. 2-44PE 병렬 어레이
    같은 X에 대해 W0~W3 네 개의 내적을 한 번에 계산합니다. P: 뒤에 6, 10, −10(…FFF6), 8이 나옵니다.    1일 오후
  5. 2-5Dense 4뉴런 레이어
    Bias를 더하고 ReLU와 16비트 포화를 거칩니다. L:0006,0000,005A,7FFF O:8에서 음수는 0이 되고, 65544는 7FFF로 막히며 넘침이 표시됩니다.    2일 오전
  6. 2-64뉴런 NPU Core
    npu_core가 자기 BRAM에서 값을 읽어 같은 Dense 계산을 합니다. N 4의 답은 L 4와 같고, 길이 2에서는 0011,0000,0061,7FFF입니다.    2일 오전
  7. 2-7UART 모델 적재
    sw2를 올리면 명령 해석기가 UART를 받습니다. 숫자 0~3을 보내면 C0~C3이 돌아옵니다. sw2를 내리고 x 0을 보내면 X:FFFF가 나와, 명령 해석기가 쓴 값을 콘솔로 확인할 수 있습니다.    2일 오후
  8. 2-8통합 NPU Top
    sw3을 올리면 통합 엔진으로 바뀝니다. 같은 그룹에서 음수 점수(…FFE, ReLU 없음)가 보이지만 클래스는 같습니다. LED0~3과 7세그먼트에 클래스가, LED14에 끝남 표시가 나옵니다.    2일 오후
  9. 시연장 시연
    PC가 입력과 가중치를 보내면 보드가 뉴런 4개짜리 추론을 하고, UART로 점수를, LED와 7세그먼트로 클래스를 보여 줍니다. 두 가지 엔진을 스위치로 바꿔 가며 같은 클래스가 나오는지도 확인합니다.    장 끝

02 준비

  1. VS Code에서 저장소 루트(amd_soc_npu/)를 엽니다. 필요한 도구는 Vivado 2024.2(합성·시뮬레이션), python3, 그리고 PC에서 보드로 명령을 보낼 pyserial(pip install pyserial)입니다. 터미널에서 Vivado 명령이 잡히도록 settings64.sh를 먼저 불러옵니다.
  2. 코드는 저장소에 모두 들어 있고, 안내서에도 전체를 실었습니다. 직접 입력하며 따라 해도 되고, 읽고 실행만 해도 됩니다. 아래는 장 전체의 틀이 되는 뼈대 파일이고, 서브젝트 모듈은 각 서브젝트 절에 있습니다.
  3. 파일 경로의 ch01, part03/ch14 같은 폴더는 모듈별 작업 폴더 이름입니다. 이 안내서의 장·서브젝트 번호와는 관계가 없으므로 경로 그대로 쓰면 됩니다.
  4. <포트>는 보드의 USB 시리얼 포트 이름입니다. Windows는 COM3, Linux는 /dev/ttyUSB1 같은 이름이고, 통신 설정은 115200 bps 8N1입니다.
  5. sw2는 UART를 누가 받는지(0 = 디버그 콘솔, 1 = 2-7 명령 해석기), sw3은 엔진(0 = 2-6 npu_core, 1 = 2-8 통합 엔진)을 고릅니다. 스위치는 명령과 명령 사이에 바꿉니다.
  6. STAGE는 끝낸 서브젝트 수입니다. 2-1만 끝냈으면 1, 2-8까지 끝냈으면 8입니다. 아직 작성하지 않은 모듈은 빌드에 들어가지 않으므로, 서브젝트를 하나 끝낼 때마다 바로 보드에 올려 볼 수 있습니다.

p02/rtl/p02_console.v · verilog
// 2장 디버그 콘솔: 서브젝트 모듈을 UART 명령 하나씩으로 확인한다. 명령 해석기와 같은 형식
// (1바이트 명령 + 바이너리 페이로드, 빅엔디언, stop-and-wait). X·W·B·S는 명령 해석기와 바이트까지 같다.
//
//   명령 페이로드              응답                                   서브젝트 (STAGE)
//   S    없음                  "I"                                    모두
//   X    addr hi lo            "OK"                                   2-1 (1)
//   W    n addr hi lo          "OK"                                   2-1 (1)
//   x    addr                  "X:" 16진수 4자리                       2-1 (1)
//   w    n addr                "W:" 16진수 4자리                       2-1 (1)
//   Q    int32 4바이트          "Q:" 2자리 " O:" 넘침 1자리             2-2 (2)  (32→8비트, SHIFT 8, 반올림, 포화)
//   D    len                   "D:" 10자리                            2-3 (3)  X·W0
//   P    len                   "P:" 10자리 ×4 (쉼표)                   2-4 (4)  X·W0~W3
//   B    n b4..b0 (signed40)    "OK"                                   2-5 (5)
//   L    len                   "L:" 4자리 ×4 " O:" 넘침 1자리          2-5 (5)  Dense(+Bias, ReLU, 16비트)
//   N    len                   "N:" 4자리 ×4 " O:" 넘침 1자리          2-6 (6)  npu_core (BRAM + Dense)
//   그 밖 (CR·LF 제외)          "?"         필드 범위 밖           "ERR"   (응답 끝은 모두 \r\n)
// len은 1~64, addr 0~63, n 0~3. view_o는 마지막 결과의 아래 16비트 (LED·7세그먼트용).
`timescale 1ns/1ps
`default_nettype none
module p02_console #(
    parameter integer STAGE = 8
) (
    input  wire               clk,
    input  wire               resetn,
    input  wire [7:0]         rx_data_i,
    input  wire               rx_valid_i,
    output wire               rx_ready_o,
    output reg  [7:0]         tx_data_o,
    output reg                tx_valid_o,
    input  wire               tx_ready_i,
    // 묶음으로
    output reg  [3:0]         op_o,
    output reg                op_valid_o,
    output reg  [5:0]         addr_o,
    output reg  [1:0]         neuron_o,
    output reg  signed [15:0] data_o,
    output reg  signed [39:0] bias_o,
    output reg  signed [31:0] qin_o,
    output reg  [6:0]         len_o,
    input  wire               op_done_i,
    input  wire               op_error_i,
    input  wire [159:0]       res_i,
    input  wire [3:0]         flags_i,
    output reg  [15:0]        view_o
);
    localparam [3:0] OP_XWR = 4'd1, OP_WWR = 4'd2, OP_BWR = 4'd3, OP_XRD = 4'd4, OP_WRD = 4'd5,
                     OP_QNT = 4'd6, OP_DOT = 4'd7, OP_PE4 = 4'd8, OP_DENSE = 4'd9, OP_CORE = 4'd10;
    localparam [2:0] S_IDLE = 3'd0, S_RECV = 3'd1, S_ISSUE = 3'd2, S_WAIT = 3'd3, S_LOAD = 3'd4, S_SEND = 3'd5;
    localparam integer MSG_MAX = 48;

    reg [2:0] state;
    reg [7:0] opc;
    reg [7:0] pl [0:5];
    reg [2:0] need, got;
    reg [7:0] msg [0:MSG_MAX-1];
    reg [5:0] msg_len, idx;
    integer   i, k, p;

    function [7:0] hex(input [3:0] n);
        hex = (n < 4'd10) ? (8'h30 + {4'd0, n}) : (8'h37 + {4'd0, n});
    endfunction

    // 명령 → 페이로드 수. 이 STAGE에 없는 명령은 7 (= 모름)
    function [2:0] plen(input [7:0] c);
        case (c)
            "S":      plen = 3'd0;
            "X":      plen = 3'd3;
            "W":      plen = 3'd4;
            "x":      plen = 3'd1;
            "w":      plen = 3'd2;
            "Q":      plen = (STAGE >= 2) ? 3'd4 : 3'd7;
            "D":      plen = (STAGE >= 3) ? 3'd1 : 3'd7;
            "P":      plen = (STAGE >= 4) ? 3'd1 : 3'd7;
            "B":      plen = (STAGE >= 5) ? 3'd6 : 3'd7;
            "L":      plen = (STAGE >= 5) ? 3'd1 : 3'd7;
            "N":      plen = (STAGE >= 6) ? 3'd1 : 3'd7;
            default:  plen = 3'd7;
        endcase
    endfunction

    wire fields_ok =
        (opc == "X" || opc == "x") ? (pl[0] < 8'd64) :
        (opc == "W" || opc == "w") ? (pl[0] < 8'd4 && pl[1] < 8'd64) :
        (opc == "B")               ? (pl[0] < 8'd4) :
        (opc == "D" || opc == "P" || opc == "L" || opc == "N") ? (pl[0] >= 8'd1 && pl[0] <= 8'd64) : 1'b1;

    assign rx_ready_o = (state == S_IDLE) || (state == S_RECV);
    wire rx_take = rx_valid_i && rx_ready_o;

    always @(posedge clk) begin
        if (!resetn) begin
            state <= S_IDLE; opc <= 8'd0; need <= 3'd0; got <= 3'd0; msg_len <= 6'd0; idx <= 6'd0;
            tx_data_o <= 8'd0; tx_valid_o <= 1'b0; op_o <= 4'd0; op_valid_o <= 1'b0;
            addr_o <= 6'd0; neuron_o <= 2'd0; data_o <= 16'sd0; bias_o <= 40'sd0; qin_o <= 32'sd0; len_o <= 7'd0;
            view_o <= 16'd0;
        end else begin
            op_valid_o <= 1'b0;
            case (state)
                S_IDLE: if (rx_take && rx_data_i != 8'h0D && rx_data_i != 8'h0A) begin
                    opc <= rx_data_i; got <= 3'd0; need <= plen(rx_data_i);
                    if (plen(rx_data_i) == 3'd7) begin
                        msg[0] <= "?"; msg[1] <= 8'h0D; msg[2] <= 8'h0A; msg_len <= 6'd3; state <= S_LOAD;
                    end else if (rx_data_i == "S") begin
                        msg[0] <= "I"; msg[1] <= 8'h0D; msg[2] <= 8'h0A; msg_len <= 6'd3; state <= S_LOAD;
                    end else begin
                        state <= S_RECV;
                    end
                end
                S_RECV: if (rx_take) begin
                    pl[got] <= rx_data_i;
                    if (got + 3'd1 == need) state <= S_ISSUE;
                    else got <= got + 3'd1;
                end
                S_ISSUE: begin
                    if (!fields_ok) begin
                        msg[0] <= "E"; msg[1] <= "R"; msg[2] <= "R"; msg[3] <= 8'h0D; msg[4] <= 8'h0A;
                        msg_len <= 6'd5; state <= S_LOAD;
                    end else begin
                        case (opc)
                            "X": begin op_o <= OP_XWR; addr_o <= pl[0][5:0]; data_o <= {pl[1], pl[2]}; end
                            "W": begin op_o <= OP_WWR; neuron_o <= pl[0][1:0]; addr_o <= pl[1][5:0]; data_o <= {pl[2], pl[3]}; end
                            "x": begin op_o <= OP_XRD; addr_o <= pl[0][5:0]; end
                            "w": begin op_o <= OP_WRD; neuron_o <= pl[0][1:0]; addr_o <= pl[1][5:0]; end
                            "Q": begin op_o <= OP_QNT; qin_o <= {pl[0], pl[1], pl[2], pl[3]}; end
                            "D": begin op_o <= OP_DOT; len_o <= pl[0][6:0]; end
                            "P": begin op_o <= OP_PE4; len_o <= pl[0][6:0]; end
                            "B": begin op_o <= OP_BWR; neuron_o <= pl[0][1:0]; bias_o <= {pl[1], pl[2], pl[3], pl[4], pl[5]}; end
                            "L": begin op_o <= OP_DENSE; len_o <= pl[0][6:0]; end
                            default: begin op_o <= OP_CORE; len_o <= pl[0][6:0]; end   // "N"
                        endcase
                        op_valid_o <= 1'b1;
                        state <= S_WAIT;
                    end
                end
                S_WAIT: if (op_done_i) begin
                    if (op_error_i) begin
                        msg[0] <= "E"; msg[1] <= "R"; msg[2] <= "R"; msg[3] <= 8'h0D; msg[4] <= 8'h0A; msg_len <= 6'd5;
                    end else begin
                        case (opc)
                            "X", "W", "B": begin
                                msg[0] <= "O"; msg[1] <= "K"; msg[2] <= 8'h0D; msg[3] <= 8'h0A; msg_len <= 6'd4;
                            end
                            "x", "w": begin
                                msg[0] <= (opc == "x") ? "X" : "W"; msg[1] <= ":";
                                for (k = 0; k < 4; k = k + 1) msg[2 + k] <= hex(res_i[4*(3-k) +: 4]);
                                msg[6] <= 8'h0D; msg[7] <= 8'h0A; msg_len <= 6'd8;
                                view_o <= res_i[15:0];
                            end
                            "Q": begin
                                msg[0] <= "Q"; msg[1] <= ":"; msg[2] <= hex(res_i[7:4]); msg[3] <= hex(res_i[3:0]);
                                msg[4] <= " "; msg[5] <= "O"; msg[6] <= ":"; msg[7] <= hex(flags_i);
                                msg[8] <= 8'h0D; msg[9] <= 8'h0A; msg_len <= 6'd10;
                                view_o <= {{8{res_i[7]}}, res_i[7:0]};
                            end
                            "D": begin
                                msg[0] <= "D"; msg[1] <= ":";
                                for (k = 0; k < 10; k = k + 1) msg[2 + k] <= hex(res_i[4*(9-k) +: 4]);
                                msg[12] <= 8'h0D; msg[13] <= 8'h0A; msg_len <= 6'd14;
                                view_o <= res_i[15:0];
                            end
                            "P": begin
                                msg[0] <= "P"; msg[1] <= ":";
                                for (p = 0; p < 4; p = p + 1) begin
                                    for (k = 0; k < 10; k = k + 1) msg[2 + 11*p + k] <= hex(res_i[40*p + 4*(9-k) +: 4]);
                                    if (p < 3) msg[12 + 11*p] <= ",";
                                end
                                msg[45] <= 8'h0D; msg[46] <= 8'h0A; msg_len <= 6'd47;
                                view_o <= res_i[15:0];
                            end
                            default: begin                       // "L", "N"
                                msg[0] <= opc; msg[1] <= ":";
                                for (p = 0; p < 4; p = p + 1) begin
                                    for (k = 0; k < 4; k = k + 1) msg[2 + 5*p + k] <= hex(res_i[16*p + 4*(3-k) +: 4]);
                                    if (p < 3) msg[6 + 5*p] <= ",";
                                end
                                msg[21] <= " "; msg[22] <= "O"; msg[23] <= ":"; msg[24] <= hex(flags_i);
                                msg[25] <= 8'h0D; msg[26] <= 8'h0A; msg_len <= 6'd27;
                                view_o <= res_i[15:0];
                            end
                        endcase
                    end
                    state <= S_LOAD;
                end
                S_LOAD: begin
                    tx_data_o <= msg[0]; tx_valid_o <= 1'b1; idx <= 6'd0; state <= S_SEND;
                end
                S_SEND: if (tx_valid_o && tx_ready_i) begin
                    if (idx + 6'd1 == msg_len) begin
                        tx_valid_o <= 1'b0; state <= S_IDLE;
                    end else begin
                        tx_data_o <= msg[idx + 6'd1]; idx <= idx + 6'd1;
                    end
                end
                default: state <= S_IDLE;
            endcase
        end
    end

// 2장 NPU 묶음: 서브젝트 모듈을 STAGE(끝낸 서브젝트 수)만큼 실제로 쌓는다.
//   2-1 (STAGE>=1) bram_sync_buffer 5개: X[64], W0~W3[64]       → 명령 x·w 되읽기
//   2-2 (STAGE>=2) fixed_quantizer 32→8비트, SHIFT 8             → 명령 Q
//   2-3 (STAGE>=3) vector_dot_core: X·W0 (안에 1-2 mac_core)       → 명령 D
//   2-4 (STAGE>=4) pe_array4: X·W0~W3 (안에 2-3 내적 4개)          → 명령 P
//   2-5 (STAGE>=5) dense_layer4: + Bias, ReLU, 16비트 양자화       → 명령 L
//   2-6 (STAGE>=6) npu_core: 자체 BRAM + Dense                    → 명령 N
//   2-7 (STAGE>=7) 엔진 포트: 명령 해석기가 npu_core를 통합 엔진처럼 쓴다 (점수 41비트 확장, argmax)
// D·P·L은 묶음의 BRAM에서 한 원소씩 읽어 각 모듈의 ready/valid로 넣는다. npu_core는 자체 BRAM을 쓰므로
// X·W 쓰기는 묶음 BRAM과 npu_core에 같이 들어간다. Bias는 묶음 레지스터 4개.
`timescale 1ns/1ps
`default_nettype none
module p02_bank #(
    parameter integer STAGE = 8
) (
    input  wire               clk,
    input  wire               resetn,
    // 디버그 콘솔 쪽
    input  wire [3:0]         op_i,          // OP_* (아래)
    input  wire               op_valid_i,    // 1클록
    input  wire [5:0]         addr_i,
    input  wire [1:0]         neuron_i,
    input  wire signed [15:0] data_i,
    input  wire signed [39:0] bias_i,
    input  wire signed [31:0] qin_i,
    input  wire [6:0]         len_i,
    output reg                op_done_o,     // 1클록. 이 클록에 res_o·flags_o 유효
    output reg                op_error_o,
    output reg  [159:0]       res_o,
    output reg  [3:0]         flags_o,
    // 엔진 포트 (명령 해석기, STAGE>=7). owner = 1이면 메모리 쓰기·코어 실행을 엔진 포트가 가진다
    input  wire               owner_engine_i,
    input  wire               e_start_i,
    input  wire [6:0]         e_length_i,
    input  wire               e_x_wr_i,
    input  wire               e_w_wr_i,
    input  wire               e_b_wr_i,
    input  wire [5:0]         e_addr_i,
    input  wire [1:0]         e_neuron_i,
    input  wire signed [15:0] e_data_i,
    input  wire signed [39:0] e_bias_i,
    output wire               e_load_ready_o,
    output wire               e_busy_o,
    output wire               e_done_o,
    output wire               e_error_o,
    output wire [1:0]         e_class_o,
    output wire [163:0]       e_scores_o
);
    localparam [3:0] OP_XWR = 4'd1, OP_WWR = 4'd2, OP_BWR = 4'd3, OP_XRD = 4'd4, OP_WRD = 4'd5,
                     OP_QNT = 4'd6, OP_DOT = 4'd7, OP_PE4 = 4'd8, OP_DENSE = 4'd9, OP_CORE = 4'd10;

    // ---------------- 쓰기 경로: 콘솔 또는 엔진 포트 ----------------
    wire               eng = (STAGE >= 7) && owner_engine_i;
    wire               x_we = eng ? e_x_wr_i : (op_valid_i && op_i == OP_XWR);
    wire               w_we = eng ? e_w_wr_i : (op_valid_i && op_i == OP_WWR);
    wire               b_we = eng ? e_b_wr_i : (op_valid_i && op_i == OP_BWR);
    wire [5:0]         w_addr = eng ? e_addr_i : addr_i;
    wire [1:0]         w_neur = eng ? e_neuron_i : neuron_i;
    wire signed [15:0] w_data = eng ? e_data_i : data_i;
    wire signed [39:0] w_bias = eng ? e_bias_i : bias_i;

    reg  [159:0] biases;                          // {b3,b2,b1,b0}
    always @(posedge clk) begin
        if (!resetn)  biases <= 160'd0;
        else if (b_we) biases[w_neur*40 +: 40] <= w_bias;
    end

    // ---------------- 2-1: BRAM 5개 ----------------
    reg         rd_en;
    reg  [5:0]  rd_addr;
    wire signed [15:0] x_rd;
    wire [63:0] w_rd;
    wire        x_rv;
    wire [3:0]  w_rv;
    bram_sync_buffer #(.DATA_WIDTH(16), .ADDR_WIDTH(6)) u_xmem (
        .clk(clk), .resetn(resetn), .wr_en(x_we), .rd_en(rd_en), .wr_addr(w_addr), .rd_addr(rd_addr),
        .wr_data(w_data), .rd_data(x_rd), .rd_valid(x_rv));
    genvar g;
    generate for (g = 0; g < 4; g = g + 1) begin : g_wmem
        bram_sync_buffer #(.DATA_WIDTH(16), .ADDR_WIDTH(6)) u_wmem (
            .clk(clk), .resetn(resetn), .wr_en(w_we && w_neur == g), .rd_en(rd_en), .wr_addr(w_addr),
            .rd_addr(rd_addr), .wr_data(w_data), .rd_data(w_rd[g*16 +: 16]), .rd_valid(w_rv[g]));
    end endgenerate

    // ---------------- 2-2: 양자화기 ----------------
    reg               q_valid;
    wire signed [7:0] q_out;
    wire              q_ov, q_done;
    generate if (STAGE >= 2) begin : g_quant
        fixed_quantizer #(.IN_WIDTH(32), .OUT_WIDTH(8), .SHIFT(8), .ROUND(1), .SATURATE(1)) u_q (
            .clk(clk), .resetn(resetn), .valid_i(q_valid), .x_i(qin_i), .q_o(q_out), .valid_o(q_done), .overflow_o(q_ov));
    end else begin : g_no_quant
        assign q_out = 8'sd0; assign q_ov = 1'b0; assign q_done = 1'b0;
    end endgenerate

    // ---------------- 2-3·2-4·2-5: 한 원소씩 넣는 순서기 ----------------
    reg  [3:0]  seq_op;                           // OP_DOT / OP_PE4 / OP_DENSE
    reg         start;                            // 1클록
    reg  [8:0]  length;
    reg         push;                             // 원소 하나를 내놓은 상태
    reg  signed [15:0] x_q;
    reg  [63:0] w_q;

    wire        dot_ready, dot_done, dot_err;
    wire signed [39:0] dot_res;
    generate if (STAGE >= 3) begin : g_dot
        vector_dot_core #(.DATA_WIDTH(16), .ACC_WIDTH(40)) u_dot (
            .clk(clk), .resetn(resetn), .start_i(start && seq_op == OP_DOT), .valid_i(push && seq_op == OP_DOT),
            .length_i(length), .a_i(x_q), .b_i(w_q[15:0]), .ready_o(dot_ready), .busy_o(), .done_o(dot_done),
            .error_o(dot_err), .result_o(dot_res));
    end else begin : g_no_dot
        assign dot_ready = 1'b0; assign dot_done = 1'b0; assign dot_err = 1'b0; assign dot_res = 40'sd0;
    end endgenerate

    wire [3:0]   pe_ready;
    wire         pe_done, pe_err;
    wire [159:0] pe_res;
    generate if (STAGE >= 4) begin : g_pe
        pe_array4 #(.DATA_WIDTH(16), .ACC_WIDTH(40)) u_pe (
            .clk(clk), .resetn(resetn), .start_i(start && seq_op == OP_PE4), .length_i(length),
            .valid_i({4{push && seq_op == OP_PE4 && (&pe_ready)}}), .a_i({4{x_q}}), .b_i(w_q),
            .ready_o(pe_ready), .busy_o(), .done_o(pe_done), .error_o(pe_err), .pe_results_o(pe_res), .sum_o());
    end else begin : g_no_pe
        assign pe_ready = 4'd0; assign pe_done = 1'b0; assign pe_err = 1'b0; assign pe_res = 160'd0;
    end endgenerate

    wire        dn_ready, dn_done, dn_err;
    wire [63:0] dn_res;
    wire [3:0]  dn_ov;
    generate if (STAGE >= 5) begin : g_dense
        dense_layer4 #(.DATA_WIDTH(16), .ACC_WIDTH(40), .SHIFT(0)) u_dense (
            .clk(clk), .resetn(resetn), .start_i(start && seq_op == OP_DENSE), .valid_i(push && seq_op == OP_DENSE),
            .length_i(length), .x_i(x_q), .weights_i(w_q), .biases_i(biases), .ready_o(dn_ready), .busy_o(),
            .done_o(dn_done), .error_o(dn_err), .result_o(dn_res), .overflow_o(dn_ov));
    end else begin : g_no_dense
        assign dn_ready = 1'b0; assign dn_done = 1'b0; assign dn_err = 1'b0; assign dn_res = 64'd0; assign dn_ov = 4'd0;
    end endgenerate

    wire seq_ready = (seq_op == OP_DOT) ? dot_ready : (seq_op == OP_PE4) ? (&pe_ready) : dn_ready;
    wire seq_done  = (seq_op == OP_DOT) ? dot_done  : (seq_op == OP_PE4) ? pe_done      : dn_done;
    wire seq_err   = (seq_op == OP_DOT) ? dot_err   : (seq_op == OP_PE4) ? pe_err       : dn_err;

    // ---------------- 2-6: npu_core (자체 BRAM) ----------------
    reg         core_start_c;                     // 콘솔이 시작
    reg         eng_run;                          // 지금 실행이 엔진 포트 것
    wire        core_start = core_start_c || (eng && e_start_i);
    wire [8:0]  core_len = (eng && e_start_i) ? {2'b00, e_length_i} : {2'b00, len_i};
    wire        core_load_ready, core_busy, core_done, core_err;
    wire [63:0] core_res;
    wire [3:0]  core_ov;
    generate if (STAGE >= 6) begin : g_core
        npu_core #(.DATA_WIDTH(16), .ACC_WIDTH(40)) u_core (
            .clk(clk), .resetn(resetn), .start_i(core_start), .length_i(core_len), .biases_i(biases),
            .x_wr_en(x_we), .w_wr_en(w_we), .x_wr_addr(w_addr), .w_wr_addr(w_addr), .w_neuron(w_neur),
            .x_wr_data(w_data), .w_wr_data(w_data), .load_ready_o(core_load_ready), .busy_o(core_busy),
            .done_o(core_done), .error_o(core_err), .result_o(core_res), .overflow_o(core_ov));
    end else begin : g_no_core
        assign core_load_ready = resetn; assign core_busy = 1'b0; assign core_done = 1'b0;
        assign core_err = 1'b0; assign core_res = 64'd0; assign core_ov = 4'd0;
    end endgenerate

    // ---------------- 2-7: 엔진 포트 (npu_core를 통합 엔진 모양으로) ----------------
    generate if (STAGE >= 7) begin : g_eng
        wire signed [15:0] r0 = core_res[15:0],  r1 = core_res[31:16];
        wire signed [15:0] r2 = core_res[47:32], r3 = core_res[63:48];
        reg  [1:0] best;
        reg  signed [15:0] best_v;
        always @(*) begin                         // 통합 엔진과 같은 규칙: 큰 값, 같으면 앞 번호
            best = 2'd0; best_v = r0;
            if (r1 > best_v) begin best = 2'd1; best_v = r1; end
            if (r2 > best_v) begin best = 2'd2; best_v = r2; end
            if (r3 > best_v) begin best = 2'd3; best_v = r3; end
        end
        assign e_load_ready_o = core_load_ready && !e_start_i;
        assign e_busy_o   = core_busy && eng_run;
        assign e_done_o   = core_done && eng_run;
        assign e_error_o  = core_err && eng_run;
        assign e_class_o  = best;
        assign e_scores_o = {{{25{r3[15]}}, r3}, {{25{r2[15]}}, r2}, {{25{r1[15]}}, r1}, {{25{r0[15]}}, r0}};
    end else begin : g_no_eng
        assign e_load_ready_o = 1'b0; assign e_busy_o = 1'b0; assign e_done_o = 1'b0; assign e_error_o = 1'b0;
        assign e_class_o = 2'd0; assign e_scores_o = 164'd0;
    end endgenerate

    // ---------------- 콘솔 명령 처리 ----------------
    localparam [2:0] S_IDLE = 3'd0, S_RDW = 3'd1, S_QW = 3'd2, S_SRD = 3'd3, S_SRDW = 3'd4,
                     S_PUSH = 3'd5, S_SWAIT = 3'd6, S_CWAIT = 3'd7;
    reg [2:0] state;
    reg [3:0] cur_op;
    reg [5:0] idx;

    function stage_ok(input [3:0] op);
        stage_ok = (op <= OP_WRD) ||
                   (op == OP_QNT && STAGE >= 2) || (op == OP_DOT && STAGE >= 3) ||
                   (op == OP_PE4 && STAGE >= 4) || (op == OP_DENSE && STAGE >= 5) || (op == OP_CORE && STAGE >= 6);
    endfunction

    always @(posedge clk) begin
        if (!resetn) begin
            state <= S_IDLE; cur_op <= 4'd0; idx <= 6'd0;
            op_done_o <= 1'b0; op_error_o <= 1'b0; res_o <= 160'd0; flags_o <= 4'd0;
            rd_en <= 1'b0; rd_addr <= 6'd0; q_valid <= 1'b0;
            seq_op <= 4'd0; start <= 1'b0; length <= 9'd0; push <= 1'b0; x_q <= 16'sd0; w_q <= 64'd0;
            core_start_c <= 1'b0; eng_run <= 1'b0;
        end else begin
            op_done_o <= 1'b0; op_error_o <= 1'b0;
            rd_en <= 1'b0; q_valid <= 1'b0; start <= 1'b0; core_start_c <= 1'b0;
            if (eng && e_start_i) eng_run <= 1'b1;
            case (state)
                S_IDLE: if (op_valid_i && !eng) begin
                    cur_op <= op_i;
                    if (!stage_ok(op_i) || ((op_i >= OP_DOT) && (len_i == 7'd0 || len_i > 7'd64))) begin
                        op_error_o <= 1'b1; op_done_o <= 1'b1;
                    end else case (op_i)
                        OP_XWR, OP_WWR, OP_BWR: op_done_o <= 1'b1;
                        OP_XRD, OP_WRD: begin rd_en <= 1'b1; rd_addr <= addr_i; state <= S_RDW; end
                        OP_QNT: begin q_valid <= 1'b1; state <= S_QW; end
                        OP_DOT, OP_PE4, OP_DENSE: begin
                            seq_op <= op_i; length <= {2'b00, len_i}; start <= 1'b1; idx <= 6'd0; state <= S_SRD;
                        end
                        OP_CORE: begin core_start_c <= 1'b1; eng_run <= 1'b0; state <= S_CWAIT; end
                        default: begin op_error_o <= 1'b1; op_done_o <= 1'b1; end
                    endcase
                end
                S_RDW: if (x_rv) begin            // BRAM 동기 읽기: rd_valid가 선 클록에 값
                    res_o <= {144'd0, (cur_op == OP_XRD) ? x_rd : w_rd[neuron_i*16 +: 16]};
                    op_done_o <= 1'b1; state <= S_IDLE;
                end
                S_QW: if (q_done) begin
                    res_o <= {152'd0, q_out}; flags_o <= {3'd0, q_ov}; op_done_o <= 1'b1; state <= S_IDLE;
                end
                S_SRD: begin rd_en <= 1'b1; rd_addr <= idx; state <= S_SRDW; end
                S_SRDW: if (x_rv) begin x_q <= x_rd; w_q <= w_rd; push <= 1'b1; state <= S_PUSH; end
                S_PUSH: if (seq_ready) begin      // 이 클록에 모듈이 원소를 받는다
                    push <= 1'b0;
                    if ({1'b0, idx} + 7'd1 == length[6:0]) state <= S_SWAIT;
                    else begin idx <= idx + 6'd1; state <= S_SRD; end
                end
                S_SWAIT: if (seq_done || seq_err) begin
                    res_o <= (seq_op == OP_DOT) ? {120'd0, dot_res} : (seq_op == OP_PE4) ? pe_res : {96'd0, dn_res};
                    flags_o <= (seq_op == OP_DENSE) ? dn_ov : 4'd0;
                    op_error_o <= seq_err; op_done_o <= 1'b1; state <= S_IDLE;
                end
                S_CWAIT: if (core_done || core_err) begin
                    res_o <= {96'd0, core_res}; flags_o <= core_ov;
                    op_error_o <= core_err; op_done_o <= 1'b1; state <= S_IDLE;
                end
                default: state <= S_IDLE;
            endcase
            if (core_done || core_err) eng_run <= 1'b0;
        end
    end

// 2장 NPU 경로 (2-7부터): 명령 해석기 + 엔진 선택.
//   2-7 (STAGE 7): 엔진 = 2-6 npu_core (p02_bank 엔진 포트). 점수는 Dense 결과(ReLU·16비트)를 41비트로 늘린 값.
//   2-8 (STAGE 8): npu_engine4를 더한다. sw[3] = 0 2-6 core, 1 = 통합 엔진(원시 점수, ReLU 없음).
//                  두 엔진은 같은 쓰기·시작을 함께 받으므로 스위치를 바꿔도 다시 적재할 필요가 없다.
`timescale 1ns/1ps
`default_nettype none
module p02_npu_path #(
    parameter integer STAGE = 8
) (
    input  wire               clk,
    input  wire               resetn,
    input  wire               sel_engine4_i,     // 보드 sw[3] (비동기)
    // UART (p02_uart_switch의 명령 해석기 쪽)
    input  wire [7:0]         rx_data_i,
    input  wire               rx_valid_i,
    output wire               rx_ready_o,
    output wire [7:0]         tx_data_o,
    output wire               tx_valid_o,
    input  wire               tx_ready_i,
    output wire               protocol_error_o,
    // p02_bank 엔진 포트
    output wire               e_start_o,
    output wire [6:0]         e_length_o,
    output wire               e_x_wr_o,
    output wire               e_w_wr_o,
    output wire               e_b_wr_o,
    output wire [5:0]         e_addr_o,
    output wire [1:0]         e_neuron_o,
    output wire signed [15:0] e_data_o,
    output wire signed [39:0] e_bias_o,
    input  wire               e_load_ready_i,
    input  wire               e_busy_i,
    input  wire               e_done_i,
    input  wire               e_error_i,
    input  wire [1:0]         e_class_i,
    input  wire [163:0]       e_scores_i,
    // 표시용 (고른 엔진)
    output wire [1:0]         class_o,
    output wire               busy_o,
    output wire               done_o,
    output wire               error_o
);
    generate if (STAGE >= 7) begin : g_path
        reg [1:0] sync;
        always @(posedge clk) begin
            if (!resetn) sync <= 2'b00;
            else         sync <= {sync[0], sel_engine4_i};
        end
        wire use4 = (STAGE >= 8) && sync[1];

        wire               start, xwe, wwe, bwe, load_ready, busy, done, err;
        wire [6:0]         length;
        wire [5:0]         addr;
        wire [1:0]         neuron, cls;
        wire signed [15:0] data;
        wire signed [39:0] bias;
        wire [163:0]       scores;

        uart_npu_command_controller u_cmd (
            .clk(clk), .resetn(resetn),
            .rx_data_i(rx_data_i), .rx_valid_i(rx_valid_i), .rx_ready_o(rx_ready_o),
            .tx_data_o(tx_data_o), .tx_valid_o(tx_valid_o), .tx_ready_i(tx_ready_i),
            .npu_start_o(start), .npu_length_o(length),
            .x_wr_en_o(xwe), .w_wr_en_o(wwe), .b_wr_en_o(bwe),
            .wr_addr_o(addr), .neuron_o(neuron), .wr_data_o(data), .bias_data_o(bias),
            .npu_load_ready_i(load_ready), .npu_busy_i(busy), .npu_done_i(done), .npu_error_i(err),
            .npu_class_i(cls), .npu_scores_i(scores), .protocol_error_o(protocol_error_o));

        assign e_start_o = start;  assign e_length_o = length;
        assign e_x_wr_o  = xwe;    assign e_w_wr_o   = wwe;    assign e_b_wr_o = bwe;
        assign e_addr_o  = addr;   assign e_neuron_o = neuron;
        assign e_data_o  = data;   assign e_bias_o   = bias;

        wire         r4, b4, d4, x4;
        wire [1:0]   c4;
        wire [163:0] s4;
        if (STAGE >= 8) begin : g_e4
            npu_engine4 u_e4 (
                .clk(clk), .resetn(resetn), .start_i(start), .length_i(length),
                .x_wr_en(xwe), .w_wr_en(wwe), .b_wr_en(bwe), .addr_i(addr), .neuron_i(neuron),
                .data_i(data), .bias_i(bias), .load_ready_o(r4), .busy_o(b4), .done_o(d4),
                .error_o(x4), .class_o(c4), .scores_o(s4));
        end else begin : g_no_e4
            assign r4 = 1'b1; assign b4 = 1'b0; assign d4 = 1'b0; assign x4 = 1'b0;
            assign c4 = 2'd0; assign s4 = 164'd0;
        end

        // 쓰기는 두 엔진이 모두 받을 수 있을 때만 (명령 해석기는 load_ready를 보고 쓴다)
        assign load_ready = e_load_ready_i && r4;
        assign busy   = use4 ? b4 : e_busy_i;
        // 고른 엔진의 완료·오류·클래스·점수를 레지스터 한 단에 받은 뒤 명령 해석기로 넘긴다.
        // npu_core 결과 → 조합 argmax → 엔진 선택 → 해석기 응답 버퍼를 한 클록에 묶으면 100 MHz를 넘기므로 여기서 끊는다.
        // 응답이 1클록 늦을 뿐 값은 같다 (done·error는 1클록 펄스 그대로).
        reg          done_q, err_q;
        reg [1:0]    cls_r;
        reg [163:0]  scores_r;
        always @(posedge clk) begin
            if (!resetn) begin
                done_q <= 1'b0; err_q <= 1'b0; cls_r <= 2'd0; scores_r <= 164'd0;
            end else begin
                done_q   <= use4 ? d4 : e_done_i;
                err_q    <= use4 ? x4 : e_error_i;
                cls_r    <= use4 ? c4 : e_class_i;
                scores_r <= use4 ? s4 : e_scores_i;
            end
        end
        assign done   = done_q;
        assign err    = err_q;
        assign cls    = cls_r;
        assign scores = scores_r;

        reg [1:0] cls_q;                          // 표시: 마지막으로 끝난 실행의 클래스
        always @(posedge clk) begin
            if (!resetn)  cls_q <= 2'd0;
            else if (done) cls_q <= cls;
        end
        assign class_o = cls_q;
        assign busy_o  = busy;
        assign done_o  = done;
        assign error_o = err;
    end else begin : g_no_path
        assign rx_ready_o = 1'b0; assign tx_data_o = 8'd0; assign tx_valid_o = 1'b0; assign protocol_error_o = 1'b0;
        assign e_start_o = 1'b0; assign e_length_o = 7'd0; assign e_x_wr_o = 1'b0; assign e_w_wr_o = 1'b0;
        assign e_b_wr_o = 1'b0; assign e_addr_o = 6'd0; assign e_neuron_o = 2'd0; assign e_data_o = 16'sd0;
        assign e_bias_o = 40'sd0; assign class_o = 2'd0; assign busy_o = 1'b0; assign done_o = 1'b0; assign error_o = 1'b0;
    end endgenerate
endmodule

"""2장 4뉴런 NPU 보드 PC 쪽 도구: 명령을 바이트로 바꿔 보내고 응답 한 줄을 받아 출력한다.

import sys

INT = lambda s: int(s, 0)


def encode(args):
    op, a = args[0], [INT(x) for x in args[1:]]
    if op in ("S", "0", "1", "2", "3"):
        return op.encode()
    if op == "X":
        return b"X" + bytes([a[0]]) + struct.pack(">h", a[1])
    if op == "W":
        return b"W" + bytes([a[0], a[1]]) + struct.pack(">h", a[2])
    if op == "x":
        return b"x" + bytes([a[0]])
    if op == "w":
        return b"w" + bytes([a[0], a[1]])
    if op == "Q":
        return b"Q" + struct.pack(">i", a[0])
    if op == "B":
        return b"B" + bytes([a[0]]) + (a[1] & ((1 << 40) - 1)).to_bytes(5, "big")
    if op in ("D", "P", "L", "N", "R"):
        return op.encode() + bytes([a[0]])
    raise SystemExit("모르는 명령: " + op)


def main(argv):
    if len(argv) < 2:
        raise SystemExit(__doc__)
    port, data = argv[0], encode(argv[1:])
    print("TX", data.hex(" "))
    if port == "--dry":
        return 0

        reply = s.read_until(b"\n")
    print("RX", repr(reply.decode("ascii", "replace")))
    return 0 if reply else 1

03 서브젝트 2-1 · BRAM 동기 버퍼

목표: X·W로 쓴 값을 x·w로 되읽으면 같은 값이 나옵니다(X:0003, X:FFFE, W:0005). 범위를 벗어난 주소 64는 ERR입니다.

해설

X와 W를 담아 둘 메모리입니다. BRAM(Block RAM)은 FPGA 안에 미리 만들어져 있는 메모리 블록이고, bram_sync_buffer는 Vivado가 이 블록을 쓰도록 유도하는 형태로 쓴 동기 메모리입니다.

'동기'라는 말은 주소를 준 다음 클록에 데이터가 나온다는 뜻입니다. 이 한 클록 지연은 뒤의 모든 모듈이 읽기 타이밍을 맞출 때 기준이 됩니다. 여기서는 X 버퍼 1개와 W 버퍼 4개에 값을 쓰고 되읽어 봅니다.

module bram_sync_buffer #(
    parameter integer DATA_WIDTH=16, ADDR_WIDTH=8
) (
    input wire clk, resetn, wr_en, rd_en,
    input wire [ADDR_WIDTH-1:0] wr_addr, rd_addr,
    input wire signed [DATA_WIDTH-1:0] wr_data,
    output reg signed [DATA_WIDTH-1:0] rd_data,
    output reg rd_valid
);
    (* ram_style="block" *) reg signed [DATA_WIDTH-1:0] mem [0:(1<<ADDR_WIDTH)-1];
    // 배열에는 Reset 루프를 두지 않는다. Reset 중 쓰기는 억제한다.
    always @(posedge clk) begin
        if (resetn && wr_en) mem[wr_addr] <= wr_data;
        if (!resetn) begin
            rd_data <= 0;
            rd_valid <= 0;
        end else begin
            rd_valid <= rd_en;
            if (rd_en) rd_data <= mem[rd_addr];
        end
    end

04 서브젝트 2-2 · 고정소수점 양자화

목표: 32비트 값을 8비트로 줄입니다. 768은 03, 384는 256으로 나누면 1.5이므로 반올림되어 02, 65536은 최댓값 7F로 막히고 넘침 표시 O:1이 붙습니다.

해설

곱해서 더한 값은 32비트나 40비트로 커지는데, 다음 계산에 넣으려면 다시 8비트나 16비트로 줄여야 합니다. 이것이 양자화입니다. fixed_quantizer는 오른쪽으로 8비트 밀어(256으로 나눔) 소수 아래를 반올림하고, 범위를 넘으면 최댓값·최솟값으로 막습니다(포화).

포화가 일어나면 값이 잘린 것이므로 넘침 표시를 함께 냅니다. 반올림과 포화가 PC의 계산과 한 비트도 다르지 않아야 보드와 PC의 추론 결과가 같아집니다.

작성할 코드

`timescale 1ns/1ps
module fixed_quantizer #(
    parameter integer IN_WIDTH=32, OUT_WIDTH=8, SHIFT=8, ROUND=1, SATURATE=1
) (
    input wire clk, resetn, valid_i,
    input wire signed [IN_WIDTH-1:0] x_i,
    output reg signed [OUT_WIDTH-1:0] q_o,
    output reg valid_o, overflow_o
);
    wire signed [63:0] wide, rounded, scaled, lower, upper;
    wire ov;
    // 입력이 초기 0에서 변하지 않아도 조합 계산을 시작하는 연속 할당이다.
    assign wide = $signed(x_i);
    assign lower = -(64'sd1 <<< (OUT_WIDTH-1));
    assign upper = (64'sd1 <<< (OUT_WIDTH-1))-1;
    // 음수는 크기를 반올림한 뒤 부호를 복원하여 tie-away 규칙을 적용한다.
    assign rounded = (ROUND && SHIFT>0) ?
      (wide<0 ? -(((-wide)+(64'sd1 <<< (SHIFT-1))) >>> SHIFT) :
                 (wide+(64'sd1 <<< (SHIFT-1))) >>> SHIFT) : wide >>> SHIFT;
    assign ov = rounded<lower || rounded>upper;
    assign scaled = (SATURATE && rounded<lower) ? lower :
                    (SATURATE && rounded>upper) ? upper : rounded;
    always @(posedge clk) begin
        if(!resetn) begin q_o<=0; valid_o<=0; overflow_o<=0; end
        else begin
            valid_o<=valid_i;
            if(valid_i) begin q_o<=scaled[OUT_WIDTH-1:0]; overflow_o<=ov; end
        end
    end
    // synthesis translate_off
    initial if(IN_WIDTH<2 || IN_WIDTH>48 || OUT_WIDTH<2 || OUT_WIDTH>32 || SHIFT<0 || SHIFT>30)
        $fatal(1,"Unsupported quantizer parameters");
    // synthesis translate_on
endmodule

05 서브젝트 2-3 · 벡터 내적

목표: X=(1,2,3,4)와 W0=(5,6,7,8)의 내적은 D:0000000046(70)입니다. W0[3]을 −8로 바꾸면 6이 되고, 길이 0을 주면 ERR입니다.

해설

vector_dot_core는 X와 W를 앞에서부터 하나씩 읽어 1장의 MAC으로 곱하고 더합니다. 길이가 len이면 len번 반복해 내적 하나를 만듭니다.

BRAM에서 값이 한 클록 늦게 나오므로 '주소 내기 → 값 받기 → 누산'의 순서를 상태 기계로 맞춥니다. 길이 0처럼 잘못된 요청은 계산하지 않고 오류로 답합니다.

작성할 코드

`timescale 1ns/1ps
module vector_dot_core #(parameter integer DATA_WIDTH=16,ACC_WIDTH=40,MAX_LEN=256)(
    input wire clk,resetn,start_i,valid_i,
    input wire [8:0] length_i,
    input wire signed [DATA_WIDTH-1:0] a_i,b_i,
    output wire ready_o,
    output reg busy_o,done_o,error_o,
    output reg signed [ACC_WIDTH-1:0] result_o
);
    reg [8:0] accepted,length_q;
    wire signed [ACC_WIDTH-1:0] acc;
    wire mac_valid;
    wire launch=start_i && !busy_o;
    assign ready_o=busy_o && accepted<length_q;
    // 정상 MAC을 그대로 사용하고 트랜잭션 경계에서만 Clear한다.
    mac_core #(.DATA_WIDTH(DATA_WIDTH),.ACC_WIDTH(ACC_WIDTH)) mac
      (.clk(clk),.resetn(resetn),.clear_i(launch),.valid_i(valid_i && ready_o),
       .a_i(a_i),.b_i(b_i),.acc_o(acc),.valid_o(mac_valid));
    always @(posedge clk) begin
        if(!resetn) begin
            busy_o<=0;done_o<=0;error_o<=0;result_o<=0;accepted<=0;length_q<=0;
        end else begin
            done_o<=0;error_o<=0;
            if(launch) begin
                accepted<=0;length_q<=length_i;
                if(length_i>MAX_LEN) error_o<=1;
                else if(length_i==0) begin result_o<=0;done_o<=1;end
                else busy_o<=1;
            end else if(busy_o) begin
                if(valid_i && ready_o) accepted<=accepted+1'b1;
                // MAC 출력은 직전 에지에 등록되었으므로 마지막 수락 다음 에지에 읽는다.
                if(mac_valid && accepted==length_q) begin
                    result_o<=acc;done_o<=1;busy_o<=0;
                end
            end
        end
    end
    // synthesis translate_off
    initial if(MAX_LEN<1 || MAX_LEN>256) $fatal(1,"MAX_LEN range");
    // synthesis translate_on
endmodule

목표: 같은 X에 대해 W0~W3 네 개의 내적을 한 번에 계산합니다. P: 뒤에 6, 10, −10(…FFF6), 8이 나옵니다.

해설

뉴런 4개는 같은 X를 쓰고 W만 다릅니다. pe_array4는 내적 코어 4개를 나란히 두고 X를 한 번만 읽어 네 곳에 동시에 넣습니다. 이렇게 연산기 하나하나를 PE(Processing Element)라고 부릅니다.

PE가 4개이므로 뉴런 4개를 계산하는 시간이 내적 한 번과 같습니다. NPU가 빠른 이유가 바로 이 병렬 구조입니다.

작성할 코드

module pe_array4 #(parameter integer DATA_WIDTH=16,ACC_WIDTH=40)(
    input wire clk,resetn,start_i,
    input wire [8:0] length_i,
    input wire [3:0] valid_i,
    input wire [4*DATA_WIDTH-1:0] a_i,b_i,
    output wire [3:0] ready_o,
    output reg busy_o,done_o,error_o,
    output wire [4*ACC_WIDTH-1:0] pe_results_o,
    output reg signed [ACC_WIDTH+1:0] sum_o
);
    wire launch=start_i && !busy_o && length_i<=256;
    wire [3:0] lane_ready,lane_done;
    wire signed [ACC_WIDTH-1:0] lane_result[0:3];
    reg signed [ACC_WIDTH-1:0] saved[0:3];
    reg [3:0] finished;
    wire signed [ACC_WIDTH+1:0] extended[0:3];
    wire signed [ACC_WIDTH+1:0] left_sum,right_sum;
    assign left_sum=extended[0]+extended[1];
    assign right_sum=extended[2]+extended[3];
    assign ready_o=lane_ready & {4{busy_o}};
    genvar g;
    generate for(g=0;g<4;g=g+1)begin: pe
        assign pe_results_o[g*ACC_WIDTH+:ACC_WIDTH]=saved[g];
        assign extended[g]={{2{saved[g][ACC_WIDTH-1]}},saved[g]};
        vector_dot_core #(.DATA_WIDTH(DATA_WIDTH),.ACC_WIDTH(ACC_WIDTH)) dot
          (.clk(clk),.resetn(resetn),.start_i(launch),.length_i(length_i),
           .valid_i(valid_i[g] && busy_o),.a_i(a_i[g*DATA_WIDTH+:DATA_WIDTH]),.b_i(b_i[g*DATA_WIDTH+:DATA_WIDTH]),
           .ready_o(lane_ready[g]),.busy_o(),.done_o(lane_done[g]),.error_o(),.result_o(lane_result[g]));
    end endgenerate
    integer i;
    always @(posedge clk)begin
        if(!resetn)begin
            busy_o<=0;done_o<=0;error_o<=0;sum_o<=0;finished<=0;
            for(i=0;i<4;i=i+1)saved[i]<=0;
        end else begin
            done_o<=0;error_o<=0;
            if(start_i && !busy_o)begin
                if(length_i>256)error_o<=1;
                else begin busy_o<=1;finished<=0;end
            end else if(busy_o)begin
                for(i=0;i<4;i=i+1)if(lane_done[i])begin saved[i]<=lane_result[i];finished[i]<=1;end
                // 서로 다른 완료 에지의 결과를 모은 후 정렬된 합을 등록한다.
                if(&finished)begin sum_o<=left_sum+right_sum;done_o<=1;busy_o<=0;end
            end
        end
    end
endmodule

module dense_layer4 #(parameter integer DATA_WIDTH=16,ACC_WIDTH=40,SHIFT=0)(
    input wire clk,resetn,start_i,valid_i,
    input wire [8:0] length_i,
    input wire signed [DATA_WIDTH-1:0] x_i,
    input wire [4*DATA_WIDTH-1:0] weights_i,
    input wire [4*ACC_WIDTH-1:0] biases_i,
    output wire ready_o,
    output reg busy_o,done_o,error_o,
    output reg [4*DATA_WIDTH-1:0] result_o,
    output reg [3:0] overflow_o
);
    wire launch=start_i && !busy_o && length_i<=64;
    reg [4*ACC_WIDTH-1:0] biases_q;
    wire [3:0] ready_pe;
    wire pe_done;
    wire [4*ACC_WIDTH-1:0] pe_result;
    wire [4*DATA_WIDTH-1:0] quantized;
    wire [3:0] qv,qov;
    assign ready_o=busy_o && (&ready_pe);
    pe_array4 #(.DATA_WIDTH(DATA_WIDTH),.ACC_WIDTH(ACC_WIDTH)) pe
      (.clk(clk),.resetn(resetn),.start_i(launch),.length_i(length_i),
       .valid_i({4{valid_i && ready_o}}),.a_i({4{x_i}}),.b_i(weights_i),
       .ready_o(ready_pe),.busy_o(),.done_o(pe_done),.error_o(),.pe_results_o(pe_result),.sum_o());
    genvar g;
    generate for(g=0;g<4;g=g+1)begin: neurons
        wire signed [ACC_WIDTH-1:0] dot_value=pe_result[g*ACC_WIDTH+:ACC_WIDTH];
        wire signed [ACC_WIDTH-1:0] bias_value=biases_q[g*ACC_WIDTH+:ACC_WIDTH];

          (.clk(clk),.resetn(resetn),.valid_i(pe_done && busy_o),.x_i(activated),
           .q_o(quantized[g*DATA_WIDTH+:DATA_WIDTH]),.valid_o(qv[g]),.overflow_o(qov[g]));
    end endgenerate
    always @(posedge clk)begin
        if(!resetn)begin busy_o<=0;done_o<=0;error_o<=0;result_o<=0;overflow_o<=0;biases_q<=0;end
        else begin
            done_o<=0;error_o<=0;
            if(start_i && !busy_o)begin
                if(length_i>64)error_o<=1;
                else begin busy_o<=1;biases_q<=biases_i;end
            end else if(busy_o && (&qv))begin
                result_o<=quantized;overflow_o<=qov;busy_o<=0;done_o<=1;
            end
        end
    end
endmodule

08 서브젝트 2-6 · 4뉴런 NPU Core

목표: npu_core가 자기 BRAM에서 값을 읽어 같은 Dense 계산을 합니다. N 4의 답은 L 4와 같고, 길이 2에서는 0011,0000,0061,7FFF입니다.

해설

지금까지는 메모리와 연산기가 따로 있었습니다. npu_core는 X·W 메모리와 Dense 계산을 한 모듈 안에 넣고, 밖으로는 '쓰기'와 '시작', '결과'만 보이게 묶습니다. 이렇게 묶어야 뒤에서 어떤 제어기든 같은 방식으로 NPU를 쓸 수 있습니다.

N 명령의 답이 2-5의 L 명령과 같다는 것으로, 묶은 뒤에도 계산이 그대로임을 확인합니다.

작성할 코드

ch10/rtl/npu_core.v · verilog
`timescale 1ns/1ps
module npu_core #(parameter integer DATA_WIDTH=16,ACC_WIDTH=40)(
    input wire clk,resetn,start_i,
    input wire [8:0] length_i,
    input wire [4*ACC_WIDTH-1:0] biases_i,
    input wire x_wr_en,w_wr_en,
    input wire [5:0] x_wr_addr,w_wr_addr,
    input wire [1:0] w_neuron,
    input wire signed [DATA_WIDTH-1:0] x_wr_data,w_wr_data,
    output wire load_ready_o,
    output reg busy_o,done_o,error_o,
    output reg [4*DATA_WIDTH-1:0] result_o,
    output reg [3:0] overflow_o
);
    localparam IDLE=0,LAUNCH=1,READ=2,WAIT_READ=3,SEND=4,WAIT_DONE=5;
    reg [2:0] state;
    reg [8:0] length_q;
    reg [5:0] index_q;
    reg [4*ACC_WIDTH-1:0] biases_q;
    wire rd_en=state==READ;
    wire signed [DATA_WIDTH-1:0] x_data;
    wire x_valid;
    wire [4*DATA_WIDTH-1:0] w_data;
    wire [3:0] w_valid;
    wire dense_ready,dense_done,dense_error;
    wire [4*DATA_WIDTH-1:0] dense_result;
    wire [3:0] dense_overflow;
    assign load_ready_o=resetn && !busy_o;
    bram_sync_buffer #(.DATA_WIDTH(DATA_WIDTH),.ADDR_WIDTH(6)) inputs_mem
      (.clk(clk),.resetn(resetn),.wr_en(x_wr_en && load_ready_o),.wr_addr(x_wr_addr),.wr_data(x_wr_data),
       .rd_en(rd_en),.rd_addr(index_q),.rd_data(x_data),.rd_valid(x_valid));
    genvar g;
    generate for(g=0;g<4;g=g+1)begin: weights_mem
        bram_sync_buffer #(.DATA_WIDTH(DATA_WIDTH),.ADDR_WIDTH(6)) mem
          (.clk(clk),.resetn(resetn),.wr_en(w_wr_en && load_ready_o && w_neuron==g),
           .wr_addr(w_wr_addr),.wr_data(w_wr_data),.rd_en(rd_en),.rd_addr(index_q),
           .rd_data(w_data[g*DATA_WIDTH+:DATA_WIDTH]),.rd_valid(w_valid[g]));
    end endgenerate
    dense_layer4 #(.DATA_WIDTH(DATA_WIDTH),.ACC_WIDTH(ACC_WIDTH)) dense
      (.clk(clk),.resetn(resetn),.start_i(state==LAUNCH),.length_i(length_q),
       .valid_i(state==SEND),.x_i(x_data),.weights_i(w_data),.biases_i(biases_q),
       .ready_o(dense_ready),.busy_o(),.done_o(dense_done),.error_o(dense_error),
       .result_o(dense_result),.overflow_o(dense_overflow));
    always @(posedge clk)begin
        if(!resetn)begin
            state<=IDLE;busy_o<=0;done_o<=0;error_o<=0;result_o<=0;overflow_o<=0;
            index_q<=0;length_q<=0;biases_q<=0;
        end else begin
            done_o<=0;error_o<=0;
            case(state)
                IDLE: if(start_i)begin
                    if(length_i>64 || x_wr_en || w_wr_en)error_o<=1;
                    else begin
                        length_q<=length_i;biases_q<=biases_i;index_q<=0;busy_o<=1;state<=LAUNCH;
                    end
                end
                LAUNCH: if(length_q==0)state<=WAIT_DONE;else state<=READ;
                READ: state<=WAIT_READ;
                WAIT_READ: begin
                    // 메모리 출력과 Valid가 정렬된 에지를 확인한 뒤 전송한다.
                    if(x_valid && (&w_valid))state<=SEND;
                    else begin state<=IDLE;busy_o<=0;error_o<=1;end
                end
                SEND: if(dense_ready)begin
                    if({3'b0,index_q}+9'd1==length_q)state<=WAIT_DONE;
                    else begin index_q<=index_q+1'b1;state<=READ;end
                end
                WAIT_DONE: if(dense_done)begin
                    result_o<=dense_result;overflow_o<=dense_overflow;busy_o<=0;done_o<=1;state<=IDLE;
                end
                default: begin state<=IDLE;busy_o<=0;error_o<=1;end
            endcase
            if(dense_error)begin state<=IDLE;busy_o<=0;error_o<=1;end
        end
    end
endmodule

09 서브젝트 2-7 · UART 모델 적재

목표: sw2를 올리면 명령 해석기가 UART를 받습니다. 숫자 0~3을 보내면 C0~C3이 돌아옵니다. sw2를 내리고 x 0을 보내면 X:FFFF가 나와, 명령 해석기가 쓴 값을 콘솔로 확인할 수 있습니다.

해설

이제 디버그용 명령이 아니라 실제 사용 방식으로 넘어갑니다. uart_npu_command_controller는 PC가 보낸 모델(X·W·Bias)을 NPU에 싣고, 추론을 시작시키고, 점수와 클래스를 한 줄로 돌려주는 명령 해석기입니다.

sw2를 올리면 UART가 디버그 콘솔 대신 이 해석기로 연결됩니다. 숫자 0~3은 미리 정해 둔 표본 입력으로 추론하는 명령이고, 답으로 가장 점수가 높은 뉴런 번호(클래스)가 옵니다.

작성할 코드

mini_npu/rtl/uart_npu_command_controller.v · verilog
// UART 명령·모델 적재·추론 결과 직렬화 Controller.
// 단일 문자 '0'~'3'은 2원소 고정 표본. 2-7 바이너리 명령은 아래 README 참조.
// 요청/응답은 stop-and-wait: ACK 또는 결과 LF까지 다음 명령 송신 금지.
module uart_npu_command_controller(
    input wire clk,resetn,
    input wire [7:0] rx_data_i,
    input wire rx_valid_i,
    output wire rx_ready_o,
    output wire [7:0] tx_data_o,
    output wire tx_valid_o,
    input wire tx_ready_i,
    output wire npu_start_o,
    output wire [6:0] npu_length_o,
    output wire x_wr_en_o,w_wr_en_o,b_wr_en_o,
    output reg [5:0] wr_addr_o,
    output reg [1:0] neuron_o,
    output reg signed [15:0] wr_data_o,
    output reg signed [39:0] bias_data_o,
    input wire npu_load_ready_i,
    input wire npu_busy_i,npu_done_i,npu_error_i,
    input wire [1:0] npu_class_i,
    input wire [163:0] npu_scores_i,
    output reg protocol_error_o
);
    localparam [2:0] IDLE=0,RECV=1,APPLY=2,PRESET=3,RUN=4,WAIT_NPU=5,SEND=6;
    reg [2:0] state;
    reg [7:0] opcode;
    reg [7:0] payload[0:5];
    reg [2:0] recv_index,expected_bytes;
    reg [1:0] sample_id;
    reg [3:0] preset_index;
    reg [6:0] run_length;
    reg [7:0] response[0:63];
    reg [5:0] send_length,send_index;
    integer i,j;

    assign rx_ready_o=resetn&&(state==IDLE||state==RECV);
    assign tx_valid_o=(state==SEND)&&(send_index<send_length);
    assign tx_data_o=response[send_index];
    assign npu_start_o=(state==RUN);
    assign npu_length_o=run_length;

    // 필드 형식 거부. 주소 0~63, 뉴런 0~3, 길이 1~64.
    wire accepted_fields =
        (opcode=="X" && payload[0]<64) ||
        (opcode=="W" && payload[0]<4 && payload[1]<64) ||
        (opcode=="B" && payload[0]<4) ||
        (opcode=="R" && payload[0]>=1 && payload[0]<=64);

    assign x_wr_en_o=(state==PRESET && preset_index<2 && npu_load_ready_i) ||
        (state==APPLY && opcode=="X" && accepted_fields && npu_load_ready_i);
    assign w_wr_en_o=(state==PRESET && preset_index>=2 && preset_index<10 &&
                      npu_load_ready_i) ||
        (state==APPLY && opcode=="W" && accepted_fields && npu_load_ready_i);
    assign b_wr_en_o=(state==PRESET && preset_index>=10 && npu_load_ready_i) ||
        (state==APPLY && opcode=="B" && accepted_fields && npu_load_ready_i);

    always @*begin
        wr_addr_o=0;neuron_o=0;wr_data_o=0;bias_data_o=0;
        if(state==PRESET)begin
            if(preset_index<2)begin
                wr_addr_o={2'b00,preset_index};
                // X0=(+1,+1), X1=(+1,-1), X2=(-1,+1), X3=(-1,-1)
                wr_data_o=((preset_index==0 && sample_id[1]) ||
                    (preset_index==1 && sample_id[0])) ? -16'sd1 : 16'sd1;
            end else if(preset_index<10)begin
                neuron_o=(preset_index-2)>>1;
                wr_addr_o=(preset_index-2)&1;
                wr_data_o=((neuron_o[1] && wr_addr_o==0) ||
                    (neuron_o[0] && wr_addr_o==1)) ? -16'sd1 : 16'sd1;
            end else neuron_o=preset_index-10;
        end else if(state==APPLY)begin
            case(opcode)
                "X":begin wr_addr_o=payload[0][5:0];wr_data_o={payload[1],payload[2]};end
                "W":begin neuron_o=payload[0][1:0];wr_addr_o=payload[1][5:0];
                    wr_data_o={payload[2],payload[3]};end
                "B":begin neuron_o=payload[0][1:0];
                    bias_data_o={payload[1],payload[2],payload[3],payload[4],payload[5]};end
                default:begin end
            endcase
        end
    end

    function [7:0] hexdigit(input [3:0] n);
        begin
            hexdigit=(n<10) ? (8'h30+n) : (8'h41+(n-10));
        end
    endfunction
    function [7:0] score_hex(input [40:0] score,input integer position);
        reg [43:0] ext;
        reg [3:0] nib;
        begin
            ext={{3{score[40]}},score};
            nib=(ext>>((10-position)*4)) & 4'hf;
            score_hex=hexdigit(nib);
        end
    endfunction

    always @(posedge clk)begin
        if(!resetn)begin
            state<=IDLE;opcode<=0;recv_index<=0;expected_bytes<=0;
            sample_id<=0;preset_index<=0;run_length<=2;
            send_length<=0;send_index<=0;protocol_error_o<=0;
        end else begin
            protocol_error_o<=0;
            case(state)
                IDLE:if(rx_valid_i && rx_ready_o)begin
                    if(rx_data_i>="0" && rx_data_i<="3")begin
                        sample_id<=rx_data_i[1:0];preset_index<=0;run_length<=2;
                        state<=PRESET;
                    end else if(rx_data_i=="X"||rx_data_i=="W"||
                        rx_data_i=="B"||rx_data_i=="R")begin
                        opcode<=rx_data_i;recv_index<=0;
                        case(rx_data_i)
                            "X":expected_bytes<=3;
                            "W":expected_bytes<=4;
                            "B":expected_bytes<=6;
                            default:expected_bytes<=1;
                        endcase
                        state<=RECV;
                    end else if(rx_data_i=="S")begin
                        response[0]<="I";response[1]<=8'h0d;response[2]<=8'h0a;
                        send_index<=0;send_length<=3;state<=SEND;
                    end else if(rx_data_i!=8'h0d && rx_data_i!=8'h0a)begin
                        protocol_error_o<=1;
                        response[0]<="E";response[1]<="R";response[2]<="R";
                        response[3]<=8'h0d;response[4]<=8'h0a;
                        send_index<=0;send_length<=5;state<=SEND;
                    end
                end
                RECV:if(rx_valid_i && rx_ready_o)begin
                    payload[recv_index]<=rx_data_i;
                    if(recv_index+3'd1==expected_bytes)state<=APPLY;
                    else recv_index<=recv_index+1'b1;
                end
                APPLY:begin
                    if(!accepted_fields || !npu_load_ready_i)begin
                        protocol_error_o<=1;
                        response[0]<="E";response[1]<="R";response[2]<="R";
                        response[3]<=8'h0d;response[4]<=8'h0a;
                        send_index<=0;send_length<=5;state<=SEND;
                    end else if(opcode=="R")begin
                        run_length<=payload[0][6:0];state<=RUN;
                    end else begin
                        response[0]<="O";response[1]<="K";
                        response[2]<=8'h0d;response[3]<=8'h0a;
                        send_index<=0;send_length<=4;state<=SEND;
                    end
                end
                PRESET:if(npu_load_ready_i)begin
                    if(preset_index==13)state<=RUN;
                    else preset_index<=preset_index+1'b1;
                end
                RUN:state<=WAIT_NPU;
                WAIT_NPU:begin
                    if(npu_error_i)begin
                        protocol_error_o<=1;
                        response[0]<="E";response[1]<="R";response[2]<="R";
                        response[3]<=8'h0d;response[4]<=8'h0a;
                        send_index<=0;send_length<=5;state<=SEND;
                    end else if(npu_done_i)begin
                        // Cx: + 4 signed 41bit scores each in 11 hex chars + CRLF.
                        response[0]<="C";response[1]<=8'h30+{6'b0,npu_class_i};
                        response[2]<=":";
                        for(i=0;i<4;i=i+1)begin
                            for(j=0;j<11;j=j+1)
                                response[3+i*12+j]<=score_hex(
                                    npu_scores_i[i*41+:41],j);
                            if(i<3)response[14+i*12]<=",";
                        end
                        response[50]<=8'h0d;response[51]<=8'h0a;
                        send_index<=0;send_length<=52;state<=SEND;
                    end
                end
                SEND:if(tx_valid_o && tx_ready_i)begin
                    if(send_index+6'd1==send_length)begin
                        send_index<=0;state<=IDLE;
                    end else send_index<=send_index+1'b1;
                end
                default:begin state<=IDLE;protocol_error_o<=1;end
            endcase
        end
    end
endmodule

해설

마지막으로 엔진을 하나 더 만듭니다. npu_engine4는 1-3의 DSP 곱셈기를 쓰는 MAC 4개와 BRAM을 직접 묶은 통합 엔진으로, 점수 4개 중 가장 큰 것을 골라(argmax) 클래스를 냅니다.

sw3으로 두 엔진을 바꿔 가며 같은 입력을 넣어 봅니다. 통합 엔진은 ReLU를 거치지 않은 원래 점수를 내므로 음수가 보이지만, 가장 큰 점수의 번호인 클래스는 같습니다. 결과는 LED와 7세그먼트에도 표시됩니다.

module npu_dsp_mac_lane #(
    parameter integer DATA_WIDTH=16,
    parameter integer ACC_WIDTH=40
)(
    input wire clk,resetn,clear_i,valid_i,
    input wire signed [DATA_WIDTH-1:0] x_i,w_i,
    output reg signed [ACC_WIDTH-1:0] acc_o
);
    wire signed [2*DATA_WIDTH-1:0] product;
    wire product_valid;
    dsp_multiplier #(.A_WIDTH(DATA_WIDTH),.B_WIDTH(DATA_WIDTH)) dsp(
        .clk(clk),.resetn(resetn),.clear_i(clear_i),
        .valid_i(valid_i),.a_i(x_i),.b_i(w_i),
        .product_o(product),.valid_o(product_valid));
    wire signed [ACC_WIDTH-1:0] product_extended =
        {{(ACC_WIDTH-2*DATA_WIDTH){product[2*DATA_WIDTH-1]}},product};
    always @(posedge clk)begin
        if(!resetn || clear_i)acc_o<=0;
        else if(product_valid)acc_o<=acc_o+product_extended;
    end
    // synthesis translate_off
    initial if(ACC_WIDTH<2*DATA_WIDTH)$fatal(1,"ACC_WIDTH too small");
    // synthesis translate_on
endmodule

// BRAM 구조 + DSP 레지스터 곱 + 4개 누산기 통합.
// 2-8 최종 경로는 2-3 벡터 내적의 곱 경로를 중복 사용하지 않는다.
// 메모리 쓰기는 IDLE에서만 허용하며 Reset 시 유효 비트만 지운다.
module npu_engine4(
    input wire clk,resetn,start_i,
    input wire [6:0] length_i,
    input wire x_wr_en,w_wr_en,b_wr_en,
    input wire [5:0] addr_i,
    input wire [1:0] neuron_i,
    input wire signed [15:0] data_i,
    input wire signed [39:0] bias_i,
    output wire load_ready_o,
    output reg busy_o,done_o,error_o,
    output reg [1:0] class_o,
    output reg [163:0] scores_o
);
    localparam [2:0] IDLE=0,READ=1,ISSUE=2,DRAIN1=3,DRAIN2=4,CMP1=5,CMP2=6;
    reg [2:0] state;
    reg [6:0] length_q;
    reg [5:0] index_q;
    (* ram_style="block" *) reg signed [15:0] xmem[0:63];
    (* ram_style="block" *) reg signed [15:0] w0[0:63];
    (* ram_style="block" *) reg signed [15:0] w1[0:63];
    (* ram_style="block" *) reg signed [15:0] w2[0:63];
    (* ram_style="block" *) reg signed [15:0] w3[0:63];
    reg [63:0] x_seen,w0_seen,w1_seen,w2_seen,w3_seen;
    reg signed [39:0] bias0,bias1,bias2,bias3;
    reg signed [15:0] x_sample,w_sample0,w_sample1,w_sample2,w_sample3;

    reg input_valid;
    integer k;
    always @* begin
        input_valid=(length_i!=0 && length_i<=64);
        for(k=0;k<64;k=k+1)
            if(k<length_i &&
               (!x_seen[k] || !w0_seen[k] || !w1_seen[k] ||
                !w2_seen[k] || !w3_seen[k]))
                input_valid=0;
    end
    wire any_write=x_wr_en||w_wr_en||b_wr_en;
    wire launch=(state==IDLE)&&start_i&&input_valid&&!any_write;
    wire mul_valid=(state==ISSUE);
    assign load_ready_o=resetn&&!busy_o&&!start_i;

    wire signed [39:0] acc0,acc1,acc2,acc3;
    npu_dsp_mac_lane lane0(.clk(clk),.resetn(resetn),.clear_i(launch),
        .valid_i(mul_valid),.x_i(x_sample),.w_i(w_sample0),.acc_o(acc0));
    npu_dsp_mac_lane lane1(.clk(clk),.resetn(resetn),.clear_i(launch),
        .valid_i(mul_valid),.x_i(x_sample),.w_i(w_sample1),.acc_o(acc1));
    npu_dsp_mac_lane lane2(.clk(clk),.resetn(resetn),.clear_i(launch),
        .valid_i(mul_valid),.x_i(x_sample),.w_i(w_sample2),.acc_o(acc2));
    npu_dsp_mac_lane lane3(.clk(clk),.resetn(resetn),.clear_i(launch),
        .valid_i(mul_valid),.x_i(x_sample),.w_i(w_sample3),.acc_o(acc3));
    // 41비트 signed: 40비트 누산값에 Bias를 더할 때 부호 확장 1비트.
    wire signed [40:0] score0=$signed({acc0[39],acc0})+$signed({bias0[39],bias0});
    wire signed [40:0] score1=$signed({acc1[39],acc1})+$signed({bias1[39],bias1});
    wire signed [40:0] score2=$signed({acc2[39],acc2})+$signed({bias2[39],bias2});
    wire signed [40:0] score3=$signed({acc3[39],acc3})+$signed({bias3[39],bias3});
    // argmax는 두 클록 토너먼트다. 누산값 + Bias 덧셈과 41비트 비교 3번을 한 클록에 직렬로 하면
    // 100 MHz를 넘기므로 나눈다. 동점이면 앞 번호가 이긴다.
    //   DRAIN2: 점수 등록 → CMP1: (0,1)·(2,3) 쌍의 승자 등록 → CMP2: 두 승자 비교, class_o·done
    wire signed [40:0] s0=scores_o[40:0],s1=scores_o[81:41],s2=scores_o[122:82],s3=scores_o[163:123];
    reg [1:0] w01_q,w23_q;
    reg signed [40:0] v01_q,v23_q;

    always @(posedge clk)begin
        if(!resetn)begin
            state<=IDLE;busy_o<=0;done_o<=0;error_o<=0;
            class_o<=0;scores_o<=0;length_q<=0;index_q<=0;
            w01_q<=0;w23_q<=0;v01_q<=0;v23_q<=0;
            x_seen<=0;w0_seen<=0;w1_seen<=0;w2_seen<=0;w3_seen<=0;
            bias0<=0;bias1<=0;bias2<=0;bias3<=0;
            x_sample<=0;w_sample0<=0;w_sample1<=0;w_sample2<=0;w_sample3<=0;
        end else begin
            done_o<=0;error_o<=0;
            if(load_ready_o)begin
                if(x_wr_en)begin
                    xmem[addr_i]<=data_i;x_seen[addr_i]<=1;
                end
                if(w_wr_en)case(neuron_i)
                    0:begin w0[addr_i]<=data_i;w0_seen[addr_i]<=1;end
                    1:begin w1[addr_i]<=data_i;w1_seen[addr_i]<=1;end
                    2:begin w2[addr_i]<=data_i;w2_seen[addr_i]<=1;end
                    3:begin w3[addr_i]<=data_i;w3_seen[addr_i]<=1;end
                endcase
                if(b_wr_en)case(neuron_i)
                    0:bias0<=bias_i;
                    1:bias1<=bias_i;
                    2:bias2<=bias_i;
                    3:bias3<=bias_i;
                endcase
            end else if(any_write)error_o<=1;
            case(state)
                IDLE:if(start_i)begin
                    if(!input_valid||any_write)error_o<=1;
                    else begin
                        state<=READ;length_q<=length_i;index_q<=0;busy_o<=1;
                    end
                end
                READ:begin
                    x_sample<=xmem[index_q];
                    w_sample0<=w0[index_q];w_sample1<=w1[index_q];
                    w_sample2<=w2[index_q];w_sample3<=w3[index_q];
                    state<=ISSUE;
                end
                ISSUE:begin
                    if({1'b0,index_q}+7'd1==length_q)state<=DRAIN1;
                    else begin index_q<=index_q+1'b1;state<=READ;end
                end
                DRAIN1:state<=DRAIN2;
                DRAIN2:begin
                    scores_o<={score3,score2,score1,score0};
                    state<=CMP1;
                end
                CMP1:begin
                    if(s1>s0)begin w01_q<=1;v01_q<=s1;end else begin w01_q<=0;v01_q<=s0;end
                    if(s3>s2)begin w23_q<=3;v23_q<=s3;end else begin w23_q<=2;v23_q<=s2;end
                    state<=CMP2;
                end
                CMP2:begin
                    class_o<=(v23_q>v01_q) ? w23_q : w01_q;
                    done_o<=1;busy_o<=0;state<=IDLE;
                end
                default:begin state<=IDLE;busy_o<=0;error_o<=1;end
            endcase
        end
    end
endmodule

// FND와 LED 표현 정책은 Top이 아닌 Controller에서 처리.
module npu_display_controller(
    input wire clk,resetn,
    input wire [1:0] class_i,
    input wire busy_i,done_i,error_i,protocol_error_i,
    input wire uart_framing_error_i,uart_overrun_i,
    output wire [15:0] led_o,
    output reg [6:0] seg_o,
    output reg [3:0] an_o,
    output wire dp_o
);
    reg done_latched,error_latched;
    reg [17:0] scan_count;
    reg [3:0] digit;
    wire [3:0] onehot=4'b0001<<class_i;
    always @(posedge clk)begin
        if(!resetn)begin
            done_latched<=0;error_latched<=0;scan_count<=0;
        end else begin
            scan_count<=scan_count+1'b1;
            if(done_i)done_latched<=1;
            if(error_i||protocol_error_i||uart_framing_error_i||uart_overrun_i)
                error_latched<=1;
        end
    end
    assign led_o[3:0]=onehot;
    assign led_o[12:4]=9'd0;
    assign led_o[13]=busy_i;
    assign led_o[14]=done_latched;
    assign led_o[15]=error_latched;
    assign dp_o=1'b1;
    always @*begin
        case(scan_count[17:16])
            2'd0:begin an_o=4'b1110;digit={2'b00,class_i};end
            2'd1:begin an_o=4'b1101;digit=0;end
            2'd2:begin an_o=4'b1011;digit=0;end
            default:begin an_o=4'b0111;digit=0;end
        endcase
        // Active low: segments {g,f,e,d,c,b,a} (seg[0] is a).
        case(digit)
            0:seg_o=7'b1000000;
            1:seg_o=7'b1111001;
            2:seg_o=7'b0100100;
            3:seg_o=7'b0110000;
            default:seg_o=7'b1111111;
        endcase
    end
endmodule

// Basys3 btnC → 동기 Reset (Active-Low resetn).
// btnC를 플립플롭 2단으로 동기화한 뒤 resetn을 만든다. 모든 플립플롭이 clk에만 반응한다.
// 리셋이 비동기로 바뀌면 그 신호를 받는 RAMB18의 EN·WE·RST 핀이 setup/hold를 어겨 BRAM 내용이 깨질 수 있으므로
// (Vivado DRC REQP-1840), 걸 때도 풀 때도 클록에 맞춘다.
//   · 전원 인가 직후: 초기값으로 resetn=0, btnC가 0이면 3클록 뒤 해제
//   · btnC를 1클록(10 ns) 이상 누르면 2~3클록 뒤 resetn=0, 떼면 2~3클록 뒤 resetn=1
module npu_reset_controller(
    input wire clk,btnC,
    output wire resetn
);
    (* ASYNC_REG="TRUE" *) reg [1:0] sync_q=2'b11;
    reg resetn_q=1'b0;
    always @(posedge clk)begin
        sync_q<={sync_q[0],btnC};
        resetn_q<=~sync_q[1];
    end
    assign resetn=resetn_q;
endmodule

// 시뮬레이션 시간을 줄이려고 BAUD 6.25 Mbps(CPB 16), REFRESH_BITS 6으로 돌린다. 보드 Top 기본값은 115200 bps.
`timescale 1ns/1ps
module tb_p02_top;
    parameter integer STAGE = 8;                  // run_sim.sh가 1~8로 바꿔 여덟 번 돌린다
    localparam integer CLK_HZ = 100000000, BAUD = 6250000;
    localparam integer CPB = (CLK_HZ + BAUD / 2) / BAUD;
    reg clk = 0, btnC = 1, rxd = 1;
    reg [1:0] sw = 2'd0;
    wire txd, dp;
    wire [15:0] led;
    wire [6:0] seg;
    wire [3:0] an;
    always #5 clk = ~clk;

    basys3_p02_top #(.CLK_HZ(CLK_HZ), .BAUD(BAUD), .REFRESH_BITS(6), .STAGE(STAGE)) dut (
        .clk(clk), .btnC(btnC), .uart_rxd(rxd), .sw(sw), .uart_txd(txd),
        .led(led), .seg(seg), .an(an), .dp(dp));

    // TX 핀 복조 (1-1 uart_rx 그대로)
    wire [7:0] got;
    wire got_valid, fe, ov;
    reg mon_resetn = 0;
    uart_rx #(.CLK_HZ(CLK_HZ), .BAUD(BAUD)) mon (
        .clk(clk), .resetn(mon_resetn), .rx_i(txd), .out_data_o(got), .out_valid_o(got_valid),
        .out_ready_i(1'b1), .framing_error_o(fe), .overrun_o(ov));

    reg [7:0] rxq [0:255];
    integer rx_wr = 0;
    always @(posedge clk) if (got_valid) begin
        rxq[rx_wr[7:0]] = got;
        rx_wr = rx_wr + 1;
    end

    task automatic send_byte(input [7:0] b);
        integer k;
        begin
            @(negedge clk); rxd = 0; repeat (CPB) @(negedge clk);
            for (k = 0; k < 8; k = k + 1) begin rxd = b[k]; repeat (CPB) @(negedge clk); end
            rxd = 1; repeat (CPB) @(negedge clk);
        end
    endtask

    integer fd, n_tx, n_rx, i, v, sel, cases = 0, rx_rd = 0, t, code;
    reg [8*8-1:0] subj;
    reg [8*200-1:0] line;
    reg [7:0] tx [0:15];
    reg [7:0] exp [0:63];
    reg [15:0] led_exp;
    reg [8*4-1:0] tag;

    initial begin
        fd = $fopen($sformatf("p02/tb/p02_cases_s%0d.txt", STAGE), "r");
        if (fd == 0) $fatal(1, "p02_cases_s%0d.txt 없음: python3 p02/reference/p02_model.py 먼저", STAGE);
        code = $fgets(line, fd);                         // 머리 줄
        repeat (5) @(posedge clk);
        btnC = 0; mon_resetn = 1;
        repeat (10) @(posedge clk);
        forever begin
            code = $fscanf(fd, "%s", subj);
            if (code != 1) $fatal(1, "사례 파일 끝에 END 줄 없음");
            if (subj == "END") begin
                code = $fscanf(fd, "%h", v); led_exp = v;
                repeat (20) @(posedge clk);
                if (led !== led_exp) $fatal(1, "LED=%04h 기대 %04h", led, led_exp);
                if (fe || ov) $fatal(1, "TX 복조 오류 fe=%0d ov=%0d", fe, ov);
                $display("P02_BOARD_TOP_LED_PASS stage=%0d led=0x%04h", STAGE, led);
                $display("P02_TOP_RTL_SIM_PASS stage=%0d cases=%0d bytes=%0d", STAGE, cases, rx_wr);
                $finish;
            end
            code = $fscanf(fd, "%h %h", sel, n_tx);
            for (i = 0; i < n_tx; i = i + 1) begin code = $fscanf(fd, "%h", v); tx[i] = v; end
            code = $fscanf(fd, "%h", n_rx);
            for (i = 0; i < n_rx; i = i + 1) begin code = $fscanf(fd, "%h", v); exp[i] = v; end
            sw = sel;
            repeat (8) @(posedge clk);                    // 스위치 2FF 동기화 대기
            for (i = 0; i < n_tx; i = i + 1) send_byte(tx[i]);
            t = 0;
            while (rx_wr - rx_rd < n_rx) begin
                @(posedge clk); t = t + 1;
                if (t > 40 * CPB * (n_rx + 2)) $fatal(1, "%0s 응답 시간 초과: %0d/%0d 바이트", subj, rx_wr - rx_rd, n_rx);
            end

"""2장 4뉴런 NPU 보드 기준 모델.

명령 순서(보낼 바이트, sw[3:2])를 정하고 보드가 돌려줄 응답을 계산해
p02/tb/p02_cases_s{STAGE}.txt (STAGE = 끝낸 서브젝트 수 1~8)로 쓴다. TB는 이 파일만 보고 판정한다.
계산은 서브젝트(구 장) 기준 모델 함수를 그대로 쓴다: 05 quantize, 07 dot, 09 dense.

  python3 p02/reference/p02_model.py
"""
import os
import struct
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parents[2]
for ch in ("ch01", "ch05", "ch07", "ch09"):
    sys.path.insert(0, str(ROOT / ch / "reference"))
from mac_reference import wrap              # noqa: E402  (1-2)
from fixed_reference import quantize        # noqa: E402  (2-2)
from dot_reference import dot               # noqa: E402  (2-3)
from dense_reference import dense           # noqa: E402  (2-5)

OUT = ROOT / "p02" / "tb" / "p02_cases_s%d.txt"
CRLF = "\r\n"
NEED = {"S": 0, "X": 3, "W": 4, "x": 1, "w": 2, "Q": 4, "D": 1, "P": 1, "B": 6, "L": 1, "N": 1}
MIN_STAGE = {"Q": 2, "D": 3, "P": 4, "B": 5, "L": 5, "N": 6}


def h(v, n):
    return format(v & ((1 << (4 * n)) - 1), "0%dX" % n)


class Board:
    def __init__(self, stage):
        self.stage = stage
        self.x = [None] * 64                     # 안 쓴 칸은 None (RTL에서는 X)
        self.w = [[None] * 64 for _ in range(4)]
        self.bias = [0] * 4
        self.view = 0
        self.x_seen = [False] * 64               # 2-8 엔진의 적재 확인 비트
        self.w_seen = [[False] * 64 for _ in range(4)]
        self.cls = 0                             # 마지막 추론 클래스 (STAGE 8 표시)
        self.done = False
        self.err = False

    # ── 디버그 콘솔 (sw[2] = 0) ──
    def console(self, data):
        c = chr(data[0])
        if c in "\r\n":
            return ""
        if c not in NEED or self.stage < MIN_STAGE.get(c, 1):
            return "?" + CRLF
        p = data[1:]
        assert len(p) == NEED[c], (c, data)
        if c == "S":
            return "I" + CRLF
        bad = ((c in "Xx" and p[0] >= 64) or (c in "Ww" and (p[0] >= 4 or p[1] >= 64))
               or (c == "B" and p[0] >= 4) or (c in "DPLN" and not 1 <= p[0] <= 64))
        if bad:
            return "ERR" + CRLF
        s16 = lambda hi, lo: struct.unpack(">h", bytes([hi, lo]))[0]
        if c == "X":
            self.x[p[0]] = s16(p[1], p[2])
            return "OK" + CRLF
        if c == "W":
            self.w[p[0]][p[1]] = s16(p[2], p[3])
            return "OK" + CRLF
        if c == "B":
            self.bias[p[0]] = wrap(int.from_bytes(bytes(p[1:6]), "big"), 40)
            return "OK" + CRLF
        if c in "xw":
            v = self.x[p[0]] if c == "x" else self.w[p[0]][p[1]]
            assert v is not None, "안 쓴 칸을 읽음"
            self.view = v & 0xFFFF
            return c.upper() + ":" + h(v, 4) + CRLF
        if c == "Q":
            v = struct.unpack(">i", bytes(p))[0]
            q, ov = quantize(v, 8, 8, 1, 1)
            self.view = q & 0xFFFF
            return "Q:%s O:%d" % (h(q, 2), ov) + CRLF
        n = p[0]
        xs = self.x[:n]
        ws = [row[:n] for row in self.w]
        assert None not in xs, "안 쓴 X"
        if c == "D":
            assert None not in ws[0]
            r = dot(xs, ws[0], 40)
            self.view = r & 0xFFFF
            return "D:" + h(r, 10) + CRLF
        if c == "P":
            assert all(None not in r for r in ws)
            rs = [dot(xs, r, 40) for r in ws]
            self.view = rs[0] & 0xFFFF
            return "P:" + ",".join(h(r, 10) for r in rs) + CRLF
        assert all(None not in r for r in ws)
        vals, mask = dense(xs, ws, self.bias, 16, 40, 0)      # L·N: Dense(+Bias, ReLU, 16비트)
        self.view = vals[0] & 0xFFFF
        return c + ":" + ",".join(h(v, 4) for v in vals) + " O:%X" % mask + CRLF

    # ── 2-7 명령 해석기 (sw[2] = 1) ──
    def write(self, kind, n, a, v):
        if kind == "X":
            self.x[a] = v
            self.x_seen[a] = True
        elif kind == "W":
            self.w[n][a] = v
            self.w_seen[n][a] = True
        else:
            self.bias[n] = v

    def infer(self, length, engine4):
        xs, ws = self.x[:length], [r[:length] for r in self.w]
        if engine4:                              # 2-8 엔진: 원시 점수 = 내적 + Bias, 적재 확인
            if not (all(self.x_seen[:length]) and all(all(r[:length]) for r in self.w_seen)):
                self.err = True
                return "ERR" + CRLF
            scores = [wrap(dot(xs, r, 40) + b, 41) for r, b in zip(ws, self.bias)]
        else:                                    # 2-6 npu_core: Dense 결과(ReLU, 16비트)를 41비트로
            scores, _ = dense(xs, ws, self.bias, 16, 40, 0)
        cls = 0
        for i in range(1, 4):
            if scores[i] > scores[cls]:
                cls = i
        self.cls, self.done = cls, True
        return "C%d:" % cls + ",".join(h(s, 11) for s in scores) + CRLF

    def engine(self, data, engine4):
        c = chr(data[0])
        if c in "\r\n":
            return ""
        if c in "0123":                          # 고정 그룹: X0·X1, W[n][0·1], Bias 0, 길이 2
            k = int(c)
            self.write("X", 0, 0, -1 if k & 2 else 1)
            self.write("X", 0, 1, -1 if k & 1 else 1)
            for n in range(4):
                self.write("W", n, 0, -1 if n & 2 else 1)
                self.write("W", n, 1, -1 if n & 1 else 1)
            for n in range(4):
                self.write("B", n, 0, 0)
            return self.infer(2, engine4)
        if c == "S":
            return "I" + CRLF
        p = data[1:]
        ok = ((c == "X" and p[0] < 64) or (c == "W" and p[0] < 4 and p[1] < 64)
              or (c == "B" and p[0] < 4) or (c == "R" and 1 <= p[0] <= 64))
        if c not in "XWBR" or not ok:
            self.err = True
            return "ERR" + CRLF
        if c == "R":
            return self.infer(p[0], engine4)
        s16 = struct.unpack(">h", bytes(p[-2:]))[0] if c in "XW" else 0
        if c == "X":
            self.write("X", 0, p[0], s16)
        elif c == "W":
            self.write("W", p[0], p[1], s16)
        else:
            self.write("B", p[0], 0, wrap(int.from_bytes(bytes(p[1:6]), "big"), 40))
        return "OK" + CRLF

    def step(self, sw, data):
        eng = self.stage >= 7 and bool(sw & 1)          # sw 값 = sw[3:2]
        e4 = self.stage >= 8 and bool(sw & 2)
        return (self.engine(data, e4) if eng else self.console(data)).encode()

    def led(self):
        if self.stage < 8:
            return self.view
        return (1 << self.cls) | (int(self.done) << 14) | (int(self.err) << 15)
