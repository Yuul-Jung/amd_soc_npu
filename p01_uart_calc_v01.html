제1장 · UART 계산기

UART로 받은 두 수를 곱하고 누산하는 계산기를 만들며, 같은 연산을 세 가지 코어로 구현해 비교합니다.

00 이 장에서 만드는 것

신경망 추론은 결국 '곱해서 더하기'의 반복입니다. 입력과 가중치를 곱하고 그 결과를 계속 더해 가는 이 연산을 MAC(Multiply-Accumulate)이라고 하며, NPU의 가장 작은 부품입니다.

이 장에서는 PC와 보드를 UART로 잇고, PC가 보낸 두 수를 보드가 곱해 누산하는 계산기를 만듭니다. 같은 MAC을 세 가지 구조(곱과 누산을 한 클록에, 곱을 레지스터로 끊은 DSP48E1 곱셈기, 2단 파이프라인)로 구현해, 결과는 같고 걸리는 클록 수만 다르다는 것을 보드에서 확인합니다.

장 끝에서 보드로 보여 줄 것: PC에서 두 수를 보내면 보드가 곱해서 누산하고, 결과를 UART·LED·7세그먼트로 돌려줍니다. 스위치로 곱셈 코어를 바꿔도 값은 같고 응답 지연만 달라집니다.

1일 과정입니다. 아래 서브젝트 4개를 차례로 끝내며 그때마다 보드에서 확인하고, 마지막에 장 전체를 시연합니다.

  1. 1-1UART 에코
    보낸 글자가 그대로 돌아옵니다. S를 보내면 준비 신호 I가 옵니다. 아직 MAC 코어가 없으므로 M도 그대로 돌아옵니다.    오전
  2. 1-2MAC 누산
    M 3 4를 두 번 보내면 12, 24(0x18)로 누산되고 LED와 7세그먼트에 0018이 보입니다. 응답 끝의 L:1은 지연 1클록이라는 뜻입니다.    오전
  3. 1-3DSP48E1 곱셈
    sw0을 올리면 DSP 코어(L:2), 내리면 1-2 코어(L:1)가 계산합니다. 두 코어의 누산값은 같습니다.    오후
  4. 1-4MAC 파이프라인
    sw1을 올리면 파이프라인 코어(L:2)가 계산합니다. 음수 경계값 −32768×32767을 넣어도 40비트 누산이 맞고, 마지막에 LED와 7세그먼트는 7D45입니다.    오후
  5. 시연장 시연
    PC에서 두 수를 보내면 보드가 곱해서 누산하고, 결과를 UART·LED·7세그먼트로 돌려줍니다. 스위치로 곱셈 코어를 바꿔도 값은 같고 응답 지연만 달라집니다.    장 끝

02 준비

  1. VS Code에서 저장소 루트(amd_soc_npu/)를 엽니다. 필요한 도구는 Vivado 2024.2(합성·시뮬레이션), python3, 그리고 PC에서 보드로 명령을 보낼 pyserial(pip install pyserial)입니다. 터미널에서 Vivado 명령이 잡히도록 settings64.sh를 먼저 불러옵니다.
  2. 코드는 저장소에 모두 들어 있고, 안내서에도 전체를 실었습니다. 직접 입력하며 따라 해도 되고, 읽고 실행만 해도 됩니다. 아래는 장 전체의 틀이 되는 뼈대 파일이고, 서브젝트 모듈은 각 서브젝트 절에 있습니다.
  3. 파일 경로의 ch01, part03/ch14 같은 폴더는 모듈별 작업 폴더 이름입니다. 이 안내서의 장·서브젝트 번호와는 관계가 없으므로 경로 그대로 쓰면 됩니다.
  4. <포트>는 보드의 USB 시리얼 포트 이름입니다. Windows는 COM3, Linux는 /dev/ttyUSB1 같은 이름이고, 통신 설정은 115200 bps 8N1입니다.
  5. STAGE는 끝낸 서브젝트 수입니다. 1-1만 끝냈으면 1, 1-4까지 끝냈으면 4입니다. 아직 작성하지 않은 모듈은 빌드에 들어가지 않으므로, 서브젝트를 하나 끝낼 때마다 바로 보드에 올려 볼 수 있습니다.

// 장 Top 공용 리셋: btnC(Active-High)를 2단 동기화해 동기 resetn을 만든다 (npu_reset_controller와 같은 동작).
// 모든 플립플롭이 clk에만 반응한다. 리셋이 비동기로 바뀌면 그 신호를 받는 BRAM 제어 핀이 setup/hold를 어겨
// 내용이 깨질 수 있으므로(Vivado DRC REQP-1840), 걸 때도 풀 때도 클록에 맞춘다.
`timescale 1ns/1ps
`default_nettype none
module p01_reset_sync (
    input  wire clk,
    input  wire btnC,
    output wire resetn
);
    (* ASYNC_REG = "TRUE" *) reg [1:0] sync_q = 2'b11;
    reg resetn_q = 1'b0;
    always @(posedge clk) begin
        sync_q   <= {sync_q[0], btnC};
        resetn_q <= ~sync_q[1];
    end
    assign resetn = resetn_q;
endmodule
`default_nettype wire
p01/rtl/p01_calc_controller.v · verilog
// 1장 UART 계산기 명령 해석기. 2-7과 같은 형식: 1바이트 명령 + 바이너리 페이로드(빅엔디언), stop-and-wait.
//
//   명령   페이로드                     응답
//   'M'    a_hi a_lo b_hi b_lo (signed16)  "A:" + 누산값 16진수 10자리 + " L:" + 지연 클록 1자리 + "\r\n"
//   'C'    없음                          "OK\r\n"   (누산값 0으로)
//   'S'    없음                          "I\r\n"    (준비 상태)
//   그 밖  —                             받은 바이트를 그대로 돌려준다 (1-1 에코)
//
// 지연(L)은 valid를 낸 클록부터 고른 코어의 valid가 보일 때까지의 클록 수다 (1-2 = 1, 1-3·1-4 = 2).
// STAGE = 지금까지 끝낸 서브젝트 수. STAGE 1(1-1)에서는 MAC 코어가 없으므로 'M'·'C'도 에코로 돌려준다.
// 응답을 보내는 동안에는 새 바이트를 받지 않는다 (rx_ready = 0, uart_core FIFO가 보관).
`timescale 1ns/1ps
`default_nettype none
module p01_calc_controller #(
    parameter integer ACC_WIDTH = 40,
    parameter integer STAGE     = 4
) (
    input  wire                        clk,
    input  wire                        resetn,
    // UART 수신
    input  wire [7:0]                  rx_data_i,
    input  wire                        rx_valid_i,
    output wire                        rx_ready_o,
    // UART 송신
    output reg  [7:0]                  tx_data_o,
    output reg                         tx_valid_o,
    input  wire                        tx_ready_i,
    // MAC 묶음
    output reg                         clear_o,
    output reg                         valid_o,
    output reg  signed [15:0]          a_o,
    output reg  signed [15:0]          b_o,
    input  wire signed [ACC_WIDTH-1:0] acc_i,
    input  wire                        acc_valid_i
);
    localparam [2:0] S_IDLE = 3'd0, S_ARG = 3'd1, S_WAIT = 3'd2, S_LOAD = 3'd3, S_SEND = 3'd4;
    localparam integer MSG_MAX = 18;            // "A:" 2 + 10 + " L:" 3 + 1 + "\r\n" 2
    localparam integer NIB = (ACC_WIDTH + 3) / 4;

    reg [2:0]  state;
    reg [1:0]  arg_cnt;
    reg [7:0]  arg [0:2];                       // 앞 세 바이트 (네 번째는 받는 클록에 바로 씀)
    reg [3:0]  lat;
    reg [7:0]  msg [0:MSG_MAX-1];
    reg [4:0]  msg_len, idx;
    integer    k;

    function [7:0] hex(input [3:0] n);
        hex = (n < 4'd10) ? (8'h30 + {4'd0, n}) : (8'h37 + {4'd0, n});   // '0'~'9', 'A'~'F'
    endfunction

    assign rx_ready_o = (state == S_IDLE) || (state == S_ARG);
    wire rx_take = rx_valid_i && rx_ready_o;

    always @(posedge clk) begin
        if (!resetn) begin
            state      <= S_IDLE;
            arg_cnt    <= 2'd0;
            lat        <= 4'd0;
            msg_len    <= 5'd0;
            idx        <= 5'd0;
            tx_data_o  <= 8'd0;
            tx_valid_o <= 1'b0;
            clear_o    <= 1'b0;
            valid_o    <= 1'b0;
            a_o        <= 16'sd0;
            b_o        <= 16'sd0;
        end else begin
            clear_o <= 1'b0;
            valid_o <= 1'b0;
            case (state)
                S_IDLE: if (rx_take) begin
                    case ((STAGE >= 2 || rx_data_i == "S") ? rx_data_i : 8'h00)
                        "M": begin arg_cnt <= 2'd0; state <= S_ARG; end
                        "C": begin
                            clear_o <= 1'b1;
                            msg[0] <= "O"; msg[1] <= "K"; msg[2] <= 8'h0D; msg[3] <= 8'h0A;
                            msg_len <= 5'd4; state <= S_LOAD;
                        end
                        "S": begin
                            msg[0] <= "I"; msg[1] <= 8'h0D; msg[2] <= 8'h0A;
                            msg_len <= 5'd3; state <= S_LOAD;
                        end
                        default: begin                   // 1-1 에코 (STAGE 1에서는 M·C 포함)
                            msg[0] <= rx_data_i;
                            msg_len <= 5'd1; state <= S_LOAD;
                        end
                    endcase
                end
                S_ARG: if (rx_take) begin
                    if (arg_cnt == 2'd3) begin
                        a_o     <= {arg[0], arg[1]};
                        b_o     <= {arg[2], rx_data_i};
                        valid_o <= 1'b1;
                        lat     <= 4'd0;
                        state   <= S_WAIT;
                    end else begin
                        arg[arg_cnt] <= rx_data_i;
                        arg_cnt <= arg_cnt + 2'd1;
                    end
                end
                S_WAIT: begin
                    if (acc_valid_i) begin
                        msg[0] <= "A"; msg[1] <= ":";
                        for (k = 0; k < NIB; k = k + 1)
                            msg[2 + k] <= hex(acc_i[4*(NIB-1-k) +: 4]);
                        msg[2 + NIB] <= " "; msg[3 + NIB] <= "L"; msg[4 + NIB] <= ":";
                        msg[5 + NIB] <= hex(lat);
                        msg[6 + NIB] <= 8'h0D; msg[7 + NIB] <= 8'h0A;
                        msg_len <= NIB + 8;
                        state <= S_LOAD;
                    end else if (lat != 4'hF) begin
                        lat <= lat + 4'd1;
                    end
                end
                S_LOAD: begin
                    tx_data_o  <= msg[0];
                    tx_valid_o <= 1'b1;
                    idx        <= 5'd0;
                    state      <= S_SEND;
                end
                S_SEND: if (tx_valid_o && tx_ready_i) begin
                    if (idx + 5'd1 == msg_len) begin
                        tx_valid_o <= 1'b0;
                        state      <= S_IDLE;
                    end else begin
                        tx_data_o <= msg[idx + 5'd1];
                        idx       <= idx + 5'd1;
                    end
                end
                default: state <= S_IDLE;
            endcase
        end
    end

    initial begin
        if (NIB + 8 > MSG_MAX)
            $fatal(1, "ACC_WIDTH too wide for response buffer");
    end
endmodule
`default_nettype wire
p01/rtl/p01_mac_bank.v · verilog
// 1장 MAC 묶음: 1-2·1-3·1-4 서브젝트의 세 코어에 같은 입력을 넣고, sw로 고른 코어의 결과만 내보낸다.
// STAGE = 지금까지 끝낸 서브젝트 수 (1~4). 아직 만들지 않은 코어는 넣지 않고, 그 sw 값은 앞 코어로 대신한다.
//   sel 0 = 1-2  mac_core                  지연 1클록
//   sel 1 = 1-3 dsp_multiplier + 누산 지연 2클록 (곱 레지스터 1 + 누산 레지스터 1)
//   sel 2·3 = 1-4 mac_pipeline_core 지연 2클록
// 세 코어가 같은 입력을 늘 함께 받으므로 누산값은 항상 같다. sw를 바꿔도 값은 그대로이고 지연만 달라진다.
`timescale 1ns/1ps
`default_nettype none
module p01_mac_bank #(
    parameter integer DATA_WIDTH = 16,
    parameter integer ACC_WIDTH  = 40,
    parameter integer STAGE      = 4
) (
    input  wire                         clk,
    input  wire                         resetn,
    input  wire                         clear_i,
    input  wire                         valid_i,
    input  wire signed [DATA_WIDTH-1:0] a_i,
    input  wire signed [DATA_WIDTH-1:0] b_i,
    input  wire [1:0]                   sel_i,      // 보드 스위치 (비동기 입력)
    output reg  signed [ACC_WIDTH-1:0]  acc_o,
    output reg                          valid_o,
    output wire [1:0]                   sel_o       // 동기화한 선택값
);
    localparam integer PRODUCT_WIDTH = 2 * DATA_WIDTH;

    // 스위치 2FF 동기화
    reg [1:0] sel_meta, sel_sync;
    always @(posedge clk) begin
        if (!resetn) begin
            sel_meta <= 2'd0;
            sel_sync <= 2'd0;
        end else begin
            sel_meta <= sel_i;
            sel_sync <= sel_meta;
        end
    end
    assign sel_o = sel_sync;

    // 1-2: mac_core
    wire signed [ACC_WIDTH-1:0] acc_mac;
    wire                        valid_mac;
    generate if (STAGE >= 2) begin : g_mac
        mac_core #(.DATA_WIDTH(DATA_WIDTH), .ACC_WIDTH(ACC_WIDTH)) u_mac (
            .clk(clk), .resetn(resetn), .clear_i(clear_i), .valid_i(valid_i),
            .a_i(a_i), .b_i(b_i), .acc_o(acc_mac), .valid_o(valid_mac));
    end else begin : g_no_mac
        assign acc_mac = {ACC_WIDTH{1'b0}};
        assign valid_mac = 1'b0;
    end endgenerate

    // 1-3: dsp_multiplier + 누산 레지스터
    wire signed [ACC_WIDTH-1:0] acc_dsp;
    wire                        valid_dsp;
    generate if (STAGE >= 3) begin : g_dsp
        wire signed [PRODUCT_WIDTH-1:0] prod_dsp;
        wire                            prod_valid_dsp;
        dsp_multiplier #(.A_WIDTH(DATA_WIDTH), .B_WIDTH(DATA_WIDTH)) u_dsp (
            .clk(clk), .resetn(resetn), .clear_i(clear_i), .valid_i(valid_i),
            .a_i(a_i), .b_i(b_i), .product_o(prod_dsp), .valid_o(prod_valid_dsp));

        reg signed [ACC_WIDTH-1:0] acc_q;
        reg                        valid_q;
        wire signed [ACC_WIDTH-1:0] prod_ext = {{(ACC_WIDTH-PRODUCT_WIDTH){prod_dsp[PRODUCT_WIDTH-1]}}, prod_dsp};
        always @(posedge clk) begin
            if (!resetn || clear_i) begin
                acc_q   <= {ACC_WIDTH{1'b0}};
                valid_q <= 1'b0;
            end else begin
                valid_q <= prod_valid_dsp;
                if (prod_valid_dsp)
                    acc_q <= acc_q + prod_ext;
            end
        end
        assign acc_dsp = acc_q;
        assign valid_dsp = valid_q;
    end else begin : g_no_dsp
        assign acc_dsp = acc_mac;              // 아직 없음: 1-2 코어로 대신
        assign valid_dsp = valid_mac;
    end endgenerate

    // 1-4: mac_pipeline_core
    wire signed [ACC_WIDTH-1:0] acc_pipe;
    wire                        valid_pipe;
    generate if (STAGE >= 4) begin : g_pipe
        mac_pipeline_core #(.DATA_WIDTH(DATA_WIDTH), .ACC_WIDTH(ACC_WIDTH)) u_pipe (
            .clk(clk), .resetn(resetn), .clear_i(clear_i), .valid_i(valid_i),
            .a_i(a_i), .b_i(b_i), .acc_o(acc_pipe), .valid_o(valid_pipe));
    end else begin : g_no_pipe
        assign acc_pipe = acc_dsp;             // 아직 없음: 앞 코어로 대신
        assign valid_pipe = valid_dsp;
    end endgenerate

    // 고른 코어의 결과
    always @(*) begin
        case (sel_sync)
            2'd0:    begin acc_o = acc_mac;  valid_o = valid_mac;  end
            2'd1:    begin acc_o = acc_dsp;  valid_o = valid_dsp;  end
            default: begin acc_o = acc_pipe; valid_o = valid_pipe; end
        endcase
    end
    initial begin
        if (STAGE < 1 || STAGE > 4)
            $fatal(1, "STAGE must be 1..4");
    end
endmodule
`default_nettype wire
p01/rtl/p01_hex4_display.v · verilog
// 1장 7세그먼트: 16비트 값을 16진수 4자리로 띄운다 (보드 seg·an·dp는 active-low, seg = {g,f,e,d,c,b,a}).
// 자리 전환은 100 MHz / 2^(REFRESH_BITS-2) 마다 (기본 18 → 약 1.5 kHz, 네 자리 한 바퀴 약 381 Hz).

"""1장 UART 계산기 PC 쪽 도구: 명령을 바이트로 바꿔 보내고 응답 한 줄을 받아 출력한다.

명령 형식은 p01/rtl/p01_calc_controller.v 머리말과 같다. 'M' 뒤 두 수는 signed16(-32768~32767).
"""
import struct
import sys


def encode(args):
    op = args[0]
    if op == "M":
        a, b = int(args[1], 0), int(args[2], 0)
        return b"M" + struct.pack(">hh", a, b)
    if len(op) == 1:
        return op.encode("ascii")          # C, S, 또는 에코할 글자
    raise SystemExit("명령은 M a b, C, S, 또는 글자 하나")


def main(argv):
    if len(argv) < 2:
        raise SystemExit(__doc__)
    port, args = argv[0], argv[1:]
    data = encode(args)
    print("TX", data.hex(" "))
    if port == "--dry":
        return 0
    import serial                           # pyserial (보드에서만 필요)
    with serial.Serial(port, 115200, timeout=1) as s:
        s.write(data)
        echo_only = len(data) == 1 and data not in (b"C", b"S")
        reply = s.read(1) if echo_only else s.read_until(b"\n")
    print("RX", repr(reply.decode("ascii", "replace")))
    return 0 if reply else 1


if __name__ == "__main__":
    sys.exit(main(sys.argv[1:]))

03 서브젝트 1-1 · UART 에코

목표: 보낸 글자가 그대로 돌아옵니다. S를 보내면 준비 신호 I가 옵니다. 아직 MAC 코어가 없으므로 M도 그대로 돌아옵니다.

해설

PC와 보드가 대화하는 통로부터 만듭니다. UART는 선 하나로 한 비트씩 보내는 직렬 통신이고, 여기서는 초당 115,200비트로 8비트 데이터를 주고받습니다(8N1).

uart_rx는 들어오는 비트열을 바이트로 모으고, uart_tx는 바이트를 비트열로 내보냅니다. uart_core는 이 둘에 16바이트 버퍼를 붙여, 보드가 응답을 보내는 동안 들어온 바이트를 잃지 않게 합니다. 이 서브젝트에서는 받은 글자를 그대로 돌려보내 통로가 살아 있는지만 확인합니다.

// 8N1 수신. RX 2FF, start midpoint/bit center, hold/overrun.
module uart_rx #(
    parameter integer CLK_HZ=100000000, BAUD=115200
)(
    input wire clk,resetn,rx_i,
    output reg [7:0] out_data_o,
    output reg out_valid_o,
    input wire out_ready_i,
    output reg framing_error_o,overrun_o
);
    localparam integer CPB=(CLK_HZ+BAUD/2)/BAUD;
    localparam integer HALF=CPB/2;
    localparam [1:0] IDLE=0,START=1,DATA=2,STOP=3;
    reg [1:0] state;
    reg rx_meta,rx_sync;
    reg [31:0] count_q;
    reg [2:0] bit_q;
    reg [7:0] shift_q;
    always @(posedge clk)begin
        if(!resetn)begin
            state<=IDLE;rx_meta<=1;rx_sync<=1;count_q<=0;bit_q<=0;shift_q<=0;
            out_data_o<=0;out_valid_o<=0;framing_error_o<=0;overrun_o<=0;
        end else begin
            rx_meta<=rx_i;rx_sync<=rx_meta;
            if(out_valid_o && out_ready_i)out_valid_o<=0;
            case(state)
                IDLE:if(!rx_sync)begin count_q<=HALF-1;state<=START;end
                START:if(count_q==0)begin
                    if(!rx_sync)begin count_q<=CPB-1;bit_q<=0;state<=DATA;end
                    else state<=IDLE;
                end else count_q<=count_q-1'b1;
                DATA:if(count_q==0)begin
                    shift_q[bit_q]<=rx_sync;count_q<=CPB-1;
                    if(bit_q==7)state<=STOP;
                    else bit_q<=bit_q+1'b1;
                end else count_q<=count_q-1'b1;
                STOP:if(count_q==0)begin
                    state<=IDLE;
                    if(!rx_sync)framing_error_o<=1;
                    else if(!out_valid_o || out_ready_i)begin
                        out_data_o<=shift_q;out_valid_o<=1;
                    end else overrun_o<=1;
                end else count_q<=count_q-1'b1;
                default:state<=IDLE;
            endcase
        end
    end
    // synthesis translate_off
    initial if(CPB<4)$fatal(1,"Unsupported UART clock/baud ratio");
    // synthesis translate_on
endmodule

// 8N1 송신. valid/ready handshake, 10bit start/data/stop.
module uart_tx #(
    parameter integer CLK_HZ=100000000, BAUD=115200
)(
    input wire clk,resetn,
    input wire [7:0] in_data_i,
    input wire in_valid_i,
    output wire in_ready_o,
    output reg tx_o
);
    localparam integer CPB=(CLK_HZ+BAUD/2)/BAUD;
    reg sending;
    reg [31:0] tick_q;
    reg [3:0] bit_q;
    reg [9:0] frame_q;
    assign in_ready_o=resetn && !sending;
    always @(posedge clk)begin
        if(!resetn)begin
            sending<=0;tick_q<=0;bit_q<=0;frame_q<=10'h3ff;tx_o<=1;
        end else if(!sending)begin
            tx_o<=1;
            if(in_valid_i)begin
                sending<=1;tick_q<=CPB-1;bit_q<=0;
                frame_q<={1'b1,in_data_i,1'b0};tx_o<=0;
            end
        end else if(tick_q!=0)tick_q<=tick_q-1'b1;
        else begin
            tick_q<=CPB-1;frame_q<={1'b1,frame_q[9:1]};
            if(bit_q==9)begin sending<=0;tx_o<=1;end
            else begin bit_q<=bit_q+1'b1;tx_o<=frame_q[1];end
        end
    end
    // synthesis translate_off
    initial if(CPB<4)$fatal(1,"Unsupported UART clock/baud ratio");
    // synthesis translate_on
endmodule

module uart_core #(

)(
    input wire clk,resetn,uart_rxd_i,
    output wire uart_txd_o,
    output wire [7:0] rx_out_data,
    output wire rx_out_valid,
    input wire rx_out_ready,
    input wire [7:0] tx_in_data,
    input wire tx_in_valid,
    output wire tx_in_ready,
    output wire rx_framing_error_o,rx_overrun_o
);

    wire phy_rx_valid,phy_rx_ready;
    wire [7:0] phy_tx_data;
    wire phy_tx_valid,phy_tx_ready;

        .out_data_o(phy_rx_data),.out_valid_o(phy_rx_valid),
        .out_ready_i(phy_rx_ready),.framing_error_o(rx_framing_error_o),
        .overrun_o(rx_overrun_o));
    uart_tx #(.CLK_HZ(CLK_HZ),.BAUD(BAUD)) tx(
        .clk(clk),.resetn(resetn),.in_data_i(phy_tx_data),
        .in_valid_i(phy_tx_valid),.in_ready_o(phy_tx_ready),.tx_o(uart_txd_o));

    reg [3:0] rx_wptr,rx_rptr;

    wire rx_push=phy_rx_valid && phy_rx_ready;

    assign rx_out_data=rx_fifo[rx_rptr];

    assign phy_tx_valid=(tx_count!=0);

04 서브젝트 1-2 · MAC 누산

목표: M 3 4를 두 번 보내면 12, 24(0x18)로 누산되고 LED와 7세그먼트에 0018이 보입니다. 응답 끝의 L:1은 지연 1클록이라는 뜻입니다.

해설

MAC의 기본형입니다. mac_core는 16비트 부호 있는 두 수를 곱하고, 그 곱을 40비트 누산기에 더합니다. 누산기를 곱(32비트)보다 넓게 잡는 이유는 여러 번 더해도 넘치지 않게 하기 위해서입니다.

곱셈과 덧셈을 한 클록 안에 끝내므로 입력을 넣은 다음 클록에 결과가 나옵니다. 응답의 L:1이 이 지연 1클록을 뜻합니다.

작성할 코드

ch01/rtl/mac_core.v · verilog
`timescale 1ns/1ps
`default_nettype none

// 독립 signed MAC: 보드 및 AXI에 의존하지 않는다.
(* use_dsp = "yes" *)
module mac_core #(
    parameter integer DATA_WIDTH = 16,
    parameter integer ACC_WIDTH = 40
) (
    input wire clk,
    input wire resetn,
    input wire clear_i,
    input wire valid_i,
    input wire signed [DATA_WIDTH-1:0] a_i,
    input wire signed [DATA_WIDTH-1:0] b_i,
    output reg signed [ACC_WIDTH-1:0] acc_o,
    output reg valid_o
);
    localparam integer PRODUCT_WIDTH = 2 * DATA_WIDTH;
    wire signed [PRODUCT_WIDTH-1:0] product_w;
    wire signed [ACC_WIDTH-1:0] product_ext_w;

    // 전체 곱을 보존한 뒤 부호 비트를 복제하여 누산 폭으로 확장한다.
    // 지원 조건: DATA_WIDTH >= 2, ACC_WIDTH >= 2*DATA_WIDTH.
    assign product_w = $signed(a_i) * $signed(b_i);
    assign product_ext_w = {{(ACC_WIDTH-PRODUCT_WIDTH){product_w[PRODUCT_WIDTH-1]}}, product_w};

    // 동기식 Active-Low Reset > Clear > Valid 순서.
    // 입력을 수락한 상승 에지 직후 acc_o와 valid_o가 함께 갱신된다.
    // valid_i=0이면 acc_o 유지, valid_o=0. Clear와 겹친 입력은 버린다.
    always @(posedge clk) begin
        if (!resetn) begin
            acc_o <= {ACC_WIDTH{1'b0}};
            valid_o <= 1'b0;
        end else if (clear_i) begin
            acc_o <= {ACC_WIDTH{1'b0}};
            valid_o <= 1'b0;
        end else begin
            valid_o <= valid_i;
            if (valid_i)
                // 범위 초과 시 상위 비트를 버리는 2의 보수 순환 연산이다.
                acc_o <= acc_o + product_ext_w;
        end
    end

    // synthesis translate_off
    initial begin
        if (DATA_WIDTH < 2 || ACC_WIDTH < PRODUCT_WIDTH)
            $fatal(1, "Require DATA_WIDTH>=2 and ACC_WIDTH>=2*DATA_WIDTH");
    end
    // synthesis translate_on
endmodule
`default_nettype wire

해설

                product_o <= product_full_w[A_WIDTH+B_WIDTH-1:0];
            end
        end
    end

    // synthesis translate_off
    initial begin
        if (A_WIDTH < 2 || A_WIDTH > 25 || B_WIDTH < 2 || B_WIDTH > 18)
            $fatal(1, "Require 2<=A_WIDTH<=25 and 2<=B_WIDTH<=18");
    end
    // synthesis translate_on

(* use_dsp = "yes" *)
module mac_pipeline_core #(
    parameter integer DATA_WIDTH = 16,
    parameter integer ACC_WIDTH = 40
) (
    input wire clk,
    input wire resetn,
    input wire clear_i,
    input wire valid_i,
    input wire signed [DATA_WIDTH-1:0] a_i,
    input wire signed [DATA_WIDTH-1:0] b_i,
    output reg signed [ACC_WIDTH-1:0] acc_o,
    output reg valid_o
);
    localparam integer PRODUCT_WIDTH = 2 * DATA_WIDTH;
    wire signed [PRODUCT_WIDTH-1:0] product_w;
    reg signed [PRODUCT_WIDTH-1:0] product_q;
    reg product_valid_q;
    wire signed [ACC_WIDTH-1:0] product_ext_w;

    assign product_w = $signed(a_i) * $signed(b_i);
    assign product_ext_w = {{(ACC_WIDTH-PRODUCT_WIDTH){product_q[PRODUCT_WIDTH-1]}}, product_q};

    always @(posedge clk) begin
        if (!resetn) begin
            product_q <= {PRODUCT_WIDTH{1'b0}};
            product_valid_q <= 1'b0;
            acc_o <= {ACC_WIDTH{1'b0}};
            valid_o <= 1'b0;
        end else if (clear_i) begin
            // 현재 입력과 미누산 곱을 모두 버려 지연 Valid가 남지 않게 한다.
            product_q <= {PRODUCT_WIDTH{1'b0}};
            product_valid_q <= 1'b0;
            acc_o <= {ACC_WIDTH{1'b0}};
            valid_o <= 1'b0;
        end else begin
            // 1단계: 곱과 같은 에지의 Valid를 함께 저장한다.
            product_valid_q <= valid_i;
            if (valid_i) begin
                product_q <= product_w;
            end
            // 2단계: 비차단 대입은 이전 에지에 저장된 곱과 Valid를 참조한다.
            valid_o <= product_valid_q;
            if (product_valid_q) begin
                // 부호 확장 후 더하며 범위 초과는 P3-01과 같은 2의 보수 순환이다.
                acc_o <= acc_o + product_ext_w;
            end
        end
    end

    // synthesis translate_off
    initial begin
        if (DATA_WIDTH < 2 || ACC_WIDTH < PRODUCT_WIDTH)
            $fatal(1, "Require DATA_WIDTH>=2 and ACC_WIDTH>=2*DATA_WIDTH");
    end
    // synthesis translate_on
endmodule

// 시뮬레이션 시간을 줄이려고 BAUD 6.25 Mbps(CPB 16), REFRESH_BITS 6으로 돌린다. 보드 Top 기본값은 115200 bps.
`timescale 1ns/1ps
module tb_p01_top;
    parameter integer STAGE = 4;                  // run_sim.sh가 1~4로 바꿔 네 번 돌린다
    localparam integer CLK_HZ = 100000000, BAUD = 6250000;
    localparam integer CPB = (CLK_HZ + BAUD / 2) / BAUD;
    reg clk = 0, btnC = 1, rxd = 1;
    reg [1:0] sw = 2'd0;
    wire txd, dp;
    wire [15:0] led;
    wire [6:0] seg;
    wire [3:0] an;
    always #5 clk = ~clk;

    basys3_p01_top #(.CLK_HZ(CLK_HZ), .BAUD(BAUD), .REFRESH_BITS(6), .STAGE(STAGE)) dut (
        .clk(clk), .btnC(btnC), .uart_rxd(rxd), .sw(sw), .uart_txd(txd),
        .led(led), .seg(seg), .an(an), .dp(dp));

    // TX 핀 복조 (1-1 uart_rx 그대로)
    wire [7:0] got;
    wire got_valid, fe, ov;
    reg mon_resetn = 0;
    uart_rx #(.CLK_HZ(CLK_HZ), .BAUD(BAUD)) mon (
        .clk(clk), .resetn(mon_resetn), .rx_i(txd), .out_data_o(got), .out_valid_o(got_valid),
        .out_ready_i(1'b1), .framing_error_o(fe), .overrun_o(ov));

    reg [7:0] rxq [0:255];
    integer rx_wr = 0;
    always @(posedge clk) if (got_valid) begin
        rxq[rx_wr[7:0]] = got;
        rx_wr = rx_wr + 1;
    end

    task automatic send_byte(input [7:0] b);
        integer k;
        begin
            @(negedge clk); rxd = 0; repeat (CPB) @(negedge clk);
            for (k = 0; k < 8; k = k + 1) begin rxd = b[k]; repeat (CPB) @(negedge clk); end
            rxd = 1; repeat (CPB) @(negedge clk);
        end
    endtask

    integer fd, n_tx, n_rx, i, v, sel, cases = 0, rx_rd = 0, t, code;
    reg [8*8-1:0] subj;
    reg [8*200-1:0] line;
    reg [7:0] tx [0:15];
    reg [7:0] exp [0:31];
    reg [15:0] led_exp;
    reg [8*4-1:0] tag;

    initial begin
        fd = $fopen($sformatf("p01/tb/p01_cases_s%0d.txt", STAGE), "r");
        if (fd == 0) $fatal(1, "p01_cases_s%0d.txt 없음: python3 p01/reference/p01_model.py 먼저", STAGE);
        code = $fgets(line, fd);                         // 머리 줄
        repeat (5) @(posedge clk);
        btnC = 0; mon_resetn = 1;
        repeat (10) @(posedge clk);
        forever begin
            code = $fscanf(fd, "%s", subj);
            if (code != 1) $fatal(1, "사례 파일 끝에 END 줄 없음");
            if (subj == "END") begin
                code = $fscanf(fd, "%h", v); led_exp = v;
                repeat (20) @(posedge clk);
                if (led !== led_exp) $fatal(1, "LED=%04h 기대 %04h", led, led_exp);
                if (fe || ov) $fatal(1, "TX 복조 오류 fe=%0d ov=%0d", fe, ov);
                $display("P01_BOARD_TOP_LED_PASS stage=%0d led=0x%04h", STAGE, led);
                $display("P01_TOP_RTL_SIM_PASS stage=%0d cases=%0d bytes=%0d", STAGE, cases, rx_wr);
                $finish;
            end
            code = $fscanf(fd, "%h %h", sel, n_tx);
            for (i = 0; i < n_tx; i = i + 1) begin code = $fscanf(fd, "%h", v); tx[i] = v; end
            code = $fscanf(fd, "%h", n_rx);
            for (i = 0; i < n_rx; i = i + 1) begin code = $fscanf(fd, "%h", v); exp[i] = v; end
            sw = sel;
            repeat (8) @(posedge clk);                    // 스위치 2FF 동기화 대기
            for (i = 0; i < n_tx; i = i + 1) send_byte(tx[i]);
            t = 0;
            while (rx_wr - rx_rd < n_rx) begin
                @(posedge clk); t = t + 1;
                if (t > 40 * CPB * (n_rx + 2)) $fatal(1, "%0s 응답 시간 초과: %0d/%0d 바이트", subj, rx_wr - rx_rd, n_rx);
            end
            for (i = 0; i < n_rx; i = i + 1)
                if (rxq[(rx_rd + i) % 256] !== exp[i])
                    $fatal(1, "%0s 응답 %0d번째 바이트 %02h 기대 %02h", subj, i, rxq[(rx_rd + i) % 256], exp[i]);
            $write("P01_CASE_PASS stage=%0d %0s sw=%0d rx=\"", STAGE, subj, sel);
            for (i = 0; i < n_rx; i = i + 1)
                if (exp[i] == 8'h0D) $write("\\r"); else if (exp[i] == 8'h0A) $write("\\n"); else $write("%c", exp[i]);
            $display("\"");
            rx_rd = rx_rd + n_rx;
            cases = cases + 1;
        end
    end

    // 7세그먼트: an이 켠 자리에 led의 그 자리 16진수가 보여야 한다 (한 번 확인)
    initial begin
        #200000;
        if (an == 4'b1111) $fatal(1, "7세그먼트 자리가 하나도 켜지지 않음");
    end

#!/usr/bin/env python3
"""1장 UART 계산기 기준 모델.

명령 순서(보낼 바이트, sw 값)를 정하고, 보드가 돌려줄 응답 바이트를 계산해
p01/tb/p01_cases_s{STAGE}.txt로 쓴다 (STAGE = 끝낸 서브젝트 수 1~4, 보드 Top 빌드 옵션과 같음).
TB는 이 파일만 보고 판정한다.

  python3 p01/reference/p01_model.py          # 자체 시험 + 사례 파일 생성
"""
import os
import struct
import sys

ACC_WIDTH = 40
CORE = {0: 2, 1: 3, 2: 4, 3: 4}  # sw 값 → 서브젝트 번호 (1-2 mac_core, 1-3 DSP+누산, 1-4 파이프라인)
LAT = {2: 1, 3: 2, 4: 2}         # 서브젝트별 지연 클록: 1-2 = 1, 1-3 = 곱 레지스터 + 누산 레지스터 = 2, 1-4 = 2
HERE = os.path.dirname(os.path.abspath(__file__))
OUT = os.path.join(HERE, "..", "tb", "p01_cases_s%d.txt")


def wrap(v):
    """40비트 2의 보수로 접는다 (RTL 누산기와 같음)."""
    v &= (1 << ACC_WIDTH) - 1
    return v - (1 << ACC_WIDTH) if v >> (ACC_WIDTH - 1) else v


class Calc:
    def __init__(self, stage=4):
        self.acc = 0
        self.stage = stage

    def step(self, sel, data):
        """보낼 바이트 → 응답 바이트."""
        op = data[0]
        if self.stage < 2 and op != ord("S"):
            return bytes([op])      # 1-1까지: MAC 코어가 없어 'M'·'C'도 에코
        if op == ord("M"):
            a, b = struct.unpack(">hh", bytes(data[1:5]))
            self.acc = wrap(self.acc + a * b)
            core = min(CORE[sel], self.stage)           # 아직 없는 코어는 앞 코어가 대신
            text = "A:%010X L:%X\r\n" % (self.acc & ((1 << ACC_WIDTH) - 1), LAT[core])
            return text.encode()
        if op == ord("C"):
            self.acc = 0
            return b"OK\r\n"
        if op == ord("S"):
            return b"I\r\n"
        return bytes([op])          # 1-1 에코


def m(a, b):
    return [ord("M")] + list(struct.pack(">hh", a, b))


C = [ord("C")]

# (서브젝트, sw, 보낼 바이트). 안내서 '보드에서 볼 것' 절차와 똑같은 순서다.
# 서브젝트마다 'C'로 누산값을 0으로 만들고 시작하므로, 어느 서브젝트부터 보드에서 해도 화면이 같다.
CASES = [
    ("1-1", 0, [ord("Z")]),
    ("1-1", 0, [ord("5")]),
    ("1-1", 0, [ord("S")]),
    ("1-2", 0, C),
    ("1-2", 0, m(3, 4)),
    ("1-2", 0, m(3, 4)),
    ("1-3", 0, C),
    ("1-3", 1, m(3, 4)),
    ("1-3", 0, m(3, 4)),
    ("1-3", 1, m(-2, 5)),
    ("1-4", 0, C),
    ("1-4", 2, m(-32768, 32767)),
    ("1-4", 2, m(100, -7)),
    ("1-4", 0, m(32767, 32767)),
]


def self_test():
    c = Calc()
    assert c.step(0, m(3, 4)) == b"A:000000000C L:1\r\n"
    assert c.step(0, m(3, 4)) == b"A:0000000018 L:1\r\n"
    assert c.step(2, m(1, 1)) == b"A:0000000019 L:2\r\n"
    assert c.step(0, [ord("C")]) == b"OK\r\n"
    assert c.step(1, m(-1, 1)) == b"A:FFFFFFFFFF L:2\r\n"
    assert wrap((1 << 39)) == -(1 << 39)
    c3 = Calc(stage=3)
    assert c3.step(2, m(1, 1)) == b"A:0000000001 L:2\r\n"   # sw=2인데 1-4가 없으면 1-3 코어
    c2 = Calc(stage=2)
    assert c2.step(1, m(1, 1)) == b"A:0000000001 L:1\r\n"   # sw=1인데 1-3이 없으면 1-2 코어
    c1 = Calc(stage=1)
    assert c1.step(0, m(3, 4)) == b"M" and c1.step(0, [ord("S")]) == b"I\r\n"
    print("PYTHON_P01_SELF_TEST_PASS")


def main():
    self_test()
    for stage in range(1, 5):
        c = Calc(stage)
        lines = ["# subject sel n_tx tx... n_rx rx... (16진수). p01_model.py가 만든다. 직접 고치지 않는다."]
        cases = [x for x in CASES if int(x[0][2]) <= stage]
        if stage == 1:
            cases = cases + [("1-1", 0, m(3, 4)[:1])]   # 1-1 빌드에서 'M'은 에코
        for subj, sel, data in cases:
            resp = c.step(sel, data)
            lines.append(" ".join([subj, "%x" % sel, "%x" % len(data)] + ["%02x" % x for x in data]
                                  + ["%x" % len(resp)] + ["%02x" % x for x in resp]))
            if stage == 4:
                print("PYTHON_P01_CASE %s sw=%d tx=%s rx=%r" % (subj, sel, bytes(data).hex(), resp.decode()))
        lines.append("END %04x" % (c.acc & 0xFFFF))
        with open(OUT % stage, "w", encoding="utf-8") as f:
            f.write("\n".join(lines) + "\n")
        print("PYTHON_P01_VECTORS stage=%d cases=%d final_led=0x%04X" % (stage, len(cases), c.acc & 0xFFFF))
    return 0


if __name__ == "__main__":
    sys.exit(main())
