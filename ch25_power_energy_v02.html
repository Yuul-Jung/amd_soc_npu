ch25/reference/energy.py · python · 원본 · ⚠ 미검증
#!/usr/bin/env python3
"""25장: 전력 보고서 두 개(A 기본, B NPU 활동 가정)와 23장 시간(CSV)으로 추론 1회 에너지를 추정한다.

E = P × t. P는 report_power의 Total On-Chip Power(W), t는 23장 보드 측정 클록 / 100 MHz.
CPU 추론 에너지는 A(NPU 쉬는 상태)를, NPU 추론 에너지는 B(NPU 활동 가정)를 쓴다 — 둘 다 추정이다.
보고서 형식은 Vivado 2024.2 텍스트 보고서를 가정했다(⚠ 실제 보고서로 미확인).
"""
from __future__ import annotations
import csv
import re
import sys
from pathlib import Path


def power(text):
    tot = re.search(r"\|\s*Total On-Chip Power \(W\)\s*\|\s*([\d.]+)", text)
    dyn = re.search(r"\|\s*Dynamic \(W\)\s*\|\s*([\d.]+)", text)
    sta = re.search(r"\|\s*Device Static \(W\)\s*\|\s*([\d.]+)", text)
    conf = re.search(r"\|\s*Confidence Level\s*\|\s*(\w+)", text)
    return {"total": float(tot.group(1)), "dynamic": float(dyn.group(1)), "static": float(sta.group(1)),
            "confidence": conf.group(1) if conf else "?"} if tot and dyn and sta else None


def main(rep_dir, csv_path=None):
    d = Path(rep_dir)
    a = power((d / "power_default.rpt").read_text())
    b = power((d / "power_npu_active.rpt").read_text())
    if not a or not b:
        print("POWER_PARSE_FAIL"); return 1
    for k, p in (("A_default", a), ("B_npu_active", b)):
        print(f"POWER {k} total={p['total']:.3f}W dynamic={p['dynamic']:.3f}W static={p['static']:.3f}W confidence={p['confidence']}")
    if csv_path and Path(csv_path).exists():
        rows = [r for r in csv.DictReader(open(csv_path)) if r.get("image", "").isdigit()]
        cpu = sum(int(r["cpu_clk"]) for r in rows) / len(rows) / 100e6
        npu = sum(int(r["npu_load_clk"]) + int(r["npu_run_clk"]) for r in rows) / len(rows) / 100e6
        print(f"ENERGY cpu={a['total'] * cpu * 1e6:.2f}uJ (P_A×{cpu * 1e6:.1f}us)  npu={b['total'] * npu * 1e6:.2f}uJ (P_B×{npu * 1e6:.1f}us)  [추정]")
    else:
        print("ENERGY NOT_RUN (23장 보드 측정 CSV 없음)")
    print("POWER_PARSE_PASS")
    return 0


if __name__ == "__main__":
    sys.exit(main(*sys.argv[1:]))

04테스트벤치·기준 모델 작성

테스트벤치는 출력을 자동 판정합니다. RTL 시뮬레이션이 아니라 정적 검사입니다. ① Tcl 괄호·따옴표 짝과 보고서 2개·가정 초기화 확인 ② 작성한 견본 전력 보고서 2개와 견본 CSV(ch25/host/fixture/, 실제 출력 아님)로 계산기 시험 ③ 실제 보고서가 있으면 계산. 견본 숫자는 결과가 아닙니다.

ch25/scripts/run_check.sh · bash · 원본 · ⚠ 미검증
#!/usr/bin/env bash
set -euo pipefail
cd -- "$(dirname -- "${BASH_SOURCE[0]}")/.."
export PYTHONDONTWRITEBYTECODE=1
echo "tclsh $(echo 'puts [info patchlevel]' | tclsh)"
tclsh <<'TCL'
set fh [open vivado/report_power.tcl]; set t [read $fh]; close $fh
if {![info complete $t]} { puts "TCL_SYNTAX_STATIC_CHECK_FAIL"; exit 1 }
puts "TCL_SYNTAX_STATIC_CHECK_PASS power_reports=[regexp -all {report_power -file} $t] activity_reset=[regexp -all {reset_switching_activity} $t]"
TCL
python3 reference/energy.py host/fixture host/fixture/bench.csv | sed -e 's/^POWER_PARSE_PASS/ENERGY_PARSER_STATIC_CHECK_PASS fixture/' -e '/^ENERGY_PARSER/!s/^/[견본·실측 아님] /'
if [ -d ../build/ch25 ]; then python3 reference/energy.py ../build/ch25 "$(ls ../ch23/validation/board_bench_*.csv 2>/dev/null | tail -1)"; else echo "REAL_POWER NOT_RUN (Vivado 미실행)"; fi

06결과 판정

확인 항목의미
TCL_SYNTAX_STATIC_CHECK_PASS power_reports=2 activity_reset=1보고서 A·B 두 번, 가정을 되돌리는 reset_switching_activity 한 번
ENERGY_PARSER_STATIC_CHECK_PASS fixture견본 보고서에서 Total·Dynamic·Static·Confidence를 읽고 E = P × t를 계산 (견본 숫자는 결과가 아님)
REAL_POWER NOT_RUN (Vivado 미실행)실제 보고서·보드 시간이 아직 없음 → 8절 표는 ⚠ 미측정

실패 시: TB의 $fatal 메시지에 표시된 cycle 번호와 기대값/실제값을 확인하고, 03절 코드와 한 줄씩 대조합니다. 하나라도 실패하면 다음 장으로 넘어가지 않습니다.

07코드 읽기 포인트

위치내용
추정과 실측report_power는 넷 토글률 가정으로 계산한 추정입니다. 보드 전류를 잰 값이 아니므로 표에 Confidence Level을 함께 적고 '추정'이라고 씁니다.
같은 조건A·B는 같은 구현 결과, 같은 100 MHz, 같은 주변 조건(Vivado 기본값)이고 B에서 NPU 계층 토글률만 바꿉니다. 그래야 두 숫자의 차이를 NPU 활동으로 읽을 수 있습니다.
가정 분리B의 토글률 25%는 비교용 가정이며 power_info.txt에 그대로 남깁니다. 실제 활동을 쓰려면 배선 후 시뮬레이션의 SAIF를 읽어야 하는데, 이 장에서는 하지 않습니다.
에너지 식추론 1회 에너지 = 전력 × 시간. CPU는 NPU가 쉬는 A 전력, NPU는 B 전력에 입력 적재 + 실행 시간을 곱합니다. 시간이 짧아도 적재 시간이 길면 에너지 이득이 줄어듭니다.
