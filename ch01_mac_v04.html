제01장 · DSP 추론 MAC 누산

mac_core로 INT16 signed 곱셈·누산을 클록 1회에 처리하는 구조를 익힙니다. 이후 모든 PE·Dense·NPU 계층이 이 모듈을 재사용합니다.

DSP 추론Reset>Clear>Valid40비트 누산

00개요

mac_core는 클록 1회에 16×16 부호 있는 곱을 40비트 누산기에 더합니다. clear_i는 누산기를 0으로 돌리는 트랜잭션 경계 신호입니다. 이 모듈은 02장 DSP 곱셈, 07장 Vector Dot, 08장 4PE, 09장 Dense, 10장 NPU Core에서 계속 재사용됩니다.

범위이 장은 단독 MAC 누산기만 다룹니다. 파이프라인 버전은 03장, 벡터 길이 FSM은 07장에서 추가합니다.

01모듈 구조

resetn·clear_i·valid_i·a_i·b_i → acc_o·valid_o. 비동기 출력 변경은 타이밍 위반으로 판정합니다.

02RTL 전체 소스

ch01/rtl/mac_core.v · verilog
`timescale 1ns/1ps
`default_nettype none

// 독립 signed MAC: 보드 및 AXI에 의존하지 않는다.
(* use_dsp = "yes" *)
module mac_core #(
    parameter integer DATA_WIDTH = 16,
    parameter integer ACC_WIDTH = 40
) (
    input wire clk,
    input wire resetn,
    input wire clear_i,
    input wire valid_i,
    input wire signed [DATA_WIDTH-1:0] a_i,
    input wire signed [DATA_WIDTH-1:0] b_i,
    output reg signed [ACC_WIDTH-1:0] acc_o,
    output reg valid_o
);
    localparam integer PRODUCT_WIDTH = 2 * DATA_WIDTH;
    wire signed [PRODUCT_WIDTH-1:0] product_w;
    wire signed [ACC_WIDTH-1:0] product_ext_w;

    // 전체 곱을 보존한 뒤 부호 비트를 복제하여 누산 폭으로 확장한다.
    // 지원 조건: DATA_WIDTH >= 2, ACC_WIDTH >= 2*DATA_WIDTH.
    assign product_w = $signed(a_i) * $signed(b_i);
    assign product_ext_w = {{(ACC_WIDTH-PRODUCT_WIDTH){product_w[PRODUCT_WIDTH-1]}}, product_w};

    // 동기식 Active-Low Reset > Clear > Valid 순서.
    // 입력을 수락한 상승 에지 직후 acc_o와 valid_o가 함께 갱신된다.
    // valid_i=0이면 acc_o 유지, valid_o=0. Clear와 겹친 입력은 버린다.
    always @(posedge clk) begin
        if (!resetn) begin
            acc_o <= {ACC_WIDTH{1'b0}};
            valid_o <= 1'b0;
        end else if (clear_i) begin
            acc_o <= {ACC_WIDTH{1'b0}};
            valid_o <= 1'b0;
        end else begin
            valid_o <= valid_i;
            if (valid_i)
                // 범위 초과 시 상위 비트를 버리는 2의 보수 순환 연산이다.
                acc_o <= acc_o + product_ext_w;
        end
    end

    // synthesis translate_off
    initial begin
        if (DATA_WIDTH < 2 || ACC_WIDTH < PRODUCT_WIDTH)
            $fatal(1, "Require DATA_WIDTH>=2 and ACC_WIDTH>=2*DATA_WIDTH");
    end
    // synthesis translate_on
endmodule
`default_nettype wire

03자동 테스트벤치 전체 소스

ch01/tb/tb_mac_core.sv · systemverilog
`timescale 1ns/1ps
`default_nettype none
module tb_mac_core;
    parameter integer DATA_WIDTH = 16;
    parameter integer ACC_WIDTH = 40;
    reg clk = 0;
    reg resetn = 0, clear_i = 0, valid_i = 0;
    reg signed [DATA_WIDTH-1:0] a_i = 0, b_i = 0;
    wire signed [ACC_WIDTH-1:0] acc_o;
    wire valid_o;
    mac_core #(.DATA_WIDTH(DATA_WIDTH), .ACC_WIDTH(ACC_WIDTH)) dut (.*);
    always #5 clk = ~clk;

    integer vectors, actual, fields, cycle = 0;
    integer rn, cl, vi, ai, bi, expected_valid;
    reg signed [ACC_WIDTH-1:0] expected_acc;
    reg signed [ACC_WIDTH-1:0] previous_acc;
    reg previous_valid;
    longint signed model_acc = 0;
    longint signed model_product;
    reg model_valid;
    string vectors_path, actual_path;

    initial begin
        if (!$value$plusargs("VECTORS=%s", vectors_path) ||
            !$value$plusargs("ACTUAL=%s", actual_path))
            $fatal(1, "Missing VECTORS/ACTUAL path");
        vectors = $fopen(vectors_path, "r");
        actual = $fopen(actual_path, "w");
        if (!vectors || !actual) $fatal(1, "Cannot open vector/trace file");
        // 첫 상승 에지에서 동기식 Reset을 적용하여 알려진 상태를 만든다.
        @(posedge clk); #1;
        if (acc_o !== 0 || valid_o !== 0) $fatal(1, "Initial reset failed");
        while (!$feof(vectors)) begin
            fields = $fscanf(vectors, "%d %d %d %d %d %d %d\n",
                              rn, cl, vi, ai, bi, expected_acc, expected_valid);
            if (fields != 7) $fatal(1, "Malformed vector row");
            @(negedge clk);
            previous_acc = acc_o;
            previous_valid = valid_o;
            resetn = rn; clear_i = cl; valid_i = vi; a_i = ai; b_i = bi;
            #1;
            // 입력 변경만으로 출력이 변하면 동기식 타이밍 위반이다.
            if (acc_o !== previous_acc || valid_o !== previous_valid)
                $fatal(1, "Output changed before rising edge cycle=%0d", cycle+1);
            @(posedge clk); #1; // NBA 갱신 이후 같은 에지의 결과를 검사한다.
            cycle = cycle + 1;
            // Python 파일 외에도 SV의 64비트 정수 산술로 독립 계산한다.
            // 이 TB의 실행 설정은 ACC_WIDTH<=40이므로 곱과 합이 64비트에 들어간다.
            model_product = $signed(a_i);
            model_product = model_product * $signed(b_i);
            model_valid = rn && !cl && vi;
            if (!rn || cl) model_acc = 0;
            else if (vi) model_acc = model_acc + model_product;
            model_acc = $signed(model_acc[ACC_WIDTH-1:0]);
            if (expected_acc !== model_acc[ACC_WIDTH-1:0] || expected_valid[0] !== model_valid)
                $fatal(1, "SV/Python reference mismatch cycle=%0d", cycle);
            if (acc_o !== expected_acc || valid_o !== expected_valid[0])
                $fatal(1, "cycle=%0d a=%0d b=%0d expected=%0d/%0d actual=%0d/%0d",
                       cycle, a_i, b_i, expected_acc, expected_valid, acc_o, valid_o);
            $fdisplay(actual, "%0d %0d %0d", cycle, acc_o, valid_o);
        end
        if (cycle == 0) $fatal(1, "Empty vector file");
        $fclose(vectors); $fclose(actual);
        $display("RTL_SIM_PASS INT%0d/%0d cycles=%0d", DATA_WIDTH, ACC_WIDTH, cycle);
        $finish;
    end
    initial begin
        #10000000;
        $fatal(1, "Simulation timeout");
    end
endmodule
`default_nettype wire

05실행 결과 확인

테스트벤치의 자동 판정에서 오류가 발생하지 않고 RTL_SIM_PASS INT16/40 cycles=35304가 출력되어야 합니다. 시뮬레이션 결과는 합성·실물 보드 확인과 구분합니다.

벡터 파일 기반 시험으로 Reset·Clear·Valid 조합·누산 오버플로(2의 보수 순환)를 모두 검증합니다. DATA_WIDTH·ACC_WIDTH 파라미터는 추론 대상이며 합성 후 DSP48E1 사용 여부는 (* use_dsp="yes" *) 힌트로 확인합니다. 실행 스크립트는 같은 장에서 두 번째 정밀도 설정도 함께 돌립니다(INT8/32 cycles=133224 추가 통과). 또한 Python 기준 모델 자체 시험과 RTL 출력 ↔ Python 기준값 비교(PYTHON_RTL_COMPARE_PASS)를 같이 판정합니다.

06핵심 코드 풀이

부호 확장: product_ext_w = {{(ACC_WIDTH-PRODUCT_WIDTH){product_w[PRODUCT_WIDTH-1]}}, product_w}은 32비트 곱의 부호 비트를 40비트까지 복제합니다. 음수 곱도 올바르게 누산됩니다.

Reset > Clear > Valid 우선순위: !resetn이 최우선, 그 다음 clear_i, 마지막으로 valid_i를 처리합니다. 이 계약은 02·03·07장도 그대로 따릅니다.

2의 보수 순환: ACC_WIDTH가 초과되면 상위 비트를 버리는 wrap-around가 발생합니다. 테스트벤치 SV 모델에서 $signed(model_acc[ACC_WIDTH-1:0])으로 명시적으로 동일하게 처리합니다.

DSP 추론: (* use_dsp = "yes" *)는 합성 힌트입니다. 시뮬레이션에서는 무시되며 Vivado 합성 후 Resource 탭에서 DSP48E1 사용 여부를 확인합니다.
