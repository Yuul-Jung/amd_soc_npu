제06장 · INT8·INT16 정밀도 비교

05장 양자화기 두 개로 같은 입력을 INT8·INT16으로 동시에 변환해 오차와 오버플로를 비교합니다.

목표: 05장 양자화기 두 개로 같은 입력을 INT8·INT16으로 동시에 변환해 오차와 오버플로를 비교합니다.

실습 순서: 01 구조 확인 → 02 준비 → 03 RTL 작성 → 04 테스트벤치·기준 모델 작성 → 05 시뮬레이션 → 06 결과 판정 → 08 합성·타이밍(Vivado) → 09 인계.

01구조도

구현 도식: 포트 이름·폭과 하위 인스턴스는 ch06/rtl/precision_compare.v 선언에서 자동으로 가져왔습니다.

방향포트폭구분설명
inputclk1클록시스템 클록 (상승 에지에서 모든 레지스터 갱신)
inputresetn1리셋동기 리셋, 0이면 초기화 (Active-Low)
inputvalid_i1데이터·제어이번 클록에 x_i를 두 정밀도로 변환
inputx_i[31:0]데이터·제어공통 signed 32비트 입력
outputq8_o[7:0]데이터·제어INT8 결과 (SHIFT=8)
outputq16_o[15:0]데이터·제어INT16 결과 (SHIFT=4)
outputoverflow8_o1데이터·제어INT8 범위 초과
outputoverflow16_o1데이터·제어INT16 범위 초과
outputvalid_o1데이터·제어두 출력이 유효함 (INT8 인스턴스 기준)

03RTL 작성

아래 파일을 경로 그대로 만들고 전체 코드를 입력합니다.

ch06/rtl/precision_compare.v · verilog · 원본 · RTL_SIM 통과 2026-11-18
`timescale 1ns/1ps
module precision_compare #(parameter integer SATURATE=1)(
    input wire clk, resetn, valid_i,
    input wire signed [31:0] x_i,
    output wire signed [7:0] q8_o,
    output wire signed [15:0] q16_o,
    output wire overflow8_o, overflow16_o, valid_o
);
    // 같은 원본을 서로 다른 소수부 정밀도로 변환하되 반올림 규칙은 공유한다.
    fixed_quantizer #(.OUT_WIDTH(8),.SHIFT(8),.ROUND(1),.SATURATE(SATURATE)) q8
      (.clk(clk),.resetn(resetn),.valid_i(valid_i),.x_i(x_i),.q_o(q8_o),.valid_o(valid_o),.overflow_o(overflow8_o));
    fixed_quantizer #(.OUT_WIDTH(16),.SHIFT(4),.ROUND(1),.SATURATE(SATURATE)) q16
      (.clk(clk),.resetn(resetn),.valid_i(valid_i),.x_i(x_i),.q_o(q16_o),.valid_o(),.overflow_o(overflow16_o));
endmodule

04테스트벤치·기준 모델 작성

테스트벤치는 출력을 자동 판정합니다. 기준 모델(Python)은 시험 벡터와 정답을 만듭니다.

ch06/tb/tb_precision_compare.sv · systemverilog · 원본 · RTL_SIM 통과 2026-11-18
`timescale 1ns/1ps
module tb_precision_compare;
    reg clk=0,rn=0,vi=0;
    reg signed [31:0] x=0;
    wire signed [7:0] q8[0:1]; wire signed [15:0] q16[0:1];
    wire o8[0:1],o16[0:1],v[0:1];
    genvar g;
    generate for(g=0;g<2;g=g+1) begin: policies
        precision_compare #(.SATURATE(g)) dut(.clk(clk),.resetn(rn),.valid_i(vi),.x_i(x),
          .q8_o(q8[g]),.q16_o(q16[g]),.overflow8_o(o8[g]),.overflow16_o(o16[g]),.valid_o(v[g]));
    end endgenerate
    always #5 clk=~clk;
    integer f,o,n,c=0,r,vin,xi,e[0:7],ev,i;
    string vp,ap;
    initial begin
        if(!$value$plusargs("VECTORS=%s",vp)||!$value$plusargs("ACTUAL=%s",ap)) $fatal(1,"Paths");
        f=$fopen(vp,"r");o=$fopen(ap,"w"); if(!f||!o) $fatal(1,"Open");
        @(posedge clk);#1;
        while(!$feof(f)) begin
            n=$fscanf(f,"%d %d %d %d %d %d %d %d %d %d %d %d\n",r,vin,xi,
              e[0],e[1],e[2],e[3],e[4],e[5],e[6],e[7],ev);
            if(n!=12) $fatal(1,"Row");
            @(negedge clk);rn=r;vi=vin;x=xi;
            @(posedge clk);#1;c=c+1;
            for(i=0;i<2;i=i+1) if($signed(q8[i])!==e[4*i]||$signed(q16[i])!==e[4*i+1]||
              o8[i]!==e[4*i+2][0]||o16[i]!==e[4*i+3][0]||v[i]!==ev[0])
              $fatal(1,"Mismatch cycle=%0d mode=%0d x=%0d q=%0d/%0d expected=%0d/%0d flags=%b/%b v=%b expectedv=%0d",
                c,i,x,q8[i],q16[i],e[4*i],e[4*i+1],o8[i],o16[i],v[i],ev);
            $fdisplay(o,"%0d %0d %0d %0d %0d %0d %0d %0d %0d %0d",c,
              q8[0],q16[0],o8[0],o16[0],q8[1],q16[1],o8[1],o16[1],v[0]);
        end
        if(!c) $fatal(1,"Empty");
        $fclose(o);$display("RTL_SIM_PASS PRECISION cycles=%0d",c);$finish;
    end
    initial begin #10000000;$fatal(1,"Timeout");end
endmodule

import argparse
import csv
import random
import sys
from pathlib import Path
sys.path.insert(0,str(Path(__file__).resolve().parents[2]/'ch05/reference'))
from fixed_reference import quantize, self_test, compare


def generate(out):
    assert quantize(4096,8,8)[0]*16 == quantize(4096,16,4)[0]
    assert quantize(128,8,8)[0]*16 != quantize(128,16,4)[0]
    xs=[0,4096,-4096,127,128,129,-127,-128,-129,32767,32768,-32768,-32769,
        524279,524280,524288,-524288,-524289,2147483647,-2147483648]
    rng=random.Random(306)
    xs += [rng.randint(-1000000,1000000) for _ in range(2000)]
    state=[0]*8
    with (out/'vectors.txt').open('w') as vf,(out/'expected.txt').open('w') as ef,(out/'comparison.csv').open('w') as cf:
        csvout=csv.writer(cf,lineterminator='\n')
        csvout.writerow(['cycle','x_q12','sat','q8_q4','q16_q8','err8_q12','err16_q12','class'])
        for c,x in enumerate(xs,1):
            rn=int(c%97!=0); vi=int(c%7!=0); ev=rn and vi
            if not rn: state=[0]*8
            elif vi:
                state=[]
                for sat in (0,1):
                    q8,o8=quantize(x,8,8,1,sat); q16,o16=quantize(x,16,4,1,sat)
                    state += [q8,q16,o8,o16]
                    e8,e16=q8*256-x,q16*16-x
                    kind='range' if o8 or o16 else ('exact' if e8==e16==0 else 'quantized')
                    csvout.writerow([c,x,sat,q8,q16,e8,e16,kind])
            vf.write(' '.join(map(str,(rn,vi,x,*state,int(ev))))+'\n')
            ef.write(' '.join(map(str,(c,*state,int(ev))))+'\n')
    print(f'PYTHON_VECTORS PRECISION cycles={len(xs)} seed=306')


if __name__=='__main__':
    p=argparse.ArgumentParser(); p.add_argument('--out',type=Path); p.add_argument('--actual',type=Path)
    a=p.parse_args(); self_test()
    if a.actual: compare(a.out/'expected.txt',a.actual)
    else: generate(a.out)

07코드 읽기 포인트

위치내용
구조적 래퍼05장 fixed_quantizer를 그대로 가져다 쓰는 순수 구조적 모듈입니다. 로직이 없으므로 별도 FSM·레지스터가 없습니다.
SHIFT 선택INT8은 SHIFT=8(소수부 8비트 버림), INT16은 SHIFT=4(소수부 4비트 버림). 같은 입력에 대해 INT16이 더 넓은 가수를 보존해 오버플로가 적게 발생합니다.
valid_o 공유INT8 인스턴스의 valid_o를 외부로 노출합니다. 두 인스턴스가 같은 valid_i를 받으므로 출력도 항상 같은 클록에 유효합니다.
