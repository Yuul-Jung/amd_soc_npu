00제3부 실습 개요

MAC·DSP·BRAM·Fixed Point·4PE를 하나씩 제작하고 UART 입력으로 실제 모델을 적재하여 4개 점수와 Class를 확인합니다. 독립 RTL의 시험과 새 통합 프로젝트의 시험은 구분합니다.

02VS Code 실행 절차

Ubuntu Icarus Verilog 설치 환경에서 각각의 테스트를 실제 실행합니다. 출력 로그와 PC 정수 기준값을 확인한 뒤 다음 장으로 이동합니다.

Ubuntu Terminal · 공통 실행 순서
# 1. 공통 UART Echo
bash part03/ch00/scripts/run_sim.sh
# 2. DSP 4PE 독립 누적 경로
bash part03/mini_npu/scripts/run_engine.sh
# 3. UART RX→NPU→UART TX 전체 검사
bash part03/mini_npu/scripts/run_demo.sh
# 4. 독립 01~10장 포함 전체 회귀
bash part03/mini_npu/scripts/run_batch_00_12.sh
