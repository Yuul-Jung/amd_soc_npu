## 3. 추가 시험 범위

`mini_npu/tb/tb_uart_core_fifo.sv` (CPB=10 고속 단위 시험, 매 클록 포인터·카운트 불변식 검사)

- T1 Reset 기본값 / T2 TX 용량 17(PHY1+FIFO16)·Full 동시 Push/Pop / T3 valid=0 무전송·Empty pop 없음
- T4 RX 17바이트 무손실·Full 동시 Push/Pop / T5 18번째만 overrun 손실 / T6 무작위 ready 64바이트 연속 수신
- T7 Full duplex / T8 Framing error / T9 TX 중 Reset / T10 RX 중 Reset / T11 Reset 없는 송신 중단 관측
- 변이 시험: FIFO 결함 6종(pop 우회 제거 RX/TX, Full 경계 15, TX 과충전, 동시 Push/Pop 카운트 오류, TX 포인터 Reset 누락) 모두 검출

`mini_npu/tb/tb_npu_uart_adversarial.sv` (실제 115200bps 핀)

- A1 `S`·CR/LF 무시 / A2 잘못된 Opcode 4종 ERR / A3 주소·뉴런·길이 오류 8종 ERR, 경계 63 OK 2종
- A4 응답 전송 중 `0~3` 연속 명령 순서 보존 / A5 `S` 20개 폭주 무손실 / A6 응답 중 Reset 후 잔류 없음
- A7 명령 중단 Timeout 부재 관측 / A8 Framing error LED15 래치

## 4. 미해결·설계 제약 (프로토콜 변경 금지로 미수정)

1. 명령 Timeout 없음: 페이로드가 덜 온 채 중단되면 Controller가 RECV에 머물고 다음 바이트를 페이로드로 소비. btnC Reset으로만 복구.
2. 8N1 특성상 송신 중단 프레임은 남은 비트가 1로 수신되어 정상 바이트로 적재될 수 있음(T11).
3. 00장 `tb_uart_echo.sv` 자체는 Reset·Framing을 판정하지 않음. FIFO 경계 시험으로 보완.
