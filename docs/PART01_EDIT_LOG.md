## 07 AXI UART Lite

- 이번 캡처에는 디버그 실행 과정에서 시작 안내문이 두 번 출력된 상태가 보입니다.
- 실기 확인 성공:
- Basys3 + Vitis Unified IDE 2024.2 + moserial에서 115200 8N1 UART Echo 동작 확인. A, B, 1의 개별 Watch 관찰은 별도 확장 확인 항목입니다.
- 실제 Xilinx IP 시뮬레이션은 아직 수행하지 않았습니다.
- Verilog 구문 검사를 FPGA 동작 확인으로 취급하지 않습니다.
- 원문 VHDL 예제의 코드를 1:1 번역한 것이 아니라, 실제 AXI UART Lite IP
- 현재 이 환경에서는 Vivado 2024.2의 IP 생성 및 실제 RTL 시뮬레이션을 실행하지 않았으므로, 이 메시지를 실측 성공 기록으로 취급하지 않는다.
- UART Echo는 보드에서 확인됐으며, 개별 Watch 변수값은 아직 확인되지 않았습니다.

## 08 AXI Timer

- 실제 보드에서 반복 점멸은 확인했지만, 정확한 0.5초 간격은 정밀 계측하지 않았습니다.

- expire_count는 폴링 루프가 수행한 만료 처리 횟수이지 외부 측정기로 계측한 정밀한 시간값이 아닙니다.

## 09 AXI Interrupt Controller

- 정확한 주기는 정밀 계측하지 않았습니다.
- AMD 외부 이미지가 표시되지 않는 환경입니다.
- PG099 v4.1 원본 PDF 5쪽 Figure 1-1을 직접 열어 확인합니다.
- 외부 이미지 제공 여부와 무관하게 원본 문서에서 직접 그림을 확인할 수 있습니다.
- 공식 기준: AMD PG079 · Timer Interrupts. Timer 내부 Counter 구조 원본은 08장 PG079 그림을 참조합니다.
- AMD PG099 v4.1 · 15~16쪽 Table 2-4 Register Address Mapping · 레지스터별 비트 배치 그림은 원본 PDF 16~23쪽을 참조합니다.
