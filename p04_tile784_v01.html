제4장 · 784 가속기 설계 공간

784 입력을 타일 13개로 나눠 누산하고, INT8과 INT16의 차이, PE 개수에 따른 클록 수를 비교합니다.

00 장 목표

장 시연 (보드): PC가 28×28 원본 손글씨를 타일 13개로 나눠 보내면, 보드가 3장 코어로 784개 입력을 누산해 분류합니다. 같은 그림이 INT8에서는 4, INT16에서는 정답 9로 갈리고, 1PE·4PE·8PE의 클록 수를 보드에서 직접 읽습니다.

1일 과정입니다. 서브젝트 4개를 차례로 끝내며 그때마다 보드에서 확인하고, 마지막에 장 전체를 시연합니다.

  1. 4-1INT8·INT16 정밀도 비교
    같은 32비트 값을 두 정밀도로 줄여 봅니다. 768은 Q:03,0030입니다. 65536은 INT8에서 7F로 막히고(넘침 1), INT16에서는 1000으로 정확합니다.    오전
  2. 4-2784 입력 13타일 누산 (INT8)
    시험 #92(숫자 9)를 타일 13개로 나눠 보냅니다. 타일마다 가중치 640개와 입력 64개를 싣고 T를 보내면 T0…TB가 차례로 오고, 마지막에 C4가 옵니다(INT8은 4로 틀립니다). 준비 없이 T를 보내면 E1입니다.    오전
  3. 4-3INT8·INT16 MNIST 정밀도
    같은 그림을 INT16 엔진으로 보냅니다. 가중치와 입력이 2바이트라 보낼 양이 두 배이고, 결과는 정답 C9입니다. LED가 4번에서 9번으로 옮겨 갑니다.    오후
  4. 4-4PE 병렬도·메모리 구조
    같은 타일 하나를 세 가지 구성으로 계산합니다. 4PE는 K4:00CE(206클록), 8PE는 K8:008A(138클록)입니다. 1PE는 클래스마다 가중치를 다시 실어야 해서 K1:0046(70클록)을 10번 반복합니다. 세 구성의 점수는 같습니다.    오후
  5. 시연장 시연
    PC가 28×28 원본 손글씨를 타일 13개로 나눠 보내면, 보드가 3장 코어로 784개 입력을 누산해 분류합니다. 같은 그림이 INT8에서는 4, INT16에서는 정답 9로 갈리고, 1PE·4PE·8PE의 클록 수를 보드에서 직접 읽습니다.    장 끝

02 준비 · 장 뼈대

  1. VS Code에서 저장소 루트(amd_soc_npu/)를 엽니다. 필요한 도구는 Vivado 2024.2(합성·시뮬레이션), python3, 그리고 PC에서 보드로 명령을 보낼 pyserial(pip install pyserial)입니다. 터미널에서 Vivado 명령이 잡히도록 settings64.sh를 먼저 불러옵니다.
  2. 아래 장 뼈대 파일을 경로 그대로 입력합니다. 서브젝트 모듈은 각 서브젝트 절에서 작성합니다.
  3. STAGE는 끝낸 서브젝트 수입니다. 4-1만 끝냈으면 1, 4-4까지 끝냈으면 4입니다. 아직 작성하지 않은 모듈은 빌드에 들어가지 않으므로, 서브젝트를 하나 끝낼 때마다 바로 보드에 올려 볼 수 있습니다.

// 4장 디버그 콘솔: 784 가속기 서브젝트를 UART 명령으로 확인한다. 1~3장과 같은 형식 (1바이트 명령 + 바이너리).
// p = 엔진 (0 INT8, 1 INT16), 원소 하나 = INT8 1바이트 / INT16 2바이트(빅엔디언). g = PE 구성 1·4·8.
//
//   명령 페이로드                         응답                                       서브젝트 (STAGE)
//   S    없음                             "I"                                        모두
//   Q    int32 4바이트                     "Q:" INT8 2자리 "," INT16 4자리 " O:" 넘침 2자리   4-1 (1)
//   B    p class b4..b0 (signed40)         "OK"                                       4-2 (2)   IDLE에서만
//   V    p class n + 원소 n개              "OK"   W[class][0..n-1] 쓰기                4-2 (2)
//   A    p                                "OK"   784 추론 시작 (외부 누산 Clear)       4-2 (2)
//   X    p n(=64) + 원소 64개               "OK"   x 타일 (마지막 타일은 16 + 0 48개)     4-2 (2)
//   T    p 타일번호                         "T" 번호 / 마지막 타일 "C" 클래스 ":" 점수 11자리 ×10   4-2 (2)
//   U    g class n + 바이트 n개             "OK"   PE 구성 g의 가중치 (PE1은 class 무시)   4-4 (4)
//   K    g                                "K" g ":" 클록 4자리 " " 점수 7자리 (PE1 1개, 그 밖 10개)  4-4 (4)
//   엔진 오류 "E" 코드 (4-2 err_code: 1 상태, 2 타일 중복, 3 타일 건너뜀, 4 프레임 없음, 5 쓰기)
//   모르는 명령 "?", 범위 밖 "ERR". 끝은 모두 \r\n.  p = 1은 STAGE 3부터.
`timescale 1ns/1ps
`default_nettype none
module p04_console #(
    parameter integer STAGE = 4
) (
    input  wire               clk,
    input  wire               resetn,
    input  wire [7:0]         rx_data_i,
    input  wire               rx_valid_i,
    output wire               rx_ready_o,
    output reg  [7:0]         tx_data_o,
    output reg                tx_valid_o,
    input  wire               tx_ready_i,
    // 묶음으로
    output reg                q_valid_o,
    output reg  signed [31:0] q_x_o,
    input  wire               q_done_i,
    input  wire signed [7:0]  q8_i,
    input  wire signed [15:0] q16_i,
    input  wire               q_ov8_i,
    input  wire               q_ov16_i,
    output wire [7:0]         s_data_o,
    output wire               s_valid_o,
    output wire               s_last_o,
    input  wire               s_ready_i,
    input  wire               held8_i,
    output reg                ack8_o,
    output reg                x16_we_o,
    output reg  [5:0]         x16_addr_o,
    output reg  signed [15:0] x16_data_o,
    output reg                x16_set_o,
    input  wire               held16_i,
    output reg                p_o,
    output reg                start_o,
    output reg                tile_go_o,
    output reg  [3:0]         tile_id_o,
    output reg                w_wr_o,
    output reg                b_wr_o,
    output reg  [3:0]         class_o,
    output reg  [5:0]         addr_o,
    output reg  signed [15:0] w_o,
    output reg  signed [39:0] b_o,
    input  wire               tile_done_i,
    input  wire               done_i,
    input  wire               error_i,
    input  wire [2:0]         err_code_i,
    input  wire               ovf_i,
    input  wire [3:0]         class_i,
    input  wire [419:0]       scores_i,
    output reg  [3:0]         g_o,
    output reg                pe_wr_o,
    output reg                pe_run_o,
    input  wire               pe_done_i,
    input  wire               pe_err_i,
    input  wire [15:0]        pe_cycles_i,
    input  wire [249:0]       pe_scores_i,
    // 표시
    output reg  [15:0]        view_o,
    output reg  [3:0]         cls_o,
    output reg                cls_ok_o
);
    localparam [3:0] S_IDLE = 4'd0, S_HDR = 4'd1, S_ISSUE = 4'd2, S_DATA = 4'd3, S_DONE = 4'd4,
                     S_QW = 4'd5, S_TW = 4'd6, S_KW = 4'd7, S_LOAD = 4'd8, S_SEND = 4'd9, S_ACK = 4'd10;
    localparam integer MSG_MAX = 128;

    reg [3:0] state;
    reg [7:0] opc;
    reg [7:0] hd [0:6];
    reg [3:0] need, got;
    reg [1:0] dly;
    reg [7:0] n_elem;                 // 남은 원소 수
    reg [5:0] eidx;                   // 원소 주소
    reg       hi_half;                // INT16 원소의 위 바이트를 받았음
    reg [7:0] hi_byte;
    reg       bad;                    // 데이터는 받되 결과는 ERR
    reg       eng_err;
    reg [2:0] eng_code;
    reg [7:0] msg [0:MSG_MAX-1];
    reg [6:0] msg_len, idx;
    integer   k, p;

    function [7:0] hex(input [3:0] n);
        hex = (n < 4'd10) ? (8'h30 + {4'd0, n}) : (8'h37 + {4'd0, n});
    endfunction

    function [3:0] plen(input [7:0] c);    // 고정 머리 바이트 수, 15 = 모르는 명령
        case (c)
            "S":     plen = 4'd0;
            "Q":     plen = 4'd4;
            "B":     plen = (STAGE >= 2) ? 4'd7 : 4'd15;
            "V":     plen = (STAGE >= 2) ? 4'd3 : 4'd15;
            "A":     plen = (STAGE >= 2) ? 4'd1 : 4'd15;
            "X":     plen = (STAGE >= 2) ? 4'd2 : 4'd15;
            "T":     plen = (STAGE >= 2) ? 4'd2 : 4'd15;
            "U":     plen = (STAGE >= 4) ? 4'd3 : 4'd15;
            "K":     plen = (STAGE >= 4) ? 4'd1 : 4'd15;
            default: plen = 4'd15;
        endcase
    endfunction

    wire is_eng   = (opc == "B" || opc == "V" || opc == "A" || opc == "X" || opc == "T");
    wire p_ok     = (hd[0] == 8'd0) || (hd[0] == 8'd1 && STAGE >= 3);
    wire g_ok     = (hd[0] == 8'd1) || (hd[0] == 8'd4) || (hd[0] == 8'd8);
    wire wide     = (opc == "V" || opc == "X") && hd[0][0];       // INT16 원소
    wire [7:0] n_hdr = (opc == "X") ? hd[1] : hd[2];
    wire fields_ok =
        (opc == "B") ? (p_ok && hd[1] < 8'd10) :
        (opc == "V") ? (p_ok && hd[1] < 8'd10 && hd[2] >= 8'd1 && hd[2] <= 8'd64) :
        (opc == "A") ? p_ok :
        (opc == "X") ? (p_ok && hd[1] == 8'd64) :
        (opc == "T") ? (p_ok && hd[1] < 8'd13) :
        (opc == "U") ? (g_ok && hd[1] < 8'd10 && hd[2] >= 8'd1 && hd[2] <= 8'd64) :
        (opc == "K") ? g_ok : 1'b1;

    // INT8 x 타일 바이트는 3-1 버퍼로 바로 흘린다
    wire stream8 = (state == S_DATA) && (opc == "X") && !hd[0][0] && !bad;
    assign s_data_o   = rx_data_i;
    assign s_valid_o  = stream8 && rx_valid_i;
    assign s_last_o   = (n_elem == 8'd1);
    assign rx_ready_o = (state == S_IDLE) || (state == S_HDR) || (state == S_DATA && (!stream8 || s_ready_i));
    wire   rx_take    = rx_valid_i && rx_ready_o;

    task put3(input [7:0] a, input [7:0] b, input [7:0] c, input [6:0] n);
        begin
            msg[0] <= a; msg[1] <= b; msg[2] <= c; msg[n - 2] <= 8'h0D; msg[n - 1] <= 8'h0A; msg_len <= n;
        end
    endtask

    always @(posedge clk) begin
        if (!resetn) begin
            state <= S_IDLE; opc <= 8'd0; need <= 4'd0; got <= 4'd0; dly <= 2'd0; n_elem <= 8'd0; eidx <= 6'd0;
            hi_half <= 1'b0; hi_byte <= 8'd0; bad <= 1'b0; eng_err <= 1'b0; eng_code <= 3'd0;
            msg_len <= 7'd0; idx <= 7'd0; tx_data_o <= 8'd0; tx_valid_o <= 1'b0;
            q_valid_o <= 1'b0; q_x_o <= 32'sd0; ack8_o <= 1'b0; x16_we_o <= 1'b0; x16_addr_o <= 6'd0;
            x16_data_o <= 16'sd0; x16_set_o <= 1'b0; p_o <= 1'b0; start_o <= 1'b0; tile_go_o <= 1'b0;
            tile_id_o <= 4'd0; w_wr_o <= 1'b0; b_wr_o <= 1'b0; class_o <= 4'd0; addr_o <= 6'd0;
            w_o <= 16'sd0; b_o <= 40'sd0; g_o <= 4'd0; pe_wr_o <= 1'b0; pe_run_o <= 1'b0;
            view_o <= 16'd0; cls_o <= 4'd0; cls_ok_o <= 1'b0;
        end else begin
            q_valid_o <= 1'b0; ack8_o <= 1'b0; x16_we_o <= 1'b0; x16_set_o <= 1'b0; start_o <= 1'b0;
            tile_go_o <= 1'b0; w_wr_o <= 1'b0; b_wr_o <= 1'b0; pe_wr_o <= 1'b0; pe_run_o <= 1'b0;
            if (error_i) begin eng_err <= 1'b1; eng_code <= err_code_i; end      // 엔진 오류는 명령 동안 모은다
            case (state)
                S_IDLE: if (rx_take && rx_data_i != 8'h0D && rx_data_i != 8'h0A) begin
                    opc <= rx_data_i; got <= 4'd0; need <= plen(rx_data_i); eng_err <= 1'b0; bad <= 1'b0; dly <= 2'd0;
                    if (plen(rx_data_i) == 4'd15) begin put3("?", 8'h0D, 8'h0A, 7'd3); state <= S_LOAD; end
                    else if (plen(rx_data_i) == 4'd0) begin put3("I", 8'h0D, 8'h0A, 7'd3); state <= S_LOAD; end
                    else state <= S_HDR;
                end
                S_HDR: if (rx_take) begin
                    hd[got] <= rx_data_i;
                    if (got + 4'd1 == need) state <= S_ISSUE;
                    else got <= got + 4'd1;
                end
                S_ISSUE: begin
                    p_o <= hd[0][0];
                    if (opc == "V" || opc == "X" || opc == "U") begin   // 데이터가 따라온다: 범위가 틀려도 받아서 버린다
                        bad <= !fields_ok; n_elem <= n_hdr; eidx <= 6'd0; hi_half <= 1'b0;
                        class_o <= hd[1][3:0]; g_o <= hd[0][3:0];
                        // INT8 x는 들고 있는 타일을 먼저 놓는다
                        if (opc == "X" && fields_ok && !hd[0][0] && held8_i) begin ack8_o <= 1'b1; state <= S_ACK; end
                        else state <= S_DATA;
                    end else if (!fields_ok) begin
                        put3("E", "R", "R", 7'd5); msg[3] <= 8'h0D; msg[4] <= 8'h0A; state <= S_LOAD;
                    end else case (opc)
                        "Q": begin q_x_o <= {hd[0], hd[1], hd[2], hd[3]}; q_valid_o <= 1'b1; state <= S_QW; end
                        "B": begin class_o <= hd[1][3:0]; b_o <= {hd[2], hd[3], hd[4], hd[5], hd[6]}; b_wr_o <= 1'b1; state <= S_DONE; end
                        "A": begin start_o <= 1'b1; state <= S_DONE; end
                        "T": begin tile_id_o <= hd[1][3:0]; tile_go_o <= 1'b1; state <= S_TW; end
                        default: begin g_o <= hd[0][3:0]; pe_run_o <= 1'b1; state <= S_KW; end   // "K"
                    endcase
                end
                S_ACK: state <= S_DATA;
                S_DATA: if (rx_take) begin
                    if (wide && !hi_half) begin
                        hi_byte <= rx_data_i; hi_half <= 1'b1;
                    end else begin
                        hi_half <= 1'b0;
                        if (!bad) begin
                            if (opc == "V") begin
                                addr_o <= eidx; w_o <= wide ? {hi_byte, rx_data_i} : {{8{rx_data_i[7]}}, rx_data_i}; w_wr_o <= 1'b1;
                            end else if (opc == "U") begin
                                addr_o <= eidx; w_o <= {{8{rx_data_i[7]}}, rx_data_i}; pe_wr_o <= 1'b1;
                            end else if (wide) begin                  // INT16 x
                                x16_addr_o <= eidx; x16_data_o <= {hi_byte, rx_data_i}; x16_we_o <= 1'b1;
                            end                                       // INT8 x는 스트림으로 이미 들어감
                        end
                        eidx <= eidx + 6'd1;
                        n_elem <= n_elem - 8'd1;
                        if (n_elem == 8'd1) begin
                            if (opc == "X" && wide && !bad) x16_set_o <= 1'b1;
                            state <= S_DONE;
                        end
                    end
                end
                S_DONE: if (dly != 2'd3) dly <= dly + 2'd1;   // 쓰기·시작 오류가 엔진에서 나올 때까지 기다린다
                else begin
                    if (bad) begin
                        put3("E", "R", "R", 7'd5); msg[3] <= 8'h0D; msg[4] <= 8'h0A;
                    end else if (eng_err || error_i) begin
                        put3("E", hex({1'b0, error_i ? err_code_i : eng_code}), 8'h0D, 7'd4); msg[3] <= 8'h0A;
                    end else begin
                        put3("O", "K", 8'h0D, 7'd4); msg[3] <= 8'h0A;
                    end
                    state <= S_LOAD;
                end
                S_QW: if (q_done_i) begin
                    msg[0] <= "Q"; msg[1] <= ":"; msg[2] <= hex(q8_i[7:4]); msg[3] <= hex(q8_i[3:0]); msg[4] <= ",";
                    for (k = 0; k < 4; k = k + 1) msg[5 + k] <= hex(q16_i[4*(3-k) +: 4]);

                        end
                        view_o <= pe_cycles_i;
                    end
                    state <= S_LOAD;
                end
                S_LOAD: begin
                    tx_data_o <= msg[0]; tx_valid_o <= 1'b1; idx <= 7'd0; state <= S_SEND;
                end
                S_SEND: if (tx_valid_o && tx_ready_i) begin
                    if (idx + 7'd1 == msg_len) begin
                        tx_valid_o <= 1'b0; state <= S_IDLE;
                    end else begin
                        tx_data_o <= msg[idx + 7'd1]; idx <= idx + 7'd1;
                    end
                end
                default: state <= S_IDLE;
            endcase
        end
    end

import json
import struct
import sys
import time
from pathlib import Path

ROOT = Path(__file__).resolve().parents[2]
sys.path.insert(0, str(ROOT))
INT = lambda s: int(s, 0)


def elems(vals, wide):
    out = b""
    for v in vals:
        out += struct.pack(">h", v) if wide else bytes([v & 0xFF])
    return out


def quant(bits):
    from part03.ch18.reference.precision_reference import quantize_model
    m = json.loads((ROOT / "part03/ch18/reference/mnist_linear_f32.json").read_text(encoding="utf-8"))
    return quantize_model(m, bits)


def sample(idx):
    for ln in (ROOT / "part03/ch18/reference/mnist_rtl_samples.txt").read_text(encoding="utf-8").splitlines():
        f = ln.split()
        if f and f[0] == str(idx):
            return int(f[1]), [int(v) for v in f[5:]]
    raise SystemExit(f"표본에 시험 #{idx}가 없다 (part03/ch18/reference/mnist_rtl_samples.txt)")


def digit(idx, prec):
    from part03.ch17.reference.tile784_reference import tile_ranges
    from part03.ch18.reference.precision_reference import quantize_x
    p, bits = (1, 16) if prec == "int16" else (0, 8)
    qm, (label, px) = quant(bits), sample(idx)
    xq, wide = quantize_x(px, bits), p == 1
    cmds = [(b"B" + bytes([p, c]) + (qm["b"][c] & ((1 << 40) - 1)).to_bytes(5, "big"), "B") for c in range(10)]
    cmds.append((b"A" + bytes([p]), "A"))
    for t, (s, n) in enumerate(tile_ranges()):
        cmds += [(b"V" + bytes([p, c, n]) + elems(qm["w"][c][s:s + n], wide), "V") for c in range(10)]
        cmds.append((b"X" + bytes([p, 64]) + elems(xq[s:s + n] + [0] * (64 - n), wide), "X"))
        cmds.append((b"T" + bytes([p, t]), f"T {t}"))
    return cmds, f"시험 #{idx}, 숫자 {label}, {prec.upper()}"


def pe(tile):
    from part03.ch17.reference.tile784_reference import tile_ranges
    from part03.ch18.reference.precision_reference import quantize_x
    qm, (_, px) = quant(8), sample(92)
    s, _ = tile_ranges()[tile]
    cmds = [(b"U" + bytes([g, c, 64]) + elems(qm["w"][c][s:s + 64], False), "U") for g in (4, 8) for c in range(10)]
    cmds.append((b"X" + bytes([0, 64]) + elems(quantize_x(px, 8)[s:s + 64], False), "X"))

def encode(args):
    op, a = args[0], args[1:]
    if op == "S":
        return [(b"S", "S")], ""
    if op == "Q":

학습목표: 시험 #92(숫자 9)를 타일 13개로 나눠 보냅니다. 타일마다 가중치 640개와 입력 64개를 싣고 T를 보내면 T0…TB가 차례로 오고, 마지막에 C4가 옵니다(INT8은 4로 틀립니다). 준비 없이 T를 보내면 E1입니다.

작성할 코드

part03/ch17/rtl/p3_tile784_10.v · verilog
`timescale 1ns/1ps
// (추가) 17장: 784입력(28×28)·10분류를 64원소 타일 13개(64×12 + 16)로 나눠 계산하는 Tile Controller.
// 14장 p3_group10_core(64→10, 4PE 4+4+2 그룹)를 변경 없이 타일마다 한 번 실행한다.
// 코어는 그룹마다 내부 누산기를 지우므로, 타일 결과(부분합)를 클래스별 외부 누산기 acc[c]에 더한다.
//   score[c] = sum_t part[t][c] + bias[c]
// Bias 중복 방지: 코어 Bias 쓰기 포트를 0으로 고정 → 코어 Bias는 Reset 값 0 유지 → 코어 점수 = 순수 부분합.
//   실제 Bias는 외부 레지스터에 두고 13타일 누산이 끝난 뒤 클래스별 1회만 더한다.
// 마지막 타일(12)은 16원소만 유효. 코어는 IN_LEN=64로 64클록을 돌므로 주소 16~63의 x를 0으로 가려
//   프레임 버퍼 잔여값과 이전 타일 가중치가 누산에 들어가지 않게 한다.
// 순서: start → [W 적재 + x 프레임 + tile_go(t)] × 13 → done.
//   W 쓰기는 IDLE·LOAD에서만 받는다. 다음 타일 프레임은 이전 타일의 4+4+2 그룹 계산과
//   결과 수락(외부 누산, frame_ack)이 끝나야 프레임 버퍼가 비워져 들어올 수 있다.
// (변경) 18장: x·W 데이터 폭을 파라미터로 둔다. 기본 DATA_W 8 / CORE_ACC_W 24 / PART_W 25가 17장 INT8 동작이다.
//   INT16: DATA_W 16 / CORE_ACC_W 38(64항 최악 2^36) / PART_W 39(코어 점수 = max(38, 코어 Bias 24) + 1).
module p3_tile784_10 #(
    parameter integer ACC_W = 41,   // 외부 누산 폭. INT16 784항 최악 841,813,590,016 → signed 41
    parameter integer BIAS_W = 40,  // 외부 Bias 폭
    parameter integer SCORE_W = 42, // 최종 점수 폭 ≥ max(ACC_W, BIAS_W) + 1
    parameter integer DATA_W = 8,   // x·W signed 폭
    parameter integer CORE_ACC_W = 24, // 14장 코어 lane 누산 폭(타일 64항)
    parameter integer PART_W = 25   // 14장 코어 점수(부분합) 폭
)(
    input wire clk,
    input wire resetn,
    input wire start_i,                 // 784 추론 시작: 외부 누산기 Clear, 타일 0 대기
    input wire abort_i,                 // LOAD 중 취소: 보관 프레임 해제 후 IDLE
    input wire tile_go_i,               // 현재 프레임·가중치로 타일 tile_id_i 실행
    input wire [3:0] tile_id_i,
    input wire x_valid_i,               // 13장 프레임 버퍼 frame_valid
    output wire x_rd_en_o,
    output wire [5:0] x_rd_addr_o,
    input wire signed [DATA_W-1:0] x_rd_data_i,
    output wire frame_ack_o,
    input wire w_wr_en_i,
    input wire b_wr_en_i,
    input wire [3:0] wr_class_i,
    input wire [5:0] wr_addr_i,
    input wire signed [DATA_W-1:0] w_data_i,
    input wire signed [BIAS_W-1:0] b_data_i,
    output wire load_ready_o,           // W 쓰기 가능(IDLE·LOAD)
    output reg busy_o,
    output reg done_o,
    output reg error_o,
    output reg [2:0] err_code_o,        // 마지막 오류 원인
    output reg ovf_o,                   // 외부 누산 overflow(이번 추론 동안 유지)
    output wire [3:0] tile_idx_o,
    output reg tile_done_o,             // 타일 결과 수락 1클록. 이때 part_scores_o = 해당 타일 부분합
    output wire [10*PART_W-1:0] part_scores_o,
    output reg [3:0] class_o,
    output wire [10*SCORE_W-1:0] scores_o
);
    localparam integer N_CLASS = 10;
    localparam [3:0] LAST_TILE = 4'd12;
    localparam [5:0] LAST_LEN = 6'd16;
    localparam integer SUM_W = ((ACC_W > PART_W) ? ACC_W : PART_W) + 1;
    localparam [2:0] IDLE=3'd0, LOAD=3'd1, RUN=3'd2, ACK=3'd3, SCORE=3'd4, FINISH=3'd5, DROP=3'd6;
    localparam [2:0] ERR_STATE=3'd1, ERR_TILE_DUP=3'd2, ERR_TILE_SKIP=3'd3,
                     ERR_NO_FRAME=3'd4, ERR_WRITE=3'd5, ERR_CORE=3'd6;

    reg [2:0] state;
    reg [3:0] tile_q;
    reg core_start_q;
    reg mask_q;
    reg signed [ACC_W-1:0] acc [0:N_CLASS-1];
    reg signed [BIAS_W-1:0] bias [0:N_CLASS-1];
    reg signed [SCORE_W-1:0] score_q [0:N_CLASS-1];

    wire loading = (state == IDLE) || (state == LOAD);
    wire w_ok = loading && (wr_class_i < N_CLASS);
    wire b_ok = (state == IDLE) && (wr_class_i < N_CLASS);
    assign load_ready_o = resetn && loading;
    assign frame_ack_o = (state == ACK) || (state == DROP);
    assign tile_idx_o = tile_q;

    // 마지막 타일 무효 주소의 x 차단: 프레임 버퍼와 같은 1클록 지연으로 정렬
    always @(posedge clk)
        if (x_rd_en_o)
            mask_q <= (tile_q == LAST_TILE) && (x_rd_addr_o >= LAST_LEN);

    wire core_done, core_err;
    p3_group10_core #(.IN_LEN(64), .OUT_N(10), .DATA_W(DATA_W), .ACC_W(CORE_ACC_W),
                      .BIAS_W(24), .SCORE_W(PART_W)) core(
        .clk(clk), .resetn(resetn), .start_i(core_start_q), .x_valid_i(x_valid_i),
        .x_rd_en_o(x_rd_en_o), .x_rd_addr_o(x_rd_addr_o),
        .x_rd_data_i(mask_q ? {DATA_W{1'b0}} : x_rd_data_i),
        .w_wr_en_i(w_wr_en_i && w_ok), .b_wr_en_i(1'b0), .wr_class_i(wr_class_i),
        .wr_addr_i(wr_addr_i), .w_data_i(w_data_i), .b_data_i(24'sd0), .load_ready_o(),
        .busy_o(), .done_o(core_done), .error_o(core_err), .class_o(), .scores_o(part_scores_o));

    // 클래스별 외부 누산(넘침 검출 폭 SUM_W)과 최종 Bias 합
    wire signed [SUM_W-1:0] sum_w [0:N_CLASS-1];
    wire signed [SCORE_W-1:0] final_w [0:N_CLASS-1];
    wire [N_CLASS-1:0] acc_fit;
    genvar g;
    generate
        for (g = 0; g < N_CLASS; g = g + 1) begin : cls
            assign sum_w[g] = acc[g] + $signed(part_scores_o[g*PART_W +: PART_W]);
            // 상위 비트가 모두 부호와 같으면 ACC_W 안에 들어간다
            assign acc_fit[g] = &sum_w[g][SUM_W-1:ACC_W-1] || ~|sum_w[g][SUM_W-1:ACC_W-1];
            assign final_w[g] = acc[g] + bias[g];
            assign scores_o[g*SCORE_W +: SCORE_W] = score_q[g];
        end
    endgenerate

    // 10개 점수 최대값, 동점은 낮은 번호(14장 코어와 같은 규칙)
    // (변경) 19장 타이밍 결함 수정: 9단 직렬 비교 → 4단 토너먼트 트리를 두 클록으로 나눈다.
    //   마지막 타일 ACK에서 score_q 확정, SCORE에서 1·2단 결과를 레지스터에, FINISH에서 3·4단.
    //   왼쪽(낮은 번호)은 오른쪽이 엄격히 클 때만 진다. done 시점은 그대로.
    integer k;
    reg signed [SCORE_W-1:0] a2s0_q, a2s1_q, a2s2_q;
    reg [3:0] a2c0_q, a2c1_q, a2c2_q;
    wire signed [SCORE_W-1:0] t1s [0:4];
    wire [3:0] t1c [0:4];
    generate
        for (g = 0; g < 5; g = g + 1) begin : arg1
            wire r = score_q[2*g+1] > score_q[2*g];
            assign t1s[g] = r ? score_q[2*g+1] : score_q[2*g];
            assign t1c[g] = r ? 2*g+1 : 2*g;
        end
    endgenerate
    wire r2a = t1s[1] > t1s[0], r2b = t1s[3] > t1s[2];
    wire signed [SCORE_W-1:0] t2s0 = r2a ? t1s[1] : t1s[0], t2s1 = r2b ? t1s[3] : t1s[2];
    wire [3:0] t2c0 = r2a ? t1c[1] : t1c[0], t2c1 = r2b ? t1c[3] : t1c[2];
    wire r3 = a2s1_q > a2s0_q;
    wire signed [SCORE_W-1:0] t3s = r3 ? a2s1_q : a2s0_q;
    wire [3:0] t3c = r3 ? a2c1_q : a2c0_q;
    wire [3:0] best_class = (a2s2_q > t3s) ? a2c2_q : t3c;

    always @(posedge clk) begin
        if (!resetn) begin
            state <= IDLE;
            tile_q <= 4'd0;
            core_start_q <= 1'b0;
            busy_o <= 1'b0;
            done_o <= 1'b0;
            error_o <= 1'b0;
            err_code_o <= 3'd0;
            ovf_o <= 1'b0;
            tile_done_o <= 1'b0;
            class_o <= 4'd0;
            for (k = 0; k < N_CLASS; k = k + 1) begin
                acc[k] <= {ACC_W{1'b0}};
                bias[k] <= {BIAS_W{1'b0}};
                score_q[k] <= {SCORE_W{1'b0}};
            end
        end else begin
            core_start_q <= 1'b0;
            done_o <= 1'b0;
            error_o <= 1'b0;
            tile_done_o <= 1'b0;
            // Bias는 IDLE에서만 바꿀 수 있다(추론 중 변경 금지)
            if (b_wr_en_i && b_ok)
                bias[wr_class_i] <= b_data_i;
            if ((w_wr_en_i && !w_ok) || (b_wr_en_i && !b_ok)) begin
                error_o <= 1'b1;
                err_code_o <= ERR_WRITE;
            end
            // 허용 상태 밖의 명령: IDLE은 start만, LOAD는 tile_go·abort만
            if ((start_i && state != IDLE) || ((tile_go_i || abort_i) && state != LOAD)) begin
                error_o <= 1'b1;
                err_code_o <= ERR_STATE;
            end
            case (state)
                IDLE: if (start_i) begin
                    busy_o <= 1'b1;
                    tile_q <= 4'd0;
                    ovf_o <= 1'b0;
                    for (k = 0; k < N_CLASS; k = k + 1)
                        acc[k] <= {ACC_W{1'b0}};
                    state <= LOAD;
                end
                LOAD: if (abort_i) begin
                    state <= DROP;
                end else if (tile_go_i) begin
                    // 타일 번호는 0..12 순서대로 한 번씩만: 이미 처리한 번호는 중복, 앞선 번호는 누락
                    if (tile_id_i < tile_q) begin
                        error_o <= 1'b1;
                        err_code_o <= ERR_TILE_DUP;
                    end else if (tile_id_i > tile_q) begin
                        error_o <= 1'b1;
                        err_code_o <= ERR_TILE_SKIP;
                    end else if (!x_valid_i) begin
                        error_o <= 1'b1;
                        err_code_o <= ERR_NO_FRAME;
                    end else begin
                        core_start_q <= 1'b1;
                        state <= RUN;
                    end
                end
                // 코어 done 시 10개 부분합은 고정되어 있다 → 외부 누산기에 한 번에 더한다
                RUN: if (core_done) begin
                    for (k = 0; k < N_CLASS; k = k + 1)
                        acc[k] <= sum_w[k][ACC_W-1:0];
                    if (~&acc_fit)
                        ovf_o <= 1'b1;
                    tile_done_o <= 1'b1;
                    state <= ACK;
                end
                // frame_ack_o = 1: 현재 타일 프레임 해제 → 다음 타일 프레임 수신 가능
                // 마지막 타일: 외부 누산이 직전 에지에서 끝났으므로 여기서 Bias를 더해 점수 확정
                ACK: if (tile_q == LAST_TILE) begin
                    for (k = 0; k < N_CLASS; k = k + 1)
                        score_q[k] <= final_w[k];
                    state <= SCORE;
                end else begin
                    tile_q <= tile_q + 4'd1;
                    state <= LOAD;
                end
                // argmax 1·2단 결과 저장
                SCORE: begin
                    a2s0_q <= t2s0; a2c0_q <= t2c0;
                    a2s1_q <= t2s1; a2c1_q <= t2c1;
                    a2s2_q <= t1s[4]; a2c2_q <= t1c[4];
                    state <= FINISH;
                end
                FINISH: begin
                    class_o <= best_class;
                    done_o <= 1'b1;
                    busy_o <= 1'b0;
                    state <= IDLE;
                end
                // 취소: frame_ack_o = 1로 보관 프레임 해제
                DROP: begin
                    busy_o <= 1'b0;
                    state <= IDLE;
                end
                default: begin
                    busy_o <= 1'b0;
                    state <= IDLE;
                end
            endcase
            // 컨트롤러가 쓰기·start를 거른 뒤이므로 코어 오류는 발생하면 안 된다(진단용)
            if (core_err) begin
                error_o <= 1'b1;
                err_code_o <= ERR_CORE;
            end
        end
    end
    // synthesis translate_off
    initial begin
        if (ACC_W < 2 || BIAS_W < 2 || SCORE_W < ((ACC_W > BIAS_W) ? ACC_W : BIAS_W) + 1)
            $fatal(1, "Require SCORE_W >= max(ACC_W, BIAS_W) + 1");
    end
    // synthesis translate_on
endmodule

// 4장 보드 Top 시험: UART 핀으로 명령을 보내고 TX 핀을 복조해 기준 모델(p04_cases_sN.txt)과 바이트 단위로 대조한다.
// 4장 Top에는 스위치 입력이 없다. 784 추론 한 번에 약 1만 바이트라 UART를 12.5 Mbps(비트당 8클록)로 돌린다.
// 시뮬레이션 시간을 줄이려고 BAUD 6.25 Mbps(CPB 16), REFRESH_BITS 6으로 돌린다. 보드 Top 기본값은 115200 bps.
`timescale 1ns/1ps
module tb_p04_top;
    parameter integer STAGE = 4;                  // run_sim.sh가 1~4로 바꿔 네 번 돌린다
    localparam integer CLK_HZ = 100000000, BAUD = 12500000;
    localparam integer CPB = (CLK_HZ + BAUD / 2) / BAUD;
    reg clk = 0, btnC = 1, rxd = 1;
    reg [1:0] sw = 2'd0;
    wire txd, dp;
    wire [15:0] led;
    wire [6:0] seg;
    wire [3:0] an;
    always #5 clk = ~clk;

    basys3_p04_top #(.CLK_HZ(CLK_HZ), .BAUD(BAUD), .REFRESH_BITS(6), .STAGE(STAGE)) dut (
        .clk(clk), .btnC(btnC), .uart_rxd(rxd), .uart_txd(txd),
        .led(led), .seg(seg), .an(an), .dp(dp));

    // TX 핀 복조 (1-1 uart_rx 그대로)
    wire [7:0] got;
    wire got_valid, fe, ov;
    reg mon_resetn = 0;
    uart_rx #(.CLK_HZ(CLK_HZ), .BAUD(BAUD)) mon (
        .clk(clk), .resetn(mon_resetn), .rx_i(txd), .out_data_o(got), .out_valid_o(got_valid),
        .out_ready_i(1'b1), .framing_error_o(fe), .overrun_o(ov));

    reg [7:0] rxq [0:255];
    integer rx_wr = 0;
    always @(posedge clk) if (got_valid) begin
        rxq[rx_wr[7:0]] = got;
        rx_wr = rx_wr + 1;
    end

    task automatic send_byte(input [7:0] b);
        integer k;
        begin
            @(negedge clk); rxd = 0; repeat (CPB) @(negedge clk);
            for (k = 0; k < 8; k = k + 1) begin rxd = b[k]; repeat (CPB) @(negedge clk); end
            rxd = 1; repeat (CPB) @(negedge clk);
        end
    endtask

    integer fd, n_tx, n_rx, i, v, sel, cases = 0, rx_rd = 0, t, code;
    reg [8*8-1:0] subj;
    reg [8*200-1:0] line;
    reg [7:0] tx [0:255];
    reg [7:0] exp [0:127];
    reg [15:0] led_exp;
    reg [8*4-1:0] tag;

    initial begin
        fd = $fopen($sformatf("p04/tb/p04_cases_s%0d.txt", STAGE), "r");
        if (fd == 0) $fatal(1, "p04_cases_s%0d.txt 없음: python3 p04/reference/p04_model.py 먼저", STAGE);
        code = $fgets(line, fd);                         // 머리 줄
        repeat (5) @(posedge clk);
        btnC = 0; mon_resetn = 1;
        repeat (10) @(posedge clk);
        forever begin
            code = $fscanf(fd, "%s", subj);
            if (code != 1) $fatal(1, "사례 파일 끝에 END 줄 없음");
            if (subj == "END") begin
                code = $fscanf(fd, "%h", v); led_exp = v;
                repeat (20) @(posedge clk);
                if (led !== led_exp) $fatal(1, "LED=%04h 기대 %04h", led, led_exp);
                if (fe || ov) $fatal(1, "TX 복조 오류 fe=%0d ov=%0d", fe, ov);
                $display("P04_BOARD_TOP_LED_PASS stage=%0d led=0x%04h", STAGE, led);
                $display("P04_TOP_RTL_SIM_PASS stage=%0d cases=%0d bytes=%0d", STAGE, cases, rx_wr);
                $finish;
            end
            code = $fscanf(fd, "%h %h", sel, n_tx);
            for (i = 0; i < n_tx; i = i + 1) begin code = $fscanf(fd, "%h", v); tx[i] = v; end
            code = $fscanf(fd, "%h", n_rx);
            for (i = 0; i < n_rx; i = i + 1) begin code = $fscanf(fd, "%h", v); exp[i] = v; end
            sw = sel;
            repeat (8) @(posedge clk);                    // 스위치 2FF 동기화 대기
            for (i = 0; i < n_tx; i = i + 1) send_byte(tx[i]);
            t = 0;
            while (rx_wr - rx_rd < n_rx) begin
                @(posedge clk); t = t + 1;
                if (t > 40 * CPB * (n_rx + 2)) $fatal(1, "%0s 응답 시간 초과: %0d/%0d 바이트", subj, rx_wr - rx_rd, n_rx);
            end
            for (i = 0; i < n_rx; i = i + 1)
                if (rxq[(rx_rd + i) % 256] !== exp[i])
                    $fatal(1, "%0s 응답 %0d번째 바이트 %02h 기대 %02h", subj, i, rxq[(rx_rd + i) % 256], exp[i]);
            $write("P04_CASE_PASS stage=%0d %0s sw=%0d rx=\"", STAGE, subj, sel);
            for (i = 0; i < n_rx; i = i + 1)
                if (exp[i] == 8'h0D) $write("\\r"); else if (exp[i] == 8'h0A) $write("\\n"); else $write("%c", exp[i]);
            $display("\"");
            rx_rd = rx_rd + n_rx;
            cases = cases + 1;
        end
    end

    // 7세그먼트: an이 켠 자리에 led의 그 자리 16진수가 보여야 한다 (한 번 확인)
    initial begin
        #200000;
        if (an == 4'b1111) $fatal(1, "7세그먼트 자리가 하나도 켜지지 않음");
    end
endmodule

"""4장 784 가속기 보드 기준 모델.

명령 순서를 정하고 보드가 돌려줄 응답을 계산해 p04/tb/p04_cases_s{STAGE}.txt (STAGE 1~4)와
표시용 설명 p04/tb/p04_case_labels_s{STAGE}.txt를 쓴다.
계산은 서브젝트 기준 모델 함수를 그대로 쓴다:
  4-1: 2-2 quantize (INT8 SHIFT 8, INT16 SHIFT 4)
  4-2·4-3: quantize_model · quantize_x · model(13타일 외부 누산)
  4-4: config_cycles (1PE·4PE·8PE 클록)
시연 그림: 4-3 고정 표본 파일의 시험 #92 (숫자 9, 4-3 PC 평가에서 INT8 → 4, INT16 → 9).

  python3 p04/reference/p04_model.py
"""
import json
import struct
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parents[2]
sys.path.insert(0, str(ROOT))
sys.path.insert(0, str(ROOT / "ch05" / "reference"))
from fixed_reference import quantize                                         # noqa: E402  (2-2)
from part03.host_tools.p3_integer_reference import dot_signed                # noqa: E402
from part03.ch17.reference.tile784_reference import model, tile_ranges       # noqa: E402  (4-2)
from part03.ch18.reference.precision_reference import quantize_model, quantize_x  # noqa: E402  (4-3)
from part03.ch19.reference.arch_reference import config_cycles               # noqa: E402  (4-4)

CASES_OUT = ROOT / "p04" / "tb" / "p04_cases_s%d.txt"
LABELS_OUT = ROOT / "p04" / "tb" / "p04_case_labels_s%d.txt"
F32 = ROOT / "part03" / "ch18" / "reference" / "mnist_linear_f32.json"
SAMPLES = ROOT / "part03" / "ch18" / "reference" / "mnist_rtl_samples.txt"
ACC_W, BIAS_W = 41, 40
DEMO = 92                         # 시험 번호
PE_TILE = 6                       # 4-4에서 쓰는 타일 (그림 가운데 줄)
CRLF = "\r\n"
NEED = {"S": 0, "Q": 4, "B": 7, "V": 3, "A": 1, "X": 2, "T": 2, "U": 3, "K": 1}
MIN_STAGE = {"B": 2, "V": 2, "A": 2, "X": 2, "T": 2, "U": 4, "K": 4}


def h(v, n):
    return format(v & ((1 << (4 * n)) - 1), "0%dX" % n)


def sample(idx):
    for ln in SAMPLES.read_text(encoding="utf-8").splitlines():
        f = ln.split()
        if f and f[0] == str(idx):
            return int(f[1]), [int(v) for v in f[2:5]], [int(v) for v in f[5:]]
    raise KeyError(idx)


class Engine:
    """p3_tile784_10 한 개의 바깥 동작 (4-2 상태 표 중 이 장에서 쓰는 부분)."""

    def __init__(self, bits):
        self.bits = bits
        self.state = "IDLE"
        self.bank = [[None] * 64 for _ in range(10)]
        self.w = [[None] * 784 for _ in range(10)]      # 이번 추론에 실제로 쓰인 가중치
        self.b = [0] * 10
        self.x = [None] * 784
        self.next = 0
        self.frame = None


class Board:
    def __init__(self, stage):
        self.stage = stage
        self.eng = [Engine(8), Engine(16)]
        self.pe = {1: [None] * 64, 4: [[None] * 64 for _ in range(10)], 8: [[None] * 64 for _ in range(10)]}
        self.view, self.cls, self.cls_ok = 0, 0, False

    def held8(self):
        return self.eng[0].frame is not None

    def step(self, data):
        c = chr(data[0])
        if c not in NEED or self.stage < MIN_STAGE.get(c, 1):
            return "?" + CRLF
        hd, body = data[1:1 + NEED[c]], data[1 + NEED[c]:]
        if c == "S":
            return "I" + CRLF
        if c == "Q":
            v = struct.unpack(">i", bytes(hd))[0]
            q8, o8 = quantize(v, 8, 8, 1, 1)
            q16, o16 = quantize(v, 16, 4, 1, 1)
            self.view = q16 & 0xFFFF
            return "Q:%s,%s O:%d%d" % (h(q8, 2), h(q16, 4), o8, o16) + CRLF
        if c in "UK":
            g = hd[0]
            if g not in (1, 4, 8) or (c == "U" and not (hd[1] < 10 and 1 <= hd[2] <= 64)):
                return "ERR" + CRLF
            if c == "U":
                vals = [struct.unpack("b", bytes([v]))[0] for v in body]
                for i, v in enumerate(vals):
                    if g == 1:
                        self.pe[1][i] = v
                    else:
                        self.pe[g][hd[1]][i] = v
                return "OK" + CRLF
            x = self.eng[0].frame
            assert x is not None
            cyc = config_cycles()
            if g == 1:
                scores = [dot_signed(x, self.pe[1])]
                n = cyc["PE1_pass"]
            else:
                scores = [dot_signed(x, row) for row in self.pe[g]]
                n = cyc["PE%d" % g]
            self.view = n
            return "K%d:%s " % (g, h(n, 4)) + ",".join(h(s, 7) for s in scores) + CRLF
        p = hd[0]
        if p > 1 or (p == 1 and self.stage < 3):
            return "ERR" + CRLF
        e = self.eng[p]
        wide = p == 1
        if c == "B":
            if hd[1] >= 10:
                return "ERR" + CRLF
            assert e.state == "IDLE"
            v = int.from_bytes(bytes(hd[2:7]), "big")
            e.b[hd[1]] = v - (1 << 40) if v >> 39 else v
            return "OK" + CRLF
        if c in "VX":
            if wide:
                vals = [struct.unpack(">h", bytes(body[2 * i:2 * i + 2]))[0] for i in range(len(body) // 2)]
            else:
                vals = [struct.unpack("b", bytes([v]))[0] for v in body]
            if c == "V":
                if not (hd[1] < 10 and 1 <= hd[2] <= 64):
                    return "ERR" + CRLF
                for i, v in enumerate(vals):
                    e.bank[hd[1]][i] = v
                return "OK" + CRLF
            if hd[1] != 64:
                return "ERR" + CRLF
            e.frame = vals
            return "OK" + CRLF
        if c == "A":
            assert e.state == "IDLE"
            e.state, e.next = "LOAD", 0
            return "OK" + CRLF
        # T
        t = hd[1]
        if t >= 13:
            return "ERR" + CRLF
        if e.state != "LOAD":
            return "E1" + CRLF                                  # 4-2 ERR_STATE
        assert t == e.next and e.frame is not None
        s, n = tile_ranges()[t]
        for cl in range(10):
            e.w[cl][s:s + n] = e.bank[cl][:n]
        e.x[s:s + n] = e.frame[:n]
        e.frame = None                                          # 타일이 끝나면 프레임을 놓는다
        e.next += 1
        if t < 12:
            self.view = t
            return "T%X" % t + CRLF
        _, scores, cls, ovf = model(e.x, e.w, e.b, ACC_W, BIAS_W, e.bits)
        e.state = "IDLE"
        self.view, self.cls, self.cls_ok = cls, cls, True
        return "C%X:" % cls + ",".join(h(v, 11) for v in scores) + (" V" if ovf else "") + CRLF

    def led(self):
        onehot = (1 << self.cls) if self.cls_ok else 0
        return onehot | (int(self.eng[1].frame is not None) << 14) | (int(self.held8()) << 15)


def elems(vals, wide):
    out = []
    for v in vals:
        out += list(struct.pack(">h", v)) if wide else [v & 0xFF]
    return out


def run_784(p, qm, xq, add, tag):
    """784 추론 한 번: Bias 10 → A → 타일마다 V 10 · X · T (PC 도구 'digit'과 같은 순서)."""
    wide = p == 1
    for cl in range(10):
        add([ord("B"), p, cl] + list((qm["b"][cl] & ((1 << 40) - 1)).to_bytes(5, "big")), f"load Bias {tag}")
    add([ord("A"), p], "")
    for t, (s, n) in enumerate(tile_ranges()):
        for cl in range(10):
            add([ord("V"), p, cl, n] + elems(qm["w"][cl][s:s + n], wide), f"load W {tag} 타일 {t}")
        xt = xq[s:s + n] + [0] * (64 - n)
        add([ord("X"), p, 64] + elems(xt, wide), f"X {p} 64 ({tag} 타일 {t} x{', 16 + 0 48개' if n < 64 else ''})")
        add([ord("T"), p, t], "")


def build_cases():
    label, preds, px = sample(DEMO)
    m = json.loads(F32.read_text(encoding="utf-8"))
    q8m, q16m = quantize_model(m, 8), quantize_model(m, 16)
    x8, x16 = quantize_x(px, 8), quantize_x(px, 16)
    cases = []
    add = lambda subj: (lambda d, t="": cases.append((subj, d, t)))
    a = add("4-1")
    a([ord("S")])
    for v in (768, 384, -384, 65536, 0x7FFFFFFF):
        a([ord("Q")] + list(struct.pack(">i", v)))
    a = add("4-2")
    a([ord("T"), 0, 5])                                       # IDLE에서 T → E1
    run_784(0, q8m, x8, a, "INT8")
    a = add("4-3")
    run_784(1, q16m, x16, a, "INT16")
    a = add("4-4")
    s, n = tile_ranges()[PE_TILE]
    for g in (4, 8):
        for cl in range(10):
            a([ord("U"), g, cl, 64] + elems(q8m["w"][cl][s:s + 64], False), f"load PE{g} 타일 {PE_TILE}")
    a([ord("X"), 0, 64] + elems(x8[s:s + 64], False), f"X 0 64 (INT8 타일 {PE_TILE} x)")
    a([ord("K"), 4]); a([ord("K"), 8])
    for cl in range(10):
        a([ord("U"), 1, cl, 64] + elems(q8m["w"][cl][s:s + 64], False), f"U 1 {cl} 64 (PE1에 class {cl} 가중치)")
        a([ord("K"), 1])
    return cases, (label, preds)


def self_test():
    b = Board(4)
    assert b.step([ord("Q")] + list(struct.pack(">i", 768))) == "Q:03,0030 O:00\r\n"
    assert b.step([ord("Q")] + list(struct.pack(">i", 65536))) == "Q:7F,1000 O:10\r\n"
    assert b.step([ord("T"), 0, 0]) == "E1\r\n"
    assert Board(2).step([ord("A"), 1]) == "ERR\r\n"                     # INT16은 4-3부터
    assert Board(1).step([ord("A"), 0]) == "?\r\n"
    c = config_cycles()
    assert (c["PE1_pass"], c["PE4"], c["PE8"]) == (70, 206, 138)
    print("PYTHON_P04_SELF_TEST_PASS")


def main():
    self_test()
    cases, (label, preds) = build_cases()
    for stage in range(1, 5):
        b = Board(stage)
        lines = ["# subject sw n_tx tx... n_rx rx... (16진수). p04_model.py가 만든다. 직접 고치지 않는다."]
        labs = []
        sel = [x for x in cases if int(x[0][2]) <= stage]
        if stage == 1:
            sel = sel + [("4-1", [ord("A"), 0], "")]               # 4-1 빌드에는 784 엔진이 없다 → '?'
        for subj, data, text in sel:
            resp = b.step(data).encode()
            lines.append(" ".join([subj, "0", "%x" % len(data)] + ["%02x" % v for v in data]
                                  + ["%x" % len(resp)] + ["%02x" % v for v in resp]))
            labs.append(text)
            if stage == 4 and resp[:1] in (b"C", b"K"):
                print("PYTHON_P04_CASE %s %s" % (subj, resp.decode().strip()[:40]))
        lines.append("END %04x" % b.led())
        CASES_OUT.with_name(CASES_OUT.name % stage).write_text("\n".join(lines) + "\n", encoding="utf-8")
        LABELS_OUT.with_name(LABELS_OUT.name % stage).write_text("\n".join(labs) + "\n", encoding="utf-8")
        print("PYTHON_P04_VECTORS stage=%d cases=%d tx_bytes=%d final_led=0x%04X"
              % (stage, len(sel), sum(len(d) for _, d, _ in sel), b.led()))
    print(f"PYTHON_P04_DEMO sample=#{DEMO} label={label} pc_pred_float={preds[0]} int8={preds[1]} int16={preds[2]}")
    return 0


if __name__ == "__main__":
    sys.exit(main())

4-1 INT8·INT16 정밀도 비교precision_compare.v같은 32비트 값을 두 정밀도로 줄여 봅니다. 768은 Q:03,0030입니다. 65536은 INT8에서 7F로 막히고(넘침 1), INT16에서는 1000으로 정확합니다.
4-2 784 입력 13타일 누산 (INT8)p3_tile784_10.v시험 #92(숫자 9)를 타일 13개로 나눠 보냅니다. 타일마다 가중치 640개와 입력 64개를 싣고 T를 보내면 T0…TB가 차례로 오고, 마지막에 C4가 옵니다(INT8은 4로 틀립니다). 준비 없이 T를 보내면 E1입니다.
4-3 INT8·INT16 MNIST 정밀도—같은 그림을 INT16 엔진으로 보냅니다. 가중치와 입력이 2바이트라 보낼 양이 두 배이고, 결과는 정답 C9입니다. LED가 4번에서 9번으로 옮겨 갑니다.
4-4 PE 병렬도·메모리 구조—같은 타일 하나를 세 가지 구성으로 계산합니다. 4PE는 K4:00CE(206클록), 8PE는 K8:008A(138클록)입니다. 1PE는 클래스마다 가중치를 다시 실어야 해서 K1:0046(70클록)을 10번 반복합니다. 세 구성의 점수는 같습니다.
