BASYS3 · PART 01 · CHAPTER 01–11 v02

제1부 · MicroBlaze V 기본 SoC

CPU·BRAM·AXI 주변장치 구축에서 사용자 Top 연결까지

00학습 흐름

Basys3 위에 MicroBlaze V CPU와 Local BRAM으로 가장 작은 SoC를 만들고, AXI 주변장치를 하나씩 붙여 GPIO·UART·Timer·Interrupt를 다루는 SoC로 키웁니다. 11장에서 사용자 Top을 연결해 제1부의 SoC를 완성합니다.

01~05장 MicroBlaze V · BRAM · Clock/Reset · Memory Map · AXI ↓ 06~09장 AXI GPIO · UART Lite · Timer · Interrupt Controller (07.1~09.1 C 코드 풀이) ↓ 10장 GPIO · UART · Timer 통합 (10.1 C 코드 풀이) ↓ 11장 사용자 Top과 1비트 GPIO

각 장은 앞 장의 Vivado·Vitis 프로젝트를 새 이름으로 복제해 이어서 만듭니다. 앞 장 프로젝트는 그대로 둡니다.

01장별 바로가기

01~05장 · 프로세서·메모리·버스

장제목학습 내용
01MicroBlaze V + BRAM 최소 SoCBasys3의 Artix-7 FPGA 내부에 MicroBlaze V(마이크로블레이즈 브이) CPU와 Local BRAM을 구성하고, Local BRAM과 Debug 구성요소를 자동 생성한다.
02Clock · Reset 구조01장에서 만든 Block Design을 이어서 Clocking Wizard 설정, Clock/Reset 연결, 기존 XDC 확인, Validate Design 및 빌드를 진행한다.
03BRAM 프로그램 실행02장에서 Bitstream을 생성한 기존 하드웨어를 XSA로 내보내고, Vitis에서 MicroBlaze V의 ELF 프로그램을 빌드해 Local BRAM 읽기·쓰기를 확인한다.
04Memory Map · MMIOVivado에서 16 KiB Local BRAM 주소를 확인하고, Vitis에서 C 프로그램을 빌드·실행한 뒤 WATCH로 실제 주소와 읽기·쓰기 결과를 확인한다.
05AXI4 · AXI4-Lite · AXI4-StreamAXI4·AXI4-Lite·AXI4-Stream의 차이와 5개 채널, VALID/READY 핸드셰이크 및 공식 전송 파형을 이해한다.

06~10장 · AXI 주변장치와 통합

장제목학습 내용
06AXI GPIOVivado에서 AXI GPIO를 연결하고 Vitis에서 C 프로그램을 작성하여, Basys3 스위치 16개 상태를 LED 16개에 그대로 표시한다.
07AXI UART LiteBasys3의 FT2232HQ USB-UART Bridge와 AXI UART Lite를 연결하고, PC에서 입력한 문자를 MicroBlaze V가 RX FIFO에서 읽은 뒤 TX FIFO로 다시 전송한다.
07.1UART Echo C 코드 풀이07장에서 성공한 main.c 를 한 줄씩 풀어 읽는다.
08AXI Timer07장에서 만든 MicroBlaze V + AXI GPIO + AXI UART Lite 회로에 Timer IP를 추가합니다.
08.1AXI Timer C 코드 풀이08장에서 실제 성공한 Timer Polling과 LED0 반전 C 코드를 07.1장과 같은 방식으로 풀어 읽습니다.
09AXI Interrupt Controller08장의 0.5초 Timer Polling을 Interrupt 방식으로 바꿉니다.
09.1Timer Interrupt C 코드 풀이09장 AXI Interrupt Controller 실습의 main.c를 코드 → 쉬운 풀이 → CPU·하드웨어 동작 순서로 읽습니다.
10GPIO · UART · Timer 통합09장 성공 프로젝트를 복제하여 Local BRAM을 16 KiB → 64 KiB로 확장한 뒤, 새 Vivado XSA·Vitis Platform으로 SW 입력·UART 명령·Timer Interrupt를 통합 실행합니다.
10.1통합 C 코드 풀이기존 10장 main.c를 기능별로 나누어 코드 → 쉬운 해설 → CPU·메모리·AXI 하드웨어 동작 순서로 살펴봅니다.
